# roms/rp2040/

ROM and flash images for the `mdrp2040` emulator and harness binaries.

## Contents

| File | Size | Source | Notes |
|---|---|---|---|
| `bootrom.bin` | 16 KB | Generated by `gen_blinky.py` | Synthetic stub: word 0 = initial SP, word 1 = `0x10000001` (flash + Thumb), rest filled with `B .` traps. Paired with `blinky.bin`. |
| `blinky.bin` | 28 B | Generated by `gen_blinky.py` | GPIO25 blink loop. Boots via the synthetic `bootrom.bin` above. |
| `bootrom-rp2040-b2.bin` | 16 KB | Upstream Raspberry Pi | Official RP2040 **B2** silicon bootrom. Required for booting real SDK-based firmware (e.g. PicoGUS). |
| `bootrom-rp2040-LICENSE.txt` | 1.7 KB | Upstream Raspberry Pi | BSD-3-Clause covering `bootrom-rp2040-b2.bin`. |
| `gen_blinky.py` | | this repo | Regenerates `bootrom.bin` + `blinky.bin`. |

## The two bootroms — when to use which

- **`bootrom.bin`** (synthetic). Minimum viable: SP + reset vector only.
  Sufficient for the hand-assembled `blinky.bin`, which doesn't call
  back into the bootrom. This is what `mdrp2040app`'s smoke test uses.
- **`bootrom-rp2040-b2.bin`** (real). Required for firmware that uses
  Pico-SDK boot2 stage-2 — standard sequence is `reset → bootrom ROM
  table lookup → BL boot2 → POP {PC} back to bootrom → jump VTOR+0x100`.
  Without the real bootrom, boot2's `POP {PC}` returns to an invalid
  address and the core wedges. This is what `picogus_diff_rp2040`
  defaults to when `--flash` is supplied.

## `bootrom-rp2040-b2.bin` — provenance

Extracted from the `b2.elf` asset of the
[`raspberrypi/pico-bootrom-rp2040`](https://github.com/raspberrypi/pico-bootrom-rp2040)
`b2` release (published 2022-05-16), targeting RP2040 B2 silicon. B2 is
the production silicon stepping in every shipping Raspberry Pi Pico.
Earlier steppings (B0, B1) are available at the same release URL pattern
if ever needed; B2 is a strict superset of behaviour that matters here.

Extraction:

```sh
curl -L -o b2.elf \
  https://github.com/raspberrypi/pico-bootrom-rp2040/releases/download/b2/b2.elf
llvm-objcopy -O binary b2.elf bootrom-rp2040-b2.bin
```

SHA256:
