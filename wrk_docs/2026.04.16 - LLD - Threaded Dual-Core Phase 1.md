# Threaded Dual-Core Phase 1 — Low-Level Design

Version: 1.0.0
Date: 2026-04-16
Parent HLD: 2026.04.16 - HLD - Threaded Dual-Core Emulation V5.md

## Scope

Three standalone types that Phase 3 will compose into `SharedState`:

1. **SharedMemory** — SRAM as `Box<[AtomicU32]>`, immutable ROM/XIP
2. **AtomicGpio** — atomic pin out/oe state
3. **ExclusiveMonitors** — per-core monitors with cross-thread snoop

All live in `crates/mdrp2350/src/threaded/`. No integration into
`Bus` or `Emulator` — that's Phase 3. Unit tests for every access
pattern.

## 1. SharedMemory

### Struct

```rust
use std::sync::atomic::{AtomicU32, Ordering::Relaxed};

pub struct SharedMemory {
    sram: Box<[AtomicU32]>,   // 130_000 words = 520 KB
    rom:  Box<[u8]>,          // 32 KB, immutable after init
    xip:  Box<[u8]>,          // flash image, immutable after load
}
```

SRAM is word-granular atomics. ROM and XIP are plain byte slices —
immutable after construction, so no atomics needed (shared `&[u8]`
is `Send + Sync`).

### Constants

```rust
const SRAM_BASE: u32 = 0x2000_0000;
const SRAM_SIZE: u32 = 520 * 1024;          // 520 KB
const SRAM_WORDS: usize = 520 * 1024 / 4;  // 130_000
const ROM_BASE: u32  = 0x0000_0000;
const ROM_SIZE: u32  = 32 * 1024;
const XIP_BASE: u32  = 0x1000_0000;
```

### Constructor

```rust
impl SharedMemory {
    pub fn new() -> Self {
        let mut sram = Vec::with_capacity(SRAM_WORDS);
        for _ in 0..SRAM_WORDS { sram.push(AtomicU32::new(0)); }
        Self {
            sram: sram.into_boxed_slice(),
            rom: vec![0u8; ROM_SIZE as usize].into_boxed_slice(),
            xip: Box::new([]),
        }
    }

    /// Initialize from existing Memory (for Phase 3 from_emulator).
    pub fn from_parts(rom: Vec<u8>, sram: &[u8], xip: Vec<u8>) -> Self {
        assert_eq!(sram.len(), SRAM_SIZE as usize);
        let mut words = Vec::with_capacity(SRAM_WORDS);
        for chunk in sram.chunks_exact(4) {
            let word = u32::from_le_bytes([chunk[0], chunk[1], chunk[2], chunk[3]]);
            words.push(AtomicU32::new(word));
        }
        Self {
            sram: words.into_boxed_slice(),
            rom: rom.into_boxed_slice(),
            xip: xip.into_boxed_slice(),
        }
    }
}
```

### Address helpers

```rust
fn sram_idx(&self, addr: u32) -> Option<usize> {
    if addr >= SRAM_BASE && addr < SRAM_BASE + SRAM_SIZE {
        Some(((addr - SRAM_BASE) / 4) as usize)
    } else { None }
}
```

### Read methods

```rust
pub fn read32(&self, addr: u32) -> u32 {
    if let Some(idx) = self.sram_idx(addr & !3) {
        self.sram[idx].load(Relaxed)
    } else if addr < ROM_BASE + ROM_SIZE {
        self.read_rom32(addr)
    } else if addr >= XIP_BASE && ((addr - XIP_BASE) as usize) < self.xip.len() {
        self.read_xip32(addr)
    } else {
        0
    }
}

pub fn read16(&self, addr: u32) -> u16 {
    let word = self.read32(addr & !3);
    if addr & 2 != 0 { (word >> 16) as u16 } else { word as u16 }
}

pub fn read8(&self, addr: u32) -> u8 {
    if let Some(idx) = self.sram_idx(addr & !3) {
        let word = self.sram[idx].load(Relaxed);
        (word >> ((addr & 3) * 8)) as u8
    } else if addr < ROM_BASE + ROM_SIZE {
        self.rom[addr as usize]
    } else if addr >= XIP_BASE {
        let off = (addr - XIP_BASE) as usize;
        if off < self.xip.len() { self.xip[off] } else { 0 }
    } else {
        0
    }
}
```

ROM/XIP read32 helpers assemble 4 bytes little-endian from the byte
slice. Straightforward; no atomics.

### Write methods

```rust
pub fn write32(&self, addr: u32, val: u32) {
    if let Some(idx) = self.sram_idx(addr & !3) {
        self.sram[idx].store(val, Relaxed);
    }
    // ROM/XIP writes are silently dropped (immutable)
}

pub fn write16(&self, addr: u32, val: u16) {
    if let Some(idx) = self.sram_idx(addr & !3) {
        let shift = (addr & 2) * 8;
        let mask = 0xFFFFu32 << shift;
        let bits = (val as u32) << shift;
        loop {
            let old = self.sram[idx].load(Relaxed);
            let new = (old & !mask) | bits;
            if self.sram[idx].compare_exchange_weak(
                old, new, Relaxed, Relaxed
            ).is_ok() { break; }
        }
    }
}

pub fn write8(&self, addr: u32, val: u8) {
    if let Some(idx) = self.sram_idx(addr & !3) {
        let shift = (addr & 3) * 8;
        let mask = 0xFFu32 << shift;
        let bits = (val as u32) << shift;
        loop {
            let old = self.sram[idx].load(Relaxed);
            let new = (old & !mask) | bits;
            if self.sram[idx].compare_exchange_weak(
                old, new, Relaxed, Relaxed
            ).is_ok() { break; }
        }
    }
}
```

**Ordering rationale:** Relaxed on all SRAM ops. On x86 (our only
target), `compare_exchange` compiles to `lock cmpxchg` which is
already fully ordered. Using Relaxed avoids unnecessary fences on
hypothetical future targets without affecting correctness on x86.

### CAS (for STREX)

```rust
/// Compare-and-swap for STREX. Returns true on success.
pub fn cas32(&self, addr: u32, expected: u32, new: u32) -> bool {
    if let Some(idx) = self.sram_idx(addr & !3) {
        self.sram[idx].compare_exchange(
            expected, new, Relaxed, Relaxed
        ).is_ok()
    } else {
        false
    }
}
```

Uses strong `compare_exchange` (not weak) — STREX must not spuriously
fail at the memory level. ARM spurious failure comes from the monitor
invalidation path, not from CAS retry.

### ROM/XIP loaders

```rust
pub fn load_rom(&mut self, data: &[u8]) {
    let len = data.len().min(self.rom.len());
    self.rom[..len].copy_from_slice(&data[..len]);
}

pub fn load_xip(&mut self, data: &[u8]) {
    self.xip = data.to_vec().into_boxed_slice();
}
```

Called before threads are spawned. `&mut self` ensures exclusive
access during loading.

## 2. AtomicGpio

### Struct

```rust
pub struct AtomicGpio {
    out: [AtomicU32; 2],   // pins 0–31, 32–47
    oe:  [AtomicU32; 2],   // output enable
}
```

RP2354 has 48 GPIO pins across two banks. The current SIO only models
bank 0 (pins 0-31); bank 1 will be zero until GPIO_HI is implemented.

### Methods

```rust
impl AtomicGpio {
    pub fn new() -> Self {
        Self {
            out: [AtomicU32::new(0), AtomicU32::new(0)],
            oe:  [AtomicU32::new(0), AtomicU32::new(0)],
        }
    }

    // --- OUT ---
    pub fn read_out(&self, bank: usize) -> u32 {
        self.out[bank].load(Relaxed)
    }
    pub fn write_out(&self, bank: usize, val: u32) {
        self.out[bank].store(val, Relaxed);
    }
    pub fn set_out(&self, bank: usize, mask: u32) {
        self.out[bank].fetch_or(mask, Relaxed);
    }
    pub fn clear_out(&self, bank: usize, mask: u32) {
        self.out[bank].fetch_and(!mask, Relaxed);
    }
    pub fn xor_out(&self, bank: usize, mask: u32) {
        self.out[bank].fetch_xor(mask, Relaxed);
    }

    // --- OE ---
    pub fn read_oe(&self, bank: usize) -> u32 {
        self.oe[bank].load(Relaxed)
    }
    pub fn write_oe(&self, bank: usize, val: u32) {
        self.oe[bank].store(val, Relaxed);
    }
    pub fn set_oe(&self, bank: usize, mask: u32) {
        self.oe[bank].fetch_or(mask, Relaxed);
    }
    pub fn clear_oe(&self, bank: usize, mask: u32) {
        self.oe[bank].fetch_and(!mask, Relaxed);
    }
    pub fn xor_oe(&self, bank: usize, mask: u32) {
        self.oe[bank].fetch_xor(mask, Relaxed);
    }

    // --- Pin-level ---
    pub fn read_pin(&self, pin: u32) -> bool {
        let bank = (pin / 32) as usize;
        let bit = pin % 32;
        self.out[bank].load(Relaxed) & (1 << bit) != 0
    }
}
```

All Relaxed — same rationale as SharedMemory. On x86, `fetch_or`
etc. compile to `lock or` which is already ordered.

The SET/CLR/XOR pattern mirrors the RP2350 SIO GPIO register layout
(SET = base+0x08, CLR = base+0x10, XOR = base+0x18).

## 3. ExclusiveMonitors

### Design

Two-level scheme:

- **Local state** (on CortexM33, already exists from Phase 0b.2):
  `exclusive_address: Option<u32>` — the per-core address tag.

- **Shared monitors** (new): `[AtomicU64; 2]` encoding
  `(address << 1) | valid_bit`. Cross-thread visible for snooping.

The local state is the fast path — the owning core checks its own
`exclusive_address` without any atomic load. The shared monitor
exists solely so that a writing core can invalidate a peer's
reservation without touching the peer's `CortexM33` fields.

### Encoding

Bit 0: valid flag. Bits 1-31: word-aligned address >> 1 (fits 31
bits, enough for 4 GB address space). Bit 32+: unused.

```rust
const VALID: u64 = 1;

fn encode(addr: u32) -> u64 {
    ((addr as u64) & !1) | VALID
}
fn decode(val: u64) -> Option<u32> {
    if val & VALID != 0 { Some((val & !1) as u32) } else { None }
}
```

### Struct

```rust
pub struct ExclusiveMonitors {
    monitors: [AtomicU64; 2],
}

impl ExclusiveMonitors {
    pub fn new() -> Self {
        Self { monitors: [AtomicU64::new(0), AtomicU64::new(0)] }
    }

    /// Mark a reservation (called alongside local exclusive_address set).
    pub fn set(&self, core: usize, addr: u32) {
        self.monitors[core].store(encode(addr), Relaxed);
    }

    /// Clear a reservation (CLREX, exception entry/exit, STREX).
    pub fn clear(&self, core: usize) {
        self.monitors[core].store(0, Relaxed);
    }

    /// Check if a reservation is still valid for this address.
    pub fn check(&self, core: usize, addr: u32) -> bool {
        self.monitors[core].load(Relaxed) == encode(addr)
    }

    /// Snoop: invalidate any monitor matching this word address.
    /// Called on every SRAM write.
    pub fn snoop(&self, addr: u32) {
        let tag = encode(addr);
        for m in &self.monitors {
            let _ = m.compare_exchange(tag, 0, Relaxed, Relaxed);
        }
    }
}
```

### STREX protocol (threaded, Phase 3 integration)

```
LDREX:
  val = shared_memory.read32(addr)
  core.exclusive_address = Some(addr)
  core.exclusive_value = val           // NEW field, added in Phase 3
  monitors.set(core_id, addr)
  rX = val

STREX:
  if !monitors.check(core_id, addr):
    rZ = 1                             // peer snooped
  elif shared_memory.cas32(addr, core.exclusive_value, rX):
    rZ = 0
    monitors.snoop(addr)               // invalidate all
  else:
    rZ = 1                             // CAS lost
  monitors.clear(core_id)
  core.exclusive_address = None

CLREX / exception entry / exception exit:
  monitors.clear(core_id)
  core.exclusive_address = None
```

`exclusive_value: u32` will be added to CortexM33 in Phase 3 when
the STREX path is rewired from address-only to CAS. Phase 1 does not
modify CortexM33.

### Snoop cost

`snoop()` is called on every SRAM write. Cost: two `compare_exchange`
(one per core), each ~5 ns on x86. With 2 writes per instruction on
average, this adds ~10 ns per instruction — ~7% overhead at the
current 143 MHz single-core rate. Acceptable.

**Optimization (deferred):** Only snoop when at least one monitor is
valid. Add `fn any_valid(&self) -> bool` using a shared dirty flag.
Not worth the complexity unless profiling shows snoop is a bottleneck.

## Testing

### SharedMemory tests

1. `read32_write32_roundtrip` — write + read at various SRAM addresses
2. `read16_write16` — sub-word read/write, verify containing word
3. `read8_write8` — byte-level, all 4 offsets within a word
4. `write16_preserves_other_half` — write to low half, verify high
5. `write8_preserves_other_bytes` — write one byte, verify other 3
6. `cas32_success` — CAS with matching expected value
7. `cas32_failure` — CAS with wrong expected value
8. `rom_read_only` — write to ROM address, verify no change
9. `xip_read_only` — write to XIP address, verify no change
10. `out_of_range_returns_zero` — read unmapped address
11. `from_parts_roundtrip` — init from byte slice, verify reads
12. `concurrent_write16_no_tearing` — 2 threads writing different
    halves of same word, verify no torn values after N iterations

### AtomicGpio tests

1. `read_write_roundtrip` — write + read on both banks
2. `set_clear_xor` — verify SET/CLR/XOR semantics
3. `read_pin` — verify single-pin read across bank boundary
4. `concurrent_xor` — 2 threads toggling different pins, verify no
   interference

### ExclusiveMonitors tests

1. `set_check_clear` — basic lifecycle
2. `snoop_invalidates` — set core 0, snoop addr, check returns false
3. `snoop_wrong_addr_no_effect` — snoop different addr, check still valid
4. `snoop_clears_both_cores` — both cores set same addr, snoop clears both
5. `clear_is_independent` — clear core 0 doesn't affect core 1
6. `concurrent_set_snoop` — 2 threads: one sets, one snoops, no crash

## What this phase does NOT do

- Does not touch `Bus`, `Emulator`, `CortexM33`, or `SIO`.
- Does not add `exclusive_value` to CortexM33 (Phase 3).
- Does not add `rtrb` dependency (Phase 2).
- Does not create `WorkerBus` or `SharedState` (Phase 3).
- Does not modify the single-threaded execution path.
