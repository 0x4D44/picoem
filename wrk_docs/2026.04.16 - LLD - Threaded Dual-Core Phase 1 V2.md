# Threaded Dual-Core Phase 1 — Low-Level Design

Version: 2.0.0
Date: 2026-04-16
Parent HLD: 2026.04.16 - HLD - Threaded Dual-Core Emulation V5.md
Changes from V1: SRAM alias support, strong CAS, word-aligned monitor
encoding, any_valid() snoop fast path, cut from_parts/concurrent tests,
document x86-TSO assumption and snoop-as-caller-responsibility.

## Scope

Three standalone types that Phase 3 will compose into `SharedState`:

1. **SharedMemory** — SRAM as `Box<[AtomicU32]>`, immutable ROM/XIP
2. **AtomicGpio** — atomic pin out/oe state
3. **ExclusiveMonitors** — per-core monitors with cross-thread snoop

All live in `crates/mdrp2350/src/threaded/`. No integration into
`Bus` or `Emulator` — that's Phase 3. Unit tests for every access
pattern.

### Platform assumption

All atomic orderings in this design target **x86-64 TSO**. On x86,
`Relaxed` loads/stores compile to plain `mov`; `compare_exchange`
compiles to `lock cmpxchg` (fully ordered regardless of Rust
ordering parameter). Any future port to a weaker memory model (ARM)
would require upgrading orderings to Acquire/Release. This matches
HLD §Host assumptions: `target_arch = "x86_64"`.

## 1. SharedMemory

### Struct

```rust
use std::sync::atomic::{AtomicU32, Ordering::Relaxed};

pub struct SharedMemory {
    sram: Box<[AtomicU32]>,   // 130_000 words = 520 KB
    rom:  Box<[u8]>,          // 32 KB, immutable after init
    xip:  Box<[u8]>,          // flash image, immutable after load
}
```

SRAM is word-granular atomics. ROM and XIP are plain byte slices —
immutable after construction, so no atomics needed.

### Constants

```rust
const SRAM_BASE: u32 = 0x2000_0000;
const SRAM_SIZE: u32 = 520 * 1024;
const SRAM_WORDS: usize = (520 * 1024) / 4;  // 130_000
const ROM_BASE: u32  = 0x0000_0000;
const ROM_SIZE: u32  = 32 * 1024;
const XIP_BASE: u32  = 0x1000_0000;
```

### Constructor

```rust
impl SharedMemory {
    pub fn new() -> Self {
        let mut sram = Vec::with_capacity(SRAM_WORDS);
        for _ in 0..SRAM_WORDS { sram.push(AtomicU32::new(0)); }
        Self {
            sram: sram.into_boxed_slice(),
            rom: vec![0u8; ROM_SIZE as usize].into_boxed_slice(),
            xip: Box::new([]),
        }
    }
}
```

**No `from_parts` constructor.** Phase 3 will add a conversion path
from `Memory` → `SharedMemory` when `from_emulator` is implemented.
That phase will also add a `pub fn sram_bytes(&self) -> &[u8]`
accessor to `Memory` in mdpicoem-common.

### Address helpers

```rust
/// Convert a bus address to a SRAM word index.
/// Strips SRAM alias bits [27:24] per RP2350 memory map.
fn sram_idx(addr: u32) -> Option<usize> {
    let region = addr >> 28;
    if region == 0x2 {
        let offset = addr & 0x00FF_FFFF;  // strip alias bits
        if offset < SRAM_SIZE {
            Some((offset / 4) as usize)
        } else { None }
    } else { None }
}

/// Extract the SRAM alias mode from bits [27:24].
/// 0 = plain, 1 = XOR, 2 = SET (OR), 3 = CLR (AND-NOT).
fn sram_alias(addr: u32) -> u8 {
    ((addr >> 24) & 0x3) as u8
}
```

### Read methods

Reads always return the plain value regardless of alias bits
(alias only affects writes).

```rust
pub fn read32(&self, addr: u32) -> u32 {
    if let Some(idx) = Self::sram_idx(addr) {
        self.sram[idx].load(Relaxed)
    } else if addr < ROM_BASE + ROM_SIZE {
        self.read_rom32(addr)
    } else if addr >= XIP_BASE
           && ((addr - XIP_BASE) as usize) < self.xip.len() {
        self.read_xip32(addr)
    } else {
        0
    }
}

pub fn read16(&self, addr: u32) -> u16 {
    let word = self.read32(addr & !2);
    if addr & 2 != 0 { (word >> 16) as u16 } else { word as u16 }
}

pub fn read8(&self, addr: u32) -> u8 {
    if let Some(idx) = Self::sram_idx(addr) {
        let word = self.sram[idx].load(Relaxed);
        (word >> ((addr & 3) * 8)) as u8
    } else if addr < ROM_BASE + ROM_SIZE {
        self.rom[addr as usize]
    } else if addr >= XIP_BASE {
        let off = (addr - XIP_BASE) as usize;
        if off < self.xip.len() { self.xip[off] } else { 0 }
    } else {
        0
    }
}
```

ROM/XIP `read32` helpers assemble 4 bytes little-endian from the
byte slice. Straightforward; no atomics.

### Write methods

```rust
pub fn write32(&self, addr: u32, val: u32) {
    if let Some(idx) = Self::sram_idx(addr) {
        match Self::sram_alias(addr) {
            0 => self.sram[idx].store(val, Relaxed),
            1 => { self.sram[idx].fetch_xor(val, Relaxed); }
            2 => { self.sram[idx].fetch_or(val, Relaxed); }
            3 => { self.sram[idx].fetch_and(!val, Relaxed); }
            _ => unreachable!(),
        }
    }
    // ROM/XIP writes silently dropped (immutable)
}

pub fn write16(&self, addr: u32, val: u16) {
    if let Some(idx) = Self::sram_idx(addr) {
        // Alias writes at 16-bit width: apply alias to the
        // affected halfword, preserve the other half.
        let shift = (addr & 2) * 8;
        let mask = 0xFFFFu32 << shift;
        let bits = (val as u32) << shift;
        let alias = Self::sram_alias(addr);
        loop {
            let old = self.sram[idx].load(Relaxed);
            let half = match alias {
                0 => bits,
                1 => (old ^ bits) & mask,
                2 => (old | bits) & mask,
                3 => (old & !(bits)) & mask,
                _ => unreachable!(),
            };
            let new = (old & !mask) | half;
            if self.sram[idx].compare_exchange(
                old, new, Relaxed, Relaxed
            ).is_ok() { break; }
        }
    }
}

pub fn write8(&self, addr: u32, val: u8) {
    if let Some(idx) = Self::sram_idx(addr) {
        let shift = (addr & 3) * 8;
        let mask = 0xFFu32 << shift;
        let bits = (val as u32) << shift;
        let alias = Self::sram_alias(addr);
        loop {
            let old = self.sram[idx].load(Relaxed);
            let byte_val = match alias {
                0 => bits,
                1 => (old ^ bits) & mask,
                2 => (old | bits) & mask,
                3 => (old & !(bits)) & mask,
                _ => unreachable!(),
            };
            let new = (old & !mask) | byte_val;
            if self.sram[idx].compare_exchange(
                old, new, Relaxed, Relaxed
            ).is_ok() { break; }
        }
    }
}
```

**Strong CAS** (`compare_exchange`, not `_weak`) in all CAS loops.
On x86 both compile to `lock cmpxchg`. Strong CAS avoids spurious
retry on non-x86 targets if we ever build there.

**Alias handling:** The RP2350 SRAM has 4 aliases at bits [27:24]:
- 0x2000_xxxx = plain write
- 0x2100_xxxx = XOR (read-modify-write)
- 0x2200_xxxx = SET (OR)
- 0x2300_xxxx = CLR (AND-NOT)

For 32-bit writes, XOR/SET/CLR use dedicated atomic RMW ops
(`fetch_xor`/`fetch_or`/`fetch_and`) — no CAS needed.

For 16/8-bit writes, the alias is applied only to the targeted
bytes; the rest of the word is preserved via CAS.

**Snoop responsibility:** SharedMemory does NOT call
`ExclusiveMonitors::snoop()`. The caller (Phase 3's WorkerBus) is
responsible for calling `monitors.snoop(addr)` after every SRAM
write. This keeps SharedMemory and ExclusiveMonitors decoupled.

### CAS (for STREX)

```rust
/// Compare-and-swap for STREX. Returns true on success.
/// Always targets the plain alias (alias bits ignored).
pub fn cas32(&self, addr: u32, expected: u32, new: u32) -> bool {
    if let Some(idx) = Self::sram_idx(addr) {
        self.sram[idx].compare_exchange(
            expected, new, Relaxed, Relaxed
        ).is_ok()
    } else {
        false
    }
}
```

Strong `compare_exchange`. ARM spurious failure comes from monitor
invalidation, not from the memory CAS.

### ROM/XIP loaders

```rust
pub fn load_rom(&mut self, data: &[u8]) {
    let len = data.len().min(self.rom.len());
    self.rom[..len].copy_from_slice(&data[..len]);
}

pub fn load_xip(&mut self, data: &[u8]) {
    self.xip = data.to_vec().into_boxed_slice();
}
```

Both take `&mut self` — must be called before wrapping in `Arc`.
After Arc wrapping, ROM and XIP are immutable. SRAM writes use
`write32/16/8(&self)` which works through `Arc<SharedMemory>`.

## 2. AtomicGpio

### Struct

```rust
pub struct AtomicGpio {
    out: [AtomicU32; 2],   // pins 0–31, 32–47
    oe:  [AtomicU32; 2],   // output enable
}
```

RP2354 has 48 GPIO pins across two banks. Bank 1 (pins 32-47) is
currently unused by the SIO (which only models bank 0). The struct
allocates both for HLD compliance; Phase 1 tests only exercise
bank 0.

### Methods

```rust
impl AtomicGpio {
    pub fn new() -> Self {
        Self {
            out: [AtomicU32::new(0), AtomicU32::new(0)],
            oe:  [AtomicU32::new(0), AtomicU32::new(0)],
        }
    }

    // --- OUT ---
    pub fn read_out(&self, bank: usize) -> u32 {
        self.out[bank].load(Relaxed)
    }
    pub fn write_out(&self, bank: usize, val: u32) {
        self.out[bank].store(val, Relaxed);
    }
    pub fn set_out(&self, bank: usize, mask: u32) {
        self.out[bank].fetch_or(mask, Relaxed);
    }
    pub fn clear_out(&self, bank: usize, mask: u32) {
        self.out[bank].fetch_and(!mask, Relaxed);
    }
    pub fn xor_out(&self, bank: usize, mask: u32) {
        self.out[bank].fetch_xor(mask, Relaxed);
    }

    // --- OE ---
    pub fn read_oe(&self, bank: usize) -> u32 {
        self.oe[bank].load(Relaxed)
    }
    pub fn write_oe(&self, bank: usize, val: u32) {
        self.oe[bank].store(val, Relaxed);
    }
    pub fn set_oe(&self, bank: usize, mask: u32) {
        self.oe[bank].fetch_or(mask, Relaxed);
    }
    pub fn clear_oe(&self, bank: usize, mask: u32) {
        self.oe[bank].fetch_and(!mask, Relaxed);
    }
    pub fn xor_oe(&self, bank: usize, mask: u32) {
        self.oe[bank].fetch_xor(mask, Relaxed);
    }

    // --- Pin-level ---
    pub fn read_pin(&self, pin: u32) -> bool {
        let bank = (pin / 32) as usize;
        let bit = pin % 32;
        self.out[bank].load(Relaxed) & (1 << bit) != 0
    }
}
```

The SET/CLR/XOR pattern mirrors the RP2350 SIO GPIO register layout
(SET = base+0x08, CLR = base+0x10, XOR = base+0x18).

## 3. ExclusiveMonitors

### Design

Two-level scheme:

- **Local state** (on CortexM33, already exists from Phase 0b.2):
  `exclusive_address: Option<u32>` — fast-path check on owning core.

- **Shared monitors** (new): `[AtomicU64; 2]` — cross-thread visible
  for snooping. The only reason this struct exists is so a writing
  core can invalidate a peer's reservation without touching the
  peer's `CortexM33` fields.

### Encoding

Bit 0: valid flag. Bits 2-31: word-aligned address (bits 2+ of the
original address). Bit 1: unused (always 0).

```rust
const VALID: u64 = 1;

fn encode(addr: u32) -> u64 {
    ((addr & !3) as u64) | VALID
}
```

Normalizing to `addr & !3` ensures that LDREX to different byte
offsets within the same word produce the same monitor tag. This
matches ARM exclusive monitor architecture (word granularity).

No `decode()` — unused in Phase 1. Add in Phase 3 if needed.

### Struct

```rust
pub struct ExclusiveMonitors {
    monitors: [AtomicU64; 2],
}

impl ExclusiveMonitors {
    pub fn new() -> Self {
        Self { monitors: [AtomicU64::new(0), AtomicU64::new(0)] }
    }

    /// Mark a reservation.
    pub fn set(&self, core: usize, addr: u32) {
        self.monitors[core].store(encode(addr), Relaxed);
    }

    /// Clear a reservation (CLREX, exception entry/exit, STREX).
    pub fn clear(&self, core: usize) {
        self.monitors[core].store(0, Relaxed);
    }

    /// Check if a reservation is still valid for this address.
    pub fn check(&self, core: usize, addr: u32) -> bool {
        self.monitors[core].load(Relaxed) == encode(addr)
    }

    /// Returns true if any core has an active reservation.
    fn any_valid(&self) -> bool {
        self.monitors[0].load(Relaxed) & VALID != 0
        || self.monitors[1].load(Relaxed) & VALID != 0
    }

    /// Snoop: invalidate any monitor matching this word address.
    /// Called by the bus layer on every SRAM write.
    pub fn snoop(&self, addr: u32) {
        if !self.any_valid() { return; }
        let tag = encode(addr);
        for m in &self.monitors {
            let _ = m.compare_exchange(tag, 0, Relaxed, Relaxed);
        }
    }
}
```

**`any_valid()` fast path:** Two Relaxed loads (plain `mov` on x86).
Skips the two `compare_exchange` calls (~10 ns each) when no monitor
is active — the common case. Reduces snoop overhead by ~90% for
non-exclusive workloads.

### STREX protocol (Phase 3 integration)

Phase 3 will add `exclusive_value: u32` to CortexM33 and rewire
STREX to use CAS:

```
LDREX:
  val = shared_memory.read32(addr)
  core.exclusive_address = Some(addr)
  core.exclusive_value = val
  monitors.set(core_id, addr)

STREX:
  if !monitors.check(core_id, addr):
    rd = 1                              // peer snooped
  elif shared_memory.cas32(addr, core.exclusive_value, new_val):
    rd = 0
    monitors.snoop(addr)
  else:
    rd = 1                              // CAS lost
  monitors.clear(core_id)
  core.exclusive_address = None

CLREX / exception entry / exception exit:
  monitors.clear(core_id)
  core.exclusive_address = None
```

### Known Phase 3 concern: snoop/set race

In threaded mode, `snoop(addr)` and `set(core, addr)` can race:
core 0 calls snoop while core 1 is setting a monitor on the same
address. The snoop's CAS could clear a just-set monitor. This does
not occur in the serial interleaver (cores are sequential within
quanta). Phase 3 must add synchronization — either a per-monitor
seqlock or by constraining set() to only occur within the owning
core's quantum (which the barrier protocol already ensures, since
LDREX only runs during execution phases, not during coordinator
snooping). Document and verify in Phase 3.

## Testing

### SharedMemory tests

1. `read32_write32_roundtrip` — write + read at various SRAM addrs
2. `read16_write16` — sub-word read/write, both halfword positions
3. `read8_write8` — byte-level, all 4 offsets within a word
4. `write16_preserves_other_half` — write low half, verify high
5. `write8_preserves_other_bytes` — write one byte, verify other 3
6. `alias_xor` — write via 0x21xx_xxxx, verify XOR applied
7. `alias_set` — write via 0x22xx_xxxx, verify OR applied
8. `alias_clr` — write via 0x23xx_xxxx, verify AND-NOT applied
9. `alias_write16_xor` — sub-word alias XOR preserves other half
10. `cas32_success` — CAS with matching expected value
11. `cas32_failure` — CAS with wrong expected value
12. `rom_read_only` — write to ROM address, verify no change
13. `xip_read_only` — write to XIP address, verify no change
14. `out_of_range_returns_zero` — read unmapped address
15. `sram_alias_bits_stripped` — same word via 0x20xx and 0x21xx
    maps to same underlying storage

### AtomicGpio tests

1. `read_write_roundtrip` — write + read on bank 0
2. `set_clear_xor` — verify SET/CLR/XOR semantics
3. `read_pin` — verify single-pin read

### ExclusiveMonitors tests

1. `set_check_clear` — basic lifecycle
2. `snoop_invalidates` — set core 0, snoop addr, check → false
3. `snoop_wrong_addr_no_effect` — snoop different addr, still valid
4. `snoop_clears_both_cores` — both set same addr, snoop clears both
5. `clear_is_independent` — clear core 0 doesn't affect core 1
6. `any_valid_fast_path` — no monitors → snoop returns immediately
7. `word_aligned_encoding` — LDREX to addr and addr+1 produce same
   monitor tag (both within same word)

## What this phase does NOT do

- Does not touch `Bus`, `Emulator`, `CortexM33`, or `SIO`.
- Does not add `exclusive_value` to CortexM33 (Phase 3).
- Does not add `rtrb` dependency (Phase 2).
- Does not create `WorkerBus` or `SharedState` (Phase 3).
- Does not modify the single-threaded execution path.
- Does not add `from_parts` conversion (Phase 3).
- Does not include concurrent stress tests (Phase 2 Loom).
