# Threaded Dual-Core Phase 2 — Low-Level Design

Version: 1.0.0
Date: 2026-04-16
Parent HLD: 2026.04.16 - HLD - Threaded Dual-Core Emulation V5.md

## Scope

Four types that Phase 3 will compose into the 4-thread topology:

1. **SpscQueue** — generic lock-free SPSC ring buffer (no external deps)
2. **SpinBarrier** — 4-way flat barrier (promoted from Phase 0c prototype)
3. **ThreadedSio** — inter-core FIFOs, spinlocks, doorbells, MTIME
4. **ThreadedPio** — per-SM TX/RX FIFOs, atomic control, command queue

All live in `crates/mdrp2350/src/threaded/`. No integration into
`Bus` or `Emulator` — that's Phase 3. No external dependencies added.
Concurrent correctness verified via std::thread tests; formal
verification (Loom/TSan) deferred to Phase 3.

### Platform assumption

Same as Phase 1: x86-64 TSO. Relaxed atomics on x86 compile to plain
`mov` / `lock cmpxchg`.

## 1. SpscQueue

Lock-free single-producer single-consumer ring buffer. Used by both
ThreadedSio (capacity 8) and ThreadedPio (capacity 4 or 8).

### Why not rtrb

The HLD suggests `rtrb` as the sole new dependency. Phase 0c showed
capacity-8 SPSC queues are pathologically slow under tight spinning,
but that doesn't apply here — SIO/PIO FIFO push/pop are non-blocking
`try_push`/`try_pop` (fail immediately when full/empty, no spinning).
A hand-rolled queue is ~60 lines, avoids an external dep, and matches
the exact semantics we need. No reason to pull in a crate.

### Struct

```rust
use std::sync::atomic::{AtomicU32, Ordering};

pub struct SpscQueue {
    buffer: Box<[AtomicU32]>,
    head: AtomicU32,           // next write position (producer owns)
    tail: AtomicU32,           // next read position (consumer owns)
    capacity: u32,             // power of 2
    mask: u32,                 // capacity - 1
}
```

Using `AtomicU32` for buffer elements avoids `UnsafeCell` and makes
the struct automatically `Send + Sync`. The Acquire/Release edges on
head/tail provide the happens-before relationship that makes the
Relaxed buffer access safe.

### Constructor

```rust
impl SpscQueue {
    pub fn new(capacity: u32) -> Self {
        assert!(capacity.is_power_of_two() && capacity >= 2);
        let mut buf = Vec::with_capacity(capacity as usize);
        for _ in 0..capacity { buf.push(AtomicU32::new(0)); }
        Self {
            buffer: buf.into_boxed_slice(),
            head: AtomicU32::new(0),
            tail: AtomicU32::new(0),
            capacity,
            mask: capacity - 1,
        }
    }
}
```

### Operations

```rust
/// Push a value. Returns true on success, false if full.
pub fn try_push(&self, val: u32) -> bool {
    let head = self.head.load(Ordering::Relaxed);
    let tail = self.tail.load(Ordering::Acquire);
    if head.wrapping_sub(tail) >= self.capacity {
        return false;                         // full
    }
    self.buffer[(head & self.mask) as usize]
        .store(val, Ordering::Relaxed);
    self.head.store(head.wrapping_add(1), Ordering::Release);
    true
}

/// Pop a value. Returns None if empty.
pub fn try_pop(&self) -> Option<u32> {
    let tail = self.tail.load(Ordering::Relaxed);
    let head = self.head.load(Ordering::Acquire);
    if tail == head {
        return None;                          // empty
    }
    let val = self.buffer[(tail & self.mask) as usize]
        .load(Ordering::Relaxed);
    self.tail.store(tail.wrapping_add(1), Ordering::Release);
    Some(val)
}

/// Current number of items in the queue.
pub fn len(&self) -> u32 {
    let head = self.head.load(Ordering::Relaxed);
    let tail = self.tail.load(Ordering::Relaxed);
    head.wrapping_sub(tail)
}

pub fn is_empty(&self) -> bool { self.len() == 0 }
pub fn is_full(&self) -> bool { self.len() >= self.capacity }

/// Drain all items, discarding them. Used for FIFO flush.
pub fn clear(&self) {
    while self.try_pop().is_some() {}
}
```

**Ordering rationale:**
- Producer: load own `head` (Relaxed — only this thread writes it),
  load peer's `tail` (Acquire — see consumer's last Release), write
  buffer (Relaxed — protected by head Release), Release-store `head`.
- Consumer: mirror with tail/head swapped.
- `len()`: Relaxed on both — approximate count for status, not a
  synchronization barrier.

### No cache padding

Head and tail are on the same cache line. This is fine for
non-blocking try_push/try_pop (no spin loops). The false-sharing cost
is one extra cache miss per check when the peer recently wrote. If
Phase 5 benchmarks show this matters, add `#[repr(align(64))]`
wrappers.

## 2. SpinBarrier

4-way flat barrier for synchronizing the 4 worker threads between
execution and coordinator phases. Promoted from the Phase 0c
prototype (`threading_micro.rs`).

### Struct

```rust
use std::sync::atomic::{AtomicU32, AtomicBool, Ordering::*};

pub struct SpinBarrier {
    generation: AtomicU32,
    count: AtomicU32,
    parties: u32,               // = 4
    poisoned: AtomicBool,
}

pub enum BarrierResult {
    Released,
    Poisoned,
}
```

### Implementation

```rust
impl SpinBarrier {
    pub fn new(parties: u32) -> Self {
        assert!(parties >= 2);
        Self {
            generation: AtomicU32::new(0),
            count: AtomicU32::new(0),
            parties,
            poisoned: AtomicBool::new(false),
        }
    }

    pub fn wait(&self) -> BarrierResult {
        if self.poisoned.load(Acquire) {
            return BarrierResult::Poisoned;
        }
        let gen = self.generation.load(Acquire);
        let n = self.count.fetch_add(1, AcqRel) + 1;
        if n == self.parties {
            self.count.store(0, Relaxed);
            self.generation.store(gen.wrapping_add(1), Release);
        } else {
            loop {
                if self.poisoned.load(Acquire) {
                    return BarrierResult::Poisoned;
                }
                if self.generation.load(Acquire) != gen {
                    break;
                }
                std::hint::spin_loop();
            }
        }
        BarrierResult::Released
    }

    pub fn poison(&self) {
        self.poisoned.store(true, Release);
    }
}
```

Identical to HLD §SpinBarrier spec. Phase 0c measured ~425 ns mean
round-trip for 4-way, well within the <500 ns threshold.

## 3. ThreadedSio

Shared SIO state for threaded dual-core execution. Contains only
cross-core and coordinator-visible fields. Per-core state (divider,
interpolator) stays on the per-core bus view (Phase 3's WorkerBus).

### Struct

```rust
pub struct ThreadedSio {
    // Inter-core FIFOs (each SPSC, capacity 8, matching hardware)
    fifo_0to1: SpscQueue,       // core 0 produces, core 1 consumes
    fifo_1to0: SpscQueue,       // core 1 produces, core 0 consumes

    // Sticky FIFO status bits per core [ROE, WOF]
    fifo_roe: [AtomicBool; 2],  // read-overflow-error (pop from empty)
    fifo_wof: [AtomicBool; 2],  // write-overflow-fifo (push to full)

    // Spinlocks: 32 test-and-set locks
    spinlocks: [AtomicU32; 32],

    // Doorbells: 4-bit pending field per core
    doorbells: [AtomicU32; 2],

    // Machine timer
    mtime: AtomicU64,
    mtime_ctrl: AtomicU32,      // bit 0 = enable
    mtimecmp: [AtomicU64; 2],   // per-core compare
}
```

### Methods

```rust
impl ThreadedSio {
    pub fn new() -> Self { /* all zero-initialized */ }

    // --- FIFO ---

    /// Push to the FIFO that the given core writes to.
    /// Core 0 writes → fifo_0to1. Core 1 writes → fifo_1to0.
    pub fn fifo_push(&self, writing_core: usize, val: u32) -> bool {
        let q = match writing_core {
            0 => &self.fifo_0to1,
            _ => &self.fifo_1to0,
        };
        if q.try_push(val) {
            true
        } else {
            self.fifo_wof[writing_core].store(true, Relaxed);
            false
        }
    }

    /// Pop from the FIFO that the given core reads from.
    /// Core 0 reads ← fifo_1to0. Core 1 reads ← fifo_0to1.
    pub fn fifo_pop(&self, reading_core: usize) -> Option<u32> {
        let q = match reading_core {
            0 => &self.fifo_1to0,
            _ => &self.fifo_0to1,
        };
        match q.try_pop() {
            Some(val) => Some(val),
            None => {
                self.fifo_roe[reading_core].store(true, Relaxed);
                None
            }
        }
    }

    /// Build FIFO_ST register value for the given core.
    /// Bit 0: VLD (data ready to read)
    /// Bit 1: RDY (room to write)
    /// Bit 2: WOF (sticky write-overflow)
    /// Bit 3: ROE (sticky read-overflow)
    pub fn fifo_st(&self, core: usize) -> u32 {
        let read_q = match core { 0 => &self.fifo_1to0, _ => &self.fifo_0to1 };
        let write_q = match core { 0 => &self.fifo_0to1, _ => &self.fifo_1to0 };
        let vld = if !read_q.is_empty() { 1 } else { 0 };
        let rdy = if !write_q.is_full() { 2 } else { 0 };
        let wof = if self.fifo_wof[core].load(Relaxed) { 4 } else { 0 };
        let roe = if self.fifo_roe[core].load(Relaxed) { 8 } else { 0 };
        vld | rdy | wof | roe
    }

    /// Clear sticky FIFO status bits (write-1-to-clear).
    pub fn fifo_st_clear(&self, core: usize, mask: u32) {
        if mask & 4 != 0 { self.fifo_wof[core].store(false, Relaxed); }
        if mask & 8 != 0 { self.fifo_roe[core].store(false, Relaxed); }
    }

    // --- Spinlocks ---

    /// Claim a spinlock. Returns bitmask on success, 0 if held.
    pub fn spinlock_claim(&self, id: usize) -> u32 {
        let mask = 1u32 << id;
        let prev = self.spinlocks[id].fetch_or(mask, Acquire);
        if prev & mask == 0 { mask } else { 0 }
    }

    /// Release a spinlock.
    pub fn spinlock_release(&self, id: usize) {
        self.spinlocks[id].store(0, Release);
    }

    /// Read raw spinlock state (for status register).
    pub fn spinlock_state(&self, id: usize) -> u32 {
        self.spinlocks[id].load(Relaxed)
    }

    // --- Doorbells ---

    pub fn doorbell_set(&self, core: usize, bits: u32) {
        self.doorbells[core].fetch_or(bits & 0xF, Relaxed);
    }

    pub fn doorbell_clear(&self, core: usize, bits: u32) {
        self.doorbells[core].fetch_and(!(bits & 0xF), Relaxed);
    }

    pub fn doorbell_read(&self, core: usize) -> u32 {
        self.doorbells[core].load(Relaxed) & 0xF
    }

    // --- MTIME ---

    pub fn mtime_read(&self) -> u64 {
        self.mtime.load(Relaxed)
    }

    pub fn mtime_advance(&self, cycles: u64) {
        if self.mtime_ctrl.load(Relaxed) & 1 != 0 {
            self.mtime.fetch_add(cycles, Relaxed);
        }
    }

    pub fn mtime_check_match(&self, core: usize) -> bool {
        let mt = self.mtime.load(Relaxed);
        let cmp = self.mtimecmp[core].load(Relaxed);
        mt >= cmp
    }
}
```

### What stays per-core (NOT in ThreadedSio)

- `divider: [Divider; 2]` — only accessed by owning core, no atomics
- `interp: [[u32; 32]; 2]` — only accessed by owning core, no atomics

These remain on Phase 3's `WorkerBus`, not in shared state.

## 4. ThreadedPio

Shared PIO state for threaded execution. The actual PioBlock
execution engine (SM stepping, instruction decode) stays on the PIO
worker thread — only the communication interfaces are shared.

### Constants

```rust
const PIO_BLOCKS: usize = 3;
const SMS_PER_BLOCK: usize = 4;
const PIO_FIFO_DEPTH: u32 = 4;     // 8 when joined
```

### Struct

```rust
pub struct ThreadedPio {
    // TX FIFOs: CPU pushes, PIO thread pops (per SM, per block)
    tx: [[SpscQueue; SMS_PER_BLOCK]; PIO_BLOCKS],

    // RX FIFOs: PIO thread pushes, CPU pops
    rx: [[SpscQueue; SMS_PER_BLOCK]; PIO_BLOCKS],

    // Atomic control (CPU writes, PIO thread reads)
    sm_enabled: [AtomicU8; PIO_BLOCKS],

    // IRQ flags (PIO writes, coordinator reads)
    irq_flags: [AtomicU8; PIO_BLOCKS],

    // DREQ signals (PIO writes, coordinator reads for DMA)
    dreq: [AtomicU8; PIO_BLOCKS],

    // Cold-path command queue (CPU → PIO thread)
    commands: std::sync::Mutex<Vec<PioCommand>>,
}
```

All SpscQueues initialized with `PIO_FIFO_DEPTH` (4). FIFO join
(depth 8) handled by Phase 3 integration — join mode creates a new
SpscQueue(8) and replaces the existing one during the coordinator
phase (no concurrent access during configuration).

### PioCommand

```rust
pub enum PioCommand {
    WriteInstrMem { block: u8, addr: u8, value: u16 },
    SetClkDiv { block: u8, sm: u8, int_div: u16, frac_div: u8 },
    SetExecCtrl { block: u8, sm: u8, value: u32 },
    SetShiftCtrl { block: u8, sm: u8, value: u32 },
    SetPinCtrl { block: u8, sm: u8, value: u32 },
    ForceExec { block: u8, sm: u8, instr: u16 },
    SmRestart { block: u8, mask: u8 },
    ClkdivRestart { block: u8, mask: u8 },
}
```

CPU worker threads push commands via `send_command()`. PIO worker
thread drains at the start of each quantum via `drain_commands()`.
Using `Mutex<Vec>` instead of a lock-free queue because commands are
infrequent (firmware setup only, not hot path) and the critical
section is tiny (push/drain a Vec).

### Methods

```rust
impl ThreadedPio {
    pub fn new() -> Self { /* all queues capacity 4, atomics zero */ }

    // --- FIFO access (CPU side) ---

    pub fn tx_push(&self, block: usize, sm: usize, val: u32) -> bool {
        self.tx[block][sm].try_push(val)
    }

    pub fn rx_pop(&self, block: usize, sm: usize) -> Option<u32> {
        self.rx[block][sm].try_pop()
    }

    pub fn tx_level(&self, block: usize, sm: usize) -> u32 {
        self.tx[block][sm].len()
    }

    pub fn rx_level(&self, block: usize, sm: usize) -> u32 {
        self.rx[block][sm].len()
    }

    // --- FIFO access (PIO thread side) ---

    pub fn tx_pop(&self, block: usize, sm: usize) -> Option<u32> {
        self.tx[block][sm].try_pop()
    }

    pub fn rx_push(&self, block: usize, sm: usize, val: u32) -> bool {
        self.rx[block][sm].try_push(val)
    }

    // --- Atomic control ---

    pub fn read_sm_enabled(&self, block: usize) -> u8 {
        self.sm_enabled[block].load(Relaxed)
    }

    pub fn write_sm_enabled(&self, block: usize, mask: u8) {
        self.sm_enabled[block].store(mask, Relaxed);
    }

    pub fn read_irq_flags(&self, block: usize) -> u8 {
        self.irq_flags[block].load(Relaxed)
    }

    pub fn write_irq_flags(&self, block: usize, flags: u8) {
        self.irq_flags[block].store(flags, Relaxed);
    }

    pub fn clear_irq_flags(&self, block: usize, mask: u8) {
        self.irq_flags[block].fetch_and(!mask, Relaxed);
    }

    pub fn read_dreq(&self, block: usize) -> u8 {
        self.dreq[block].load(Relaxed)
    }

    pub fn write_dreq(&self, block: usize, val: u8) {
        self.dreq[block].store(val, Relaxed);
    }

    // --- Command queue ---

    pub fn send_command(&self, cmd: PioCommand) {
        self.commands.lock().unwrap().push(cmd);
    }

    pub fn drain_commands(&self) -> Vec<PioCommand> {
        let mut guard = self.commands.lock().unwrap();
        std::mem::take(&mut *guard)
    }
}
```

### What stays on the PIO thread (NOT in ThreadedPio)

- `PioBlock` struct (instruction memory, SM execution state, clock
  divider accumulators, pin latches) — owned by the PIO worker
- `StateMachine` stepping logic
- Side-set pin computation

These are handed to the PIO worker thread at spawn time. Only the
communication interfaces (FIFOs, control flags, command queue) are
shared.

## Testing

### SpscQueue tests

1. `push_pop_roundtrip` — push 8 items, pop 8 items, verify values
2. `empty_pop_returns_none` — pop from fresh queue
3. `full_push_returns_false` — push capacity+1 items
4. `wraparound` — push/pop past capacity boundary, verify correctness
5. `len_tracks_occupancy` — verify len/is_empty/is_full
6. `clear_empties_queue` — push items, clear, verify empty
7. `concurrent_push_pop` — std::thread: producer pushes 100K items,
   consumer pops, verify all received in order

### SpinBarrier tests

1. `all_threads_released` — 4 threads wait, all proceed
2. `multiple_rounds` — 10 rounds, all threads cross each time
3. `poison_breaks_waiters` — poison while threads wait, all return
   Poisoned

### ThreadedSio tests

1. `fifo_push_pop` — core 0 pushes, core 1 pops, round-trips
2. `fifo_reverse` — core 1 pushes, core 0 pops
3. `fifo_full_sets_wof` — push 9 items, 9th sets WOF flag
4. `fifo_empty_sets_roe` — pop from empty sets ROE flag
5. `fifo_st_reflects_state` — verify VLD/RDY/WOF/ROE bits
6. `fifo_st_clear` — clear sticky bits with write-1-to-clear
7. `spinlock_claim_release` — claim succeeds, double-claim fails
8. `spinlock_release_allows_reclaim` — release then claim succeeds
9. `doorbell_set_read_clear` — set bits, read, clear, read
10. `mtime_advance_when_enabled` — advance increments when ctrl[0]=1
11. `mtime_no_advance_when_disabled` — advance is noop when ctrl[0]=0

### ThreadedPio tests

## What this phase does NOT do

- Does not touch `Bus`, `Emulator`, `Sio`, or `PioBlock`.
- Does not create `WorkerBus` or `SharedState` (Phase 3).
- Does not add any external dependencies.
- Does not include Loom tests (TSan in Phase 3 instead).
- Does not modify the single-threaded execution path.
- Does not implement register-level dispatch (Phase 3's WorkerBus).
- Does not implement FIFO join (Phase 3 configuration path).
