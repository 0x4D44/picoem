# Threaded Dual-Core Phase 0 — Low-Level Design

Version: 4.0.0
Date: 2026-04-16
Parent HLD: 2026.04.16 - HLD - Threaded Dual-Core Emulation V5.md
Changes from V3: Adds IRQ `irq_pending_dirty` flag to preserve inline
peripheral IRQ visibility, documents DMA CoreId convention.

## Scope

Phase 0 prerequisite refactors and validation. Three sub-phases:

- **0b** — PPB move, LDREX/STREX, cross-core atomization (main work)
- **0a** — workload instrumentation + synthetic dual-core program
- **0c** — primitives micro-prototype (barrier, atomics, queues)

Implementation order: 0b first (critical path, independently valuable),
0c in parallel (standalone binary), 0a after 0b lands.

---

## Phase 0b.1 — Move PPB to CortexM33

### Goal

Eliminate `Bus::active_core()`. Move the per-core `Ppb` from
`Bus.ppb: [Ppb; 2]` to `CortexM33.ppb: Ppb`. Thread `CoreId` through
every Bus method that currently relies on `active_core`.

After this phase, `Bus` has no concept of "which core is running" —
the caller always supplies `CoreId` explicitly.

### What moves, what stays

| Field | Action | Rationale |
|---|---|---|
| `ppb: [Ppb; 2]` | Move to `CortexM33.ppb: Ppb` | Per-core, only owning core accesses |
| `rcp_salt: [u32; 2]` | **Stays on Bus** | Core 0 seeds core 1's salt via `rcp_salt_core1` coprocessor op — cross-core write |
| `rcp_salt_valid: [bool; 2]` | **Stays on Bus** | Same cross-core access pattern as `rcp_salt` |
| `rcp_count: u32` | Stays on Bus | Shared across cores |
| `event_flag: [bool; 2]` | Stays on Bus | SEV writes both; FIFO push writes peer's; Phase 0b.3 atomizes |
| `irq_pending: [u64; 2]` | Stays on Bus | Set by peripherals (Bus owns peripherals) |
| `irq_pending_dirty: [bool; 2]` | **NEW on Bus** | Signals pending IRQs need merge into `nvic_ispr` |
| `active_pc: [u32; 2]` | Stays on Bus | Indexed by `core_id` parameter (replaces `active_core`) |
| `active_core: usize` | **Deleted** | Replaced by explicit CoreId parameters |

### Migration strategy

Two commits:

**Commit A (mechanical):** Add `core_id: u8` to Bus method signatures,
update all ~900 call sites.

**Commit B (semantic):** Move PPB to CortexM33, add bus_read32/write32
wrappers, IRQ sync decoupling, remove Bus PPB dispatch.

#### Commit A: Add CoreId to Bus methods

Add `core: u8` parameter to these Bus methods:

| Method | New signature |
|---|---|
| `read32` | `(&mut self, addr: u32, core: u8) -> u32` |
| `write32` | `(&mut self, addr: u32, val: u32, core: u8)` |
| `read16` | `(&mut self, addr: u32, core: u8) -> u16` |
| `write16` | `(&mut self, addr: u32, val: u16, core: u8)` |
| `read8` | `(&mut self, addr: u32, core: u8) -> u8` |
| `write8` | `(&mut self, addr: u32, val: u8, core: u8)` |
| `set_active_pc` | `(&mut self, pc: u32, core: u8)` |

Internally, Bus methods replace `self.active_core` with the `core`
parameter. `active_core` field, getter, and setter remain temporarily
(deleted in Commit B).

**Interim safety:** During Commit A, Bus internal dispatch arms (SIO
at region 0xD, PPB at region 0xE, MMIO trace) still read
`self.active_core` alongside the new `core` parameter. Add this guard
at the top of every signature-changed method:

```rust
debug_assert_eq!(self.active_core, core as usize,
    "core parameter must match active_core during interim migration");
```

This catches any drift during the Commit A → Commit B interim. The
guards are deleted in Commit B when `active_core` is removed.

Also update all `active_core()` call sites WITHIN Bus dispatch arms
(SIO write at line 2192, PPB dispatch at lines 1716/2063/2201, MMIO
trace at line 785, set_active_pc at line 749) to use the `core`
parameter instead.

**DMA caller convention:** `Bus::tick_peripherals` calls `self.dma.step()`
which issues bus reads/writes. DMA is not a core — it's a bus master.
For bus method CoreId parameters, DMA uses `0` by convention. Since
Bus no longer dispatches PPB after Commit B, DMA's CoreId value only
affects SIO routing (DMA should not access SIO per-core state) and
MMIO trace attribution. Convention: pass `0` from DMA paths.

**Step B.2: Add PPB intercept wrappers to CortexM33.**

```rust
impl CortexM33 {
    /// Bus access with PPB intercept. PPB addresses (0xE000_0000–0xEFFF_FFFF)
    /// route to self.ppb UNLESS the address falls in boot RAM
    /// (0xEFFF_F000–0xFFFF_FFFF).
    pub(crate) fn bus_read32(&mut self, addr: u32, bus: &mut Bus) -> u32 {
        if addr >> 28 == 0xE && !Bus::is_boot_ram(addr) {
            let val = self.ppb.read32(addr);
            if bus.mmio_trace_enabled {
                bus.emit_trace_read(addr, val, self.core_id);
            }
            val
        } else {
            bus.read32(addr, self.core_id)
        }
    }

    pub(crate) fn bus_write32(&mut self, addr: u32, val: u32, bus: &mut Bus) {
        if addr >> 28 == 0xE && !Bus::is_boot_ram(addr) {
            self.ppb.write32(addr, val);
            self.sync_nvic_to_irq_pending(addr, bus);
            if bus.mmio_trace_enabled {
                bus.emit_trace_write(addr, val, self.core_id);
            }
        } else {
            bus.write32(addr, val, self.core_id);
        }
    }

    pub(crate) fn bus_read16(&mut self, addr: u32, bus: &mut Bus) -> u16 {
        if addr >> 28 == 0xE && !Bus::is_boot_ram(addr) {
            let word = self.ppb.read32(addr & !3);
            if addr & 2 != 0 { (word >> 16) as u16 } else { word as u16 }
        } else {
            bus.read16(addr, self.core_id)
        }
    }

    pub(crate) fn bus_write16(&mut self, addr: u32, val: u16, bus: &mut Bus) {
        if addr >> 28 == 0xE && !Bus::is_boot_ram(addr) {
            let old = self.ppb.read32(addr & !3);
            let new_val = if addr & 2 != 0 {
                (old & 0x0000_FFFF) | ((val as u32) << 16)
            } else {
                (old & 0xFFFF_0000) | val as u32
            };
            self.ppb.write32(addr & !3, new_val);
            self.sync_nvic_to_irq_pending(addr & !3, bus);
        } else {
            bus.write16(addr, val, self.core_id);
        }
    }

    pub(crate) fn bus_read8(&mut self, addr: u32, bus: &mut Bus) -> u8 {
        if addr >> 28 == 0xE && !Bus::is_boot_ram(addr) { 0 }
        else { bus.read8(addr, self.core_id) }
    }

    pub(crate) fn bus_write8(&mut self, addr: u32, val: u8, bus: &mut Bus) {
        if addr >> 28 == 0xE && !Bus::is_boot_ram(addr) { /* drop */ }
        else { bus.write8(addr, val, self.core_id); }
    }
}
```

Note: `core/decode.rs` instruction fetches (`bus.read16(pc, core_id)`)
go directly to Bus — NOT through the PPB intercept wrapper, since
opcode fetches are never PPB addresses.

**Step B.3: Remove PPB dispatch from Bus.**

Delete the PPB branches from `Bus::read32`, `Bus::write32`,
`Bus::read16`. Add `debug_assert!(addr >> 28 != 0xE || Self::is_boot_ram(addr))`
in debug mode.

**Step B.4: IRQ routing — decouple from PPB.**

`Bus::assert_irq_core` / `assert_irq_shared` / `clear_irq_core` /
`clear_irq_shared` currently write both `irq_pending` and `ppb[core]`.
After the move, they set `irq_pending` AND set the dirty flag:

```rust
pub fn assert_irq_core(&mut self, core: usize, irq: u32) {
    if core < 2 && irq < IRQ_COUNT {
        self.irq_pending[core] |= 1u64 << irq;
        self.irq_pending_dirty[core] = true;
    }
}

pub fn assert_irq_shared(&mut self, irq: u32) {
    if irq < IRQ_COUNT {
        for core in 0..2 {
            self.irq_pending[core] |= 1u64 << irq;
            self.irq_pending_dirty[core] = true;
        }
    }
}

pub fn clear_irq_core(&mut self, core: usize, irq: u32) {
    if core < 2 && irq < IRQ_COUNT {
        self.irq_pending[core] &= !(1u64 << irq);
        // No dirty flag needed — merge is union, stale clear doesn't re-fire.
        // The dispatch path clears nvic_ispr directly.
    }
}
// clear_irq_shared: similar, no dirty flag.
```

**IRQ sync: the dual-clear invariant.**

The forward sync merges hardware-pending IRQs into the core's NVIC
using UNION (`|=`), preserving firmware self-pends:

```rust
pub fn merge_irq_pending(&mut self, pending: u64) {
    self.nvic_ispr[0] |= pending as u32;
    self.nvic_ispr[1] |= (pending >> 32) as u32;
}
```

This is safe because the existing exception dispatch path
(`try_take_any_pending_exception` at `exceptions.rs:483-484`) clears
BOTH `bus.irq_pending[core]` AND `self.ppb.nvic_ispr[word]` when
dispatching an IRQ. After the PPB move, the dispatch path has
`&mut Bus` access for `irq_pending` and `&mut self` for `ppb.nvic_ispr`:

```rust
// In try_take_any_pending_exception (after PPB move):
bus.irq_pending[core] &= !(1u64 << irq);  // clear source
self.ppb.nvic_ispr[word] &= !(1u32 << bit); // clear mirror
self.ppb.set_irq_active(irq as u32);
```

**This dual-clear is the critical invariant.** Preserved through all
clear paths:

- Exception dispatch (`exceptions.rs:483-484`): clears both ✓
- Firmware writes ICPR: clears `nvic_ispr`, then `sync_nvic_to_irq_pending`
  pushes to `irq_pending` ✓
- `Bus::clear_irq_core/shared`: clears `irq_pending` only. Merge union
  doesn't re-fire because the source is no longer driving. ✓

**Inline IRQ visibility via `irq_pending_dirty`:**

When a peripheral asserts an IRQ during a core's instruction execution
(e.g., inline peripheral write triggering IRQ), the IRQ must be
visible to the next exception dispatch check — not delayed to the next
quantum. `assert_irq_core/shared` sets `irq_pending_dirty[core] = true`.
`CortexM33::step()` merges before the dispatch check if dirty:

```rust
// In CortexM33::step(), before try_take_any_pending_exception:
if bus.irq_pending_dirty[self.core_id as usize] {
    self.ppb.merge_irq_pending(bus.irq_pending[self.core_id as usize]);
    bus.irq_pending_dirty[self.core_id as usize] = false;
}
```

Cost: one bool load per instruction (free on x86). Merge runs only
when something changed. Preserves the current zero-latency IRQ
visibility.

**Quantum-boundary merge in `Emulator::step()`:**

Also runs before each core's instruction loop (picks up IRQs asserted
by `tick_peripherals` at the previous quantum's end):

```rust
pub fn step(&mut self) -> u64 {
    self.bus.master_cycle = self.clock.cycles;
    let target = self.clock.cycles + self.step_quantum as u64;

    for core_id in 0..2 {
        // Quantum-boundary merge: pick up IRQs from tick_peripherals.
        if self.bus.irq_pending_dirty[core_id] {
            self.cores[core_id].ppb.merge_irq_pending(
                self.bus.irq_pending[core_id]
            );
            self.bus.irq_pending_dirty[core_id] = false;
        }

        while !self.cores[core_id].is_halted()
            && !self.cores[core_id].is_wfe_waiting()
            && self.cores[core_id].cycles < target
        {
            self.cores[core_id].ppb.update_latest_cycles(
                self.cores[core_id].cycles
            );
            self.cores[core_id].step(&mut self.bus);
        }
        self.cores[core_id].ppb.update_latest_cycles(
            self.cores[core_id].cycles
        );
    }
    // ... tick_peripherals, tick_systick, wake_checks ...
}
```

Reverse sync (firmware writes ISPR/ICPR via MMIO → update irq_pending):
```rust
fn sync_nvic_to_irq_pending(&self, addr: u32, bus: &mut Bus) {
    let low = addr & 0xFFFF;
    if matches!(low, 0xE200 | 0xE204 | 0xE280 | 0xE284) {
        bus.irq_pending[self.core_id as usize] =
            self.ppb.nvic_ispr[0] as u64
            | (self.ppb.nvic_ispr[1] as u64) << 32;
        // No dirty flag: we just set nvic_ispr AND irq_pending in sync.
    }
}
```

## Phase 0b.2 — LDREX/STREX

### Goal

Replace stubs with a proper exclusive monitor. Per-core
`exclusive_address` on CortexM33. Address-based monitor per ARMv8-M.
Snoop invalidates on peer writes.

### Current state

- LDREX (`0xE850`): treated as normal LDR (`execute_thumb32.rs:711`)
- STREX (`0xE840`): treated as normal STR, Rd always 0 (`execute_thumb32.rs:729`)
- CLREX (`0xF3BF, 0x8020`): 1-cycle NOP (`execute_thumb32.rs:866`)

### New fields on CortexM33

```rust
pub(crate) exclusive_address: Option<u32>,
pub(crate) did_write_this_quantum: bool,
```

Initialized to `(None, false)` in `with_id()`.

No `exclusive_value`. ARM exclusive monitors are address-based, not
value-based. CAS/value-comparison is architecturally wrong.

### Implementation

**LDREX** (replace `execute_thumb32.rs:711-717`):
```rust
let rn = (hw0 & 0xF) as usize;
let rt = ((hw1 >> 12) & 0xF) as usize;
let imm8 = (hw1 & 0xFF) as u32;
let addr = self.regs.r[rn].wrapping_add(imm8 << 2);
self.regs.r[rt] = self.bus_read32(addr, bus);
self.exclusive_address = Some(addr);
return 2;
```

**STREX** (replace `execute_thumb32.rs:729-737`):
```rust
let rn = (hw0 & 0xF) as usize;
let rt = ((hw1 >> 12) & 0xF) as usize;
let rd = ((hw1 >> 8) & 0xF) as usize;
let imm8 = (hw1 & 0xFF) as u32;
let addr = self.regs.r[rn].wrapping_add(imm8 << 2);

if self.exclusive_address == Some(addr) {
    self.bus_write32(addr, self.regs.r[rt], bus);
    self.regs.r[rd] = 0;
} else {
    self.regs.r[rd] = 1;
}
self.exclusive_address = None;
return if addr >> 28 == 0xD { 1 } else { 2 };
```

**CLREX**:
```rust
0x2 => { self.exclusive_address = None; 1 }
```

**Snoop** — peer writes invalidate.

After each core's quantum in `Emulator::step()`:
```rust
let peer = 1 - core_id;
if self.cores[peer].exclusive_address.is_some()
    && self.cores[core_id].did_write_this_quantum
{
    self.cores[peer].exclusive_address = None;
}
self.cores[core_id].did_write_this_quantum = false;
```

`did_write_this_quantum` is set in `bus_write32/16/8`. Same-core
writes don't invalidate the local monitor (ARM semantics).

**Known limitation:** In the interleaved scheduler, the snoop fires
after each core's quantum — not per-instruction. Correct for the
single-threaded model because cores run sequentially within a quantum
(core 0 completes before core 1 starts). Future threaded mode
(Phase 1+) requires atomic CAS on SharedMemory.

**LDREXB/LDREXH/STREXB/STREXH**: same pattern, narrower width.
Implement after LDREX/STREX.

### Parallelization

Phase 0b.2 can start on a branch in parallel with 0b.1. Touches only
`execute_thumb32.rs`, `core/mod.rs`, `lib.rs`. Rebase after 0b.1.

### Verification

1. Unit tests: LDREX→STREX success, LDREX→peer-write→STREX fail,
   LDREX→CLREX→STREX fail, LDREX→same-core-STR→STREX success
2. QEMU diff — LDREX/STREX correct vs QEMU

## Phase 0b.3 — Atomize cross-core fields + WFI

### Goal

Convert cross-core mutable fields to atomics. Implement proper WFI.

### Fields to atomize

| Field | Current | Location | New type |
|---|---|---|---|
| `halted` | `bool` | CortexM33 | `AtomicBool` |
| `wfe_waiting` | `bool` | CortexM33 | `AtomicBool` |
| `event_flag` | `[bool; 2]` | Bus | `[AtomicBool; 2]` |
| `nvic_ispr` | `[u32; 2]` | CortexM33.ppb | `[AtomicU32; 2]` |
| `nvic_iabr` | `[u32; 2]` | CortexM33.ppb | `[AtomicU32; 2]` |
| `nvic_iser` | `[u32; 2]` | CortexM33.ppb | `[AtomicU32; 2]` |

Notes:
- Sizes are `NVIC_BIT_WORDS` = 2 (not 8).
- `nvic_icpr` is not a field — ICPR writes clear bits in `nvic_ispr`.
- `Ppb` loses `Clone`/`Copy` with atomics.
- `pending_fifo_event` path: update to `.store(true, Release)`.
- `merge_irq_pending` becomes `fetch_or(val, Relaxed)`.

### WFI implementation

Per ARMv8-M B1.5.17: WFI with enabled pending IRQ does not sleep.

```rust
// Thumb-16 WFI (execute.rs):
0x3 => {
    let pending = bus.irq_pending[self.core_id as usize];
    if self.ppb.any_pending_enabled(pending) {
        1
    } else {
        self.halted.store(true, Release);
        1
    }
}
```

Same for Thumb-32 WFI.W.

```rust
pub fn any_pending_enabled(&self, pending: u64) -> bool {
    let iser = self.nvic_iser[0].load(Acquire) as u64
             | (self.nvic_iser[1].load(Acquire) as u64) << 32;
    (pending & iser) != 0
}
```

### QEMU diff compatibility

WFI doesn't modify architectural registers — register comparison is
unaffected. For multi-step tests where first opcode is WFI, add
`debug_step()` that clears halted BEFORE the inner step:

```rust
pub fn debug_step(&mut self, bus: &mut Bus) {
    self.halted.store(false, Relaxed);
    self.wfe_waiting.store(false, Relaxed);
    self.step(bus);
}
```

QEMU diff harness uses `debug_step()`.

### Wake path

```rust
fn wake_checks(&mut self) {
    for i in 0..2 {
        if self.cores[i].wfe_waiting.load(Acquire)
            && self.bus.event_flag[i].load(Acquire)
        {
            self.bus.event_flag[i].store(false, Release);
            self.cores[i].wfe_waiting.store(false, Release);
        }
        if self.cores[i].halted.load(Acquire) {
            let pending = self.bus.irq_pending[i];
            if pending != 0
                && self.cores[i].ppb.any_pending_enabled(pending)
            {
                self.cores[i].halted.store(false, Release);
            }
        }
    }
}
```

### SEV update

```rust
pub fn signal_sev(&mut self) {
    self.event_flag[0].store(true, Release);
    self.event_flag[1].store(true, Release);
}
```

### Verification

1. `cargo test --workspace` — all tests pass with atomic types
2. WFI tests: halts without pending; NOP with enabled pending;
   disabled IRQ doesn't block; wake on IRQ; dual-WFI with timer
3. QEMU diff with `debug_step()` — no new mismatches
