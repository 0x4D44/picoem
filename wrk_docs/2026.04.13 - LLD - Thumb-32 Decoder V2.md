## 1. Scope and Approach

Phase 1 goal: "can execute simple Thumb-2 binaries in flat memory."

**Implementation order: demand-driven.** Implement instructions as test binaries
need them. Priority list guides what to implement first.

**Priority:**
1. **First**: MOVW, MOVT, ADD.W/SUB.W/CMP.W (mod imm), AND.W/ORR.W/BIC.W,
   LDR.W/STR.W (imm12), LDRB.W/LDRH.W/STRB.W/STRH.W, B.W, LDM.W/STM.W
2. **Then**: shifted register ops, LDRD/STRD, MUL/MLA/MLS, SDIV/UDIV,
   SMULL/UMULL, CLZ, RBIT, BFI/BFC/UBFX/SBFX, wide extends, pre/post-index
   load/store, TBB/TBH
3. **When needed**: MSR/MRS (+SP banking), DSB/DMB/ISB, LDREX/STREX,
   coprocessor MRC/MCR/CDP, IT blocks, SSAT/USAT
4. **Deferred**: DSP extensions (Tier 4), FPU (Phase 7)

## 2. File Organization

One new file: `execute_thumb32.rs`. Split when it exceeds ~1,500 lines.
Update `decode.rs` to replace the BL-only stub with the full dispatch tree.

## 3. Top-Level Decode Tree (Verified)

Fields extracted from the two halfwords:
```
op1 = (hw0 >> 11) & 0x3    // hw0[12:11]
op2 = (hw0 >> 4) & 0x7F    // hw0[10:4]
op  = (hw1 >> 15) & 0x1    // hw1[15]
```

**Verified dispatch** (traced against assembler output for LDR.W, STR.W, LDRB.W,
LDRSB.W, CLZ, RBIT, REV.W, SXTH.W, MUL, MLA, SMULL, UMULL, SDIV, UDIV, CDP2):

```rust
fn execute_thumb32(&mut self, hw0: u16, hw1: u16, bus: &mut Bus) -> u32 {
    let op1 = (hw0 >> 11) & 0x3;
    let op2 = ((hw0 >> 4) & 0x7F) as u32;
    let op  = (hw1 >> 15) & 0x1;

    match op1 {
        0b01 => match op2 >> 5 {
            0b00 => if op2 & 0x04 == 0 {
                self.thumb32_ldm_stm(hw0, hw1, bus)       // STMIA, STMDB, LDMIA, LDMDB
            } else {
                self.thumb32_load_store_dual(hw0, hw1, bus) // LDRD, STRD, TBB, TBH, LDREX, STREX
            },
            0b01 => self.thumb32_dp_shifted_reg(hw0, hw1), // ALU with barrel-shifted Rm
            _    => self.thumb32_coprocessor(hw0, hw1, bus), // CDP, MCR, MRC, LDC, STC
        },
        0b10 => if op == 0 {
            if op2 & 0x20 == 0 {
                self.thumb32_dp_modified_imm(hw0, hw1)     // ALU with ThumbExpandImm
            } else {
                self.thumb32_dp_plain_imm(hw0, hw1)        // MOVW, MOVT, ADDW, SUBW, BFI, UBFX
            }
        } else {
            self.thumb32_branch_misc(hw0, hw1, bus)        // B.W, BL, MSR, MRS, hints, barriers
        },
        0b11 => if op2 & 0x40 != 0 {
            self.thumb32_coprocessor(hw0, hw1, bus)        // CDP2, MCR2, MRC2, LDC2, STC2
        } else if op2 & 0x20 == 0 {
            self.thumb32_load_store_single(hw0, hw1, bus)  // LDR.W, STR.W, LDRB.W, LDRSB.W, etc.
        } else if op2 & 0x10 == 0 {
            self.thumb32_dp_register(hw0, hw1)             // CLZ, RBIT, REV, SXTH, LSL.W, etc.
        } else if op2 & 0x08 == 0 {
            self.thumb32_multiply(hw0, hw1)                // MUL, MLA, MLS
        } else {
            self.thumb32_long_multiply(hw0, hw1)           // SMULL, UMULL, SDIV, UDIV, SMLAL, UMLAL
        },
        _ => self.thumb32_undefined(hw0, hw1),
    }
}
```

**Why `op` (hw1[15]) is NOT used for `op1=11`:** For multiply instructions,
hw1[15] is the MSB of the Ra register field (Ra=0xF for MUL, Ra=R3 for MLA).
Using it as a dispatch bit would misroute MUL to coprocessor. The coprocessor
vs. non-coprocessor split is entirely on op2[6] (hw0[10]).

## 4. ThumbExpandImm (Modified Immediate Constants)

The 12-bit immediate `i:imm3:imm8` expands to a 32-bit constant with carry-out.

```
imm12 = ((hw0 >> 10) & 1) << 11  // i = hw0[10]
      | ((hw1 >> 12) & 0x7) << 8  // imm3 = hw1[14:12]
      | (hw1 & 0xFF)               // imm8 = hw1[7:0]
```

```rust
#[inline(always)]
fn thumb_expand_imm_c(imm12: u32, carry_in: bool) -> (u32, bool) {
    if imm12 & 0xC00 == 0 {
        // Bits [11:10] = 00: byte replication. Carry unchanged.
        let imm8 = imm12 & 0xFF;
        let val = match (imm12 >> 8) & 0x3 {
            0b00 => imm8,                           // 0x000000ii
            0b01 => (imm8 << 16) | imm8,            // 0x00ii00ii
            0b10 => (imm8 << 24) | (imm8 << 8),     // 0xii00ii00
            _    => imm8 * 0x01_01_01_01,            // 0xiiiiiiii
        };
        (val, carry_in)
    } else {
        // Bits [11:10] != 00: rotate (1:imm7) right by imm12[11:7].
        let unrotated = 0x80 | (imm12 & 0x7F);
        let rotation = (imm12 >> 7) & 0x1F;
        let val = unrotated.rotate_right(rotation);
        (val, val >> 31 != 0)
    }
}

#[inline(always)]
fn thumb_expand_imm(imm12: u32) -> u32 {
    thumb_expand_imm_c(imm12, false).0
}
```

## 5. Instruction Group Details

### 5.1 Data Processing (Modified Immediate)

Format: `11110_i_0_op[3:0]_S_Rn  0_imm3_Rd_imm8`

Extract fields:
```
op = (hw0 >> 5) & 0xF        // hw0[8:5]
s  = (hw0 >> 4) & 1          // hw0[4]
rn = (hw0 & 0xF) as usize    // hw0[3:0]
rd = ((hw1 >> 8) & 0xF) as usize  // hw1[11:8]
imm12 = (see Section 4)
```

| op | S=0, Rd!=15 | S=1, Rd=15 | S=1, Rd!=15 |
|----|-------------|------------|-------------|
| 0000 | AND | TST | ANDS |
| 0001 | BIC | — | BICS |
| 0010 | ORR (Rn=15: MOV) | — | ORRS (Rn=15: MOVS) |
| 0011 | ORN (Rn=15: MVN) | — | ORNS (Rn=15: MVNS) |
| 0100 | EOR | TEQ | EORS |
| 1000 | ADD | CMN | ADDS |
| 1010 | ADC | — | ADCS |
| 1011 | SBC | — | SBCS |
| 1101 | SUB | CMP | SUBS |
| 1110 | RSB | — | RSBS |

When S=1 and ThumbExpandImm uses the rotation path, carry-out updates C flag.
When S=1 and ThumbExpandImm uses replication, C flag is unchanged (carry_in).
All: 1 cycle.

### 5.2 Data Processing (Plain Binary Immediate)

Format: `11110_i_1_op[4:0]_0_Rn  0_imm3_Rd_imm8`

Uses zero-extended immediates, NOT ThumbExpandImm.

**MOVW** (op=00100):
```
imm16 = ((hw0 & 0xF) << 12) | (((hw0 >> 10) & 1) << 11)
      | (((hw1 >> 12) & 0x7) << 8) | (hw1 & 0xFF)
rd = (hw1 >> 8) & 0xF
```
Rd = imm16 (zero-extended to 32 bits).

**MOVT** (op=01100): Same imm16 extraction. Rd[31:16] = imm16, Rd[15:0] unchanged.

**ADDW** (op=00000, Rn!=15):
```
imm12 = (((hw0 >> 10) & 1) << 11) | (((hw1 >> 12) & 0x7) << 8) | (hw1 & 0xFF)
```
Rd = Rn + ZeroExtend(imm12). No flag update.

**SUBW** (op=01010, Rn!=15): Rd = Rn - ZeroExtend(imm12).
**ADR** (ADDW/SUBW with Rn=15): Rd = Align(PC, 4) +/- imm12.
**BFI/BFC/SBFX/UBFX**: Bit field operations.
**SSAT/USAT**: Saturation (implement when needed).

All: 1 cycle.

### 5.3 Data Processing (Shifted Register)

Format: `11101_01_op[3:0]_S_Rn  0_imm3_Rd_imm2_tt_Rm`

Same ALU ops as 5.1 but with barrel-shifted Rm.
```
shift_type = (hw1 >> 4) & 0x3     // 00=LSL, 01=LSR, 10=ASR, 11=ROR
shift_amount = ((hw1 >> 12) & 0x7) << 2 | ((hw1 >> 6) & 0x3)  // imm3:imm2 (5 bits)
rm = (hw1 & 0xF) as usize
```
Special: type=11, amount=0 → RRX (rotate right through carry by 1).
When Rn=1111, op=0010: becomes LSL.W/LSR.W/ASR.W/ROR.W/RRX/MOV.W.
All: 1 cycle.

### 5.4 Load/Store Single

Sub-dispatch within handler using hw0 fields:
```
size  = (hw0 >> 5) & 0x3   // hw0[6:5]: 00=byte, 01=half, 10=word
load  = (hw0 >> 4) & 1     // hw0[4]: 1=load, 0=store
sign  = (hw0 >> 8) & 1     // hw0[8]: 1=signed load (LDRSB, LDRSH)
rn    = (hw0 & 0xF) as usize  // hw0[3:0], 1111=PC-relative
rt    = ((hw1 >> 12) & 0xF) as usize  // hw1[15:12]
```
Note: hw0[9] is always 0 within load_store_single (consumed by top-level
dispatch). The sign bit is hw0[8] (= op2[4]).

**GUARD: When load=1 and Rt=1111, this is a PLD/PLI preload hint, NOT a load
to PC. Return 1 (NOP). Omitting this check corrupts PC.**

**Addressing modes (hw0[7] distinguishes them):**

When hw0[7]=1: unsigned 12-bit immediate offset.
```
imm12 = hw1 & 0xFFF          // hw1[11:0]
addr = Rn + imm12
```

When hw0[7]=0 and Rn!=1111:
```
if hw1 & 0x800 != 0 {
    // hw1[11]=1: 8-bit immediate with P/U/W
    p = (hw1 >> 10) & 1
    u = (hw1 >> 9) & 1
    w = (hw1 >> 8) & 1
    imm8 = hw1 & 0xFF
    offset = if u == 1 { imm8 } else { 0u32.wrapping_sub(imm8) }
    // P=1,W=0: offset; P=1,W=1: pre-index; P=0,W=1: post-index
    // P=1,U=1,W=0: unprivileged access (treat as normal for Phase 1)
} else {
    // hw1[11]=0: register offset with LSL
    shift = (hw1 >> 4) & 0x3  // hw1[5:4]
    rm = (hw1 & 0xF) as usize
    offset = Rm << shift
    addr = Rn + offset
}
```

When Rn=1111: PC-relative literal load.
```
base = Align(read_pc(), 4)    // read_pc() = instr_addr + 4, word-aligned
u = (hw0 >> 7) & 1            // add or subtract
addr = if u == 1 { base + imm12 } else { base - imm12 }
```

**Cycle costs:** Load: 2. Store: 1.

### 5.5 Load/Store Multiple

Format: `11101_00_op_PUW_L_Rn  reglist[15:0]`

STMIA, STMDB, LDMIA, LDMDB. 16-bit register list (R0-R15).
Cycle cost: 1+N (N = register count). Validate M33 may be N.

### 5.6 Load/Store Dual, Exclusive, Table Branch

**LDRD/STRD**: Rt=hw1[15:12], Rt2=hw1[11:8], imm8=hw1[7:0], offset=imm8<<2.
P/U/W addressing modes. Cycle cost: 1+2.

**LDREX/STREX**: Treat as normal load/store for Phase 1.
**TBB**: PC += 2 * ZeroExtend(MemU_B[Rn + Rm]). **TBH**: PC += 2 * ZeroExtend(MemU_H[Rn + Rm*2]).
**CLREX**: 1-cycle NOP.

### 5.7 Branches and Miscellaneous Control

All op1=10, op=1 instructions route here. Sub-dispatch within handler:
```
hw1[14] = 1 → BL (link bit set)
hw1[14] = 0, hw1[12] = 1 → B.W T4 (unconditional)
hw1[14] = 0, hw1[12] = 0:
    hw0[9:6] != 0b111x → B.W T3 (conditional branch)
    hw0[9:6] == 0b111x → miscellaneous control (MSR, MRS, hints, barriers)
```

**B.W conditional (T3):**
```
hw0 = 11110_S_cond[3:0]_imm6    hw1 = 10_J1_0_J2_imm11
S = (hw0 >> 10) & 1, cond = (hw0 >> 6) & 0xF, imm6 = hw0 & 0x3F
J1 = (hw1 >> 13) & 1, J2 = (hw1 >> 11) & 1, imm11 = hw1 & 0x7FF
offset = SignExtend(S:J2:J1:imm6:imm11:0, 21)
```
Note: J1/J2 used directly (no XOR trick — that's only for T4/BL).
Range: +/- 1 MB. 2 cycles taken, 1 not taken.

**B.W unconditional (T4):**
```
hw0 = 11110_S_imm10    hw1 = 10_J1_1_J2_imm11
I1 = NOT(J1 XOR S), I2 = NOT(J2 XOR S)
offset = SignExtend(S:I1:I2:imm10:imm11:0, 25)
```
Range: +/- 16 MB. 2 cycles.

**BL:** Already implemented (move to execute_thumb32.rs).

**MSR** (write special register): Requires SP banking (implement together).
```
hw0 = 11110_011100_R_Rn    hw1 = 10_00_mask_00_SYSm
SYSm = hw1 & 0xFF (selects APSR/MSP/PSP/PRIMASK/BASEPRI/FAULTMASK/CONTROL)
```

SP banking helpers (add with MSR):
```rust
impl Registers {
    fn active_sp_is_psp(&self) -> bool {
        // Handler mode always uses MSP, regardless of SPSEL.
        !self.in_handler_mode() && self.control & 2 != 0
    }
    fn sync_sp_to_banked(&mut self) {
        if self.active_sp_is_psp() { self.psp = self.r[13]; }
        else { self.msp = self.r[13]; }
    }
    fn sync_sp_from_banked(&mut self) {
        self.r[13] = if self.active_sp_is_psp() { self.psp } else { self.msp };
    }
}
```

**MRS** (read special register): Rd = selected system register.
**Hints**: NOP.W, YIELD.W, WFE.W, WFI.W, SEV.W — 1-cycle NOPs.
**Barriers**: DSB, DMB, ISB — 1-cycle NOPs for Phase 1.

### 5.8 Multiply and Divide

```
Rn = hw0 & 0xF, Rd = (hw1 >> 8) & 0xF, Rm = hw1 & 0xF, Ra = (hw1 >> 12) & 0xF
```

**32-bit result** (thumb32_multiply): MUL (Ra=15), MLA, MLS. 1 cycle each.
**64-bit result** (thumb32_long_multiply): SMULL, UMULL, SMLAL, UMLAL. 1 cycle.
**Division**: SDIV, UDIV. Data-dependent 2-11 cycles; use 4 as placeholder.
Div by zero returns 0 (default CCR.DIV_0_TRP=0).

### 5.9 Data Processing (Register)

Miscellaneous: CLZ, RBIT, REV.W, REV16.W, REVSH.W. 1 cycle.
Wide shift by register: LSL.W, LSR.W, ASR.W, ROR.W. 1 cycle.
Wide extend: SXTH.W, SXTB.W, UXTH.W, UXTB.W. 1 cycle.

### 5.10 Coprocessor

```rust
let coproc = ((hw1 >> 8) & 0xF) as u8;
match coproc {
    0       => self.coproc_gpioc(hw0, hw1, bus),  // Phase 3
    4 | 5   => self.coproc_dcp(hw0, hw1),         // Phase 3
    7       => self.coproc_rcp(hw0, hw1),          // Phase 3
    10 | 11 => self.coproc_fpu(hw0, hw1),          // Phase 7
    _       => self.thumb32_undefined(hw0, hw1),
}
```

Phase 1: all coprocessor instructions return `thumb32_undefined`.

## 6. IT Block Design

Needed before running real compiled code (GCC emits IT for conditionals).
Not needed for individual handler testing via `execute_one_wide()`.

**State**: `it_state: u8` on `CortexM33`. Format: `cond[7:4]:mask[3:0]`.
`mask == 0` = not in IT block.

**IT instruction** (Thumb-16, 0xBFxx in misc group):
```rust
self.it_state = (opcode & 0xFF) as u8;
```

**Decode loop**: Before executing, check IT state:
```rust
let in_it = self.it_state & 0xF != 0;
let cond = if in_it { (self.it_state >> 4) & 0xF } else { 0xE }; // AL
let cond_passed = self.regs.condition_passed(cond as u8);
// if !cond_passed: skip execution, return 1 cycle
// after execution: if in_it { self.advance_it_state(); }
```

**Advance**: Shift mask left. The T/E condition inversion is baked into the
mask bits set by the IT instruction — bit[4] of `it_state` after advance is
the condition LSB for the next instruction.
```rust
fn advance_it_state(&mut self) {
    if self.it_state & 0x7 == 0 {
        self.it_state = 0;
    } else {
        self.it_state = (self.it_state & 0xE0) | ((self.it_state << 1) & 0x1F);
    }
}
```

**Flag suppression in IT blocks**: Thumb-16 instructions that normally set
flags unconditionally (ADDS, SUBS, MOVS, LSLS, etc.) must suppress flag
updates inside IT blocks. **Exception:** CMP, CMN, and TST always set flags
even inside IT blocks — they are flag-only instructions with no non-flag
variant. Implementation: `execute_thumb16` checks `self.it_state & 0xF != 0`
and suppresses flag writes for instructions that write to a destination
register, but not for flag-only instructions.

**xPSR sync** (Phase 3): IT state is architecturally in xPSR bits [15:10,
26:25]. The `it_state` shadow must sync on exception entry/return and MSR
writes to xPSR.

## 9. Known Thumb-16 Gaps

These are missing from the existing Thumb-16 implementation and should be
addressed alongside Thumb-32 work:

- **CBZ/CBNZ** (0xB1xx/0xB9xx in misc group): Compare-and-branch-if-zero.
  Compilers emit these heavily for null checks and loop termination. Currently
  caught by the `_ => 1` NOP catch-all in `thumb16_misc`. Must implement.
- **IT instruction** (0xBFxx): Covered in Section 6 but the handler must
  actually be added to `thumb16_misc`.

## 10. IT Flag Suppression — Recommended Implementation

The cleanest approach avoids modifying existing Thumb-16 handlers. In
`decode_execute`, save the flag bits before executing, then restore them
after if flag suppression applies:

```rust
let saved_flags = if in_it { self.regs.xpsr & 0xF800_0000 } else { 0 };
let cycles = self.execute_thumb16(opcode, bus);
if in_it && !is_flag_only(opcode) {
    self.regs.xpsr = (self.regs.xpsr & !0xF800_0000) | saved_flags;
}
```

Where `is_flag_only` detects CMP/CMN/TST (these always set flags, even in
IT blocks). This avoids adding a conditional to every flag-setting handler.

## 11. Design Decisions

| Decision | Rationale |
|---|---|
| One file, split later | Can't predict fault lines before writing code |
| Demand-driven order | Implement what binaries need, not a waterfall |
| op1=11 uses op2 bits only, not hw1[15] | hw1[15] is Ra MSB for multiplies, not a dispatch bit |
| IT: implement before real binaries | Individual handler tests don't need IT |
| SP banking: implement with MSR | No instruction needs it until then |
| Bus fault: defer to Phase 3 | Phase 1 is flat memory |
| Coprocessor: plain match | 4 known CPs, no extensibility needed |
| PLD/PLI (Rt=15 on loads): NOP | Prevents PC corruption |
| Unaligned LDR/STR: allow | M33 default; LDRD/LDM always fault |
