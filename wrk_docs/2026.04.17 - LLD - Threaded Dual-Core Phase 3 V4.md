# Threaded Dual-Core Phase 3 — Low-Level Design

Version: 4.0.0
Date: 2026-04-17
Supersedes: V3 (same date)
Parent HLD: `2026.04.16 - HLD - Threaded Dual-Core Emulation V5.md`

## Changes from V3

Review round 3 found 2 critical + 4 high + 3 medium; all addressed.

- **Decode cache invalidation: `Vec<u32>` of pending addresses** on
  `WorkerBus`, drained after every `CortexM33::step`. V3's single
  `Option<u32>` lost all but the last write of multi-word instructions
  (STM/PUSH/VSTM) — functional bug.
- **Monitor snoop wording unified.** §4 is authoritative: every
  `WorkerBus::write*` snoops. STREX additionally clears its own
  monitor at the execute site (pre-existing `CLREX`-equivalent path).
  Deleted the contradictory V3 §11 wording.
- **ISB wires decode-cache flush now.** `ISB` invalidates the
  executing core's own cache entirely. `DMB`/`DSB` do not.
- **`CoreAtomics` passed at ctor: `CortexM33::new(core_id, atomics)`.**
  `Bus::new()` builds the Arc once and hands it to both cores. No
  `set_atomics`, no `Option<Arc<...>>`, no interim atomics-less state.
- **`Peripherals` built via struct literal** at `from_emulator` call
  site. 20-arg ctor dropped.
- **`ThreadedEmulator.poisoned: bool`** flag; set on worker panic.
  Next `run_quanta` panics with a clear message.
- **Single generic `spawn_worker<F, R>` helper** wraps the
  `catch_unwind + barrier.poison() + resume_unwind` pattern. Removes
  duplication across 4 worker types.
- **`PerCoreSio` lives on `CortexM33` directly** (no new file). Just a
  field; divider/interp behaviour bodies unchanged.
- **Address table collapsed**: per-peripheral routing listed, exact
  offsets owned by `WorkerBus` match-arms that mirror `bus/mod.rs`.
  Prior versions of this table had real mistakes.
- **Tests down to 12** (dropped cross-thread `rcp_count_check` test —
  `compare_exchange` is stdlib-atomic; a single-thread unit test of
  return values is enough).

## Scope

Compose Phase 1/2 primitives into a 4-thread runtime:

1. `CoreBus` trait — MMIO surface `CortexM33` uses on the bus.
2. `CoreAtomics` — `Arc`'d cross-core per-core state.
3. `SharedState` — `Arc` bundle.
4. `WorkerBus` — CPU-thread view (impls `CoreBus`).
5. `PioBus` — PIO thread's view, owns `PioBlock`s.
6. `PerCoreSio` — divider + interpolator on each `CortexM33`.
7. `Peripherals` — mutex-protected coordinator-owned state.
8. `ThreadedEmulator::from_emulator` + `run_quanta(n)`.
9. Windows thread pinning (cores 0/1/2/3).

Deferred to Phases 4/5: see §14.

### Platform gate

`#[cfg(all(target_arch = "x86_64", target_os = "windows"))]` on
`ThreadedEmulator`, `WorkerBus`, `PioBus`, `worker::*`,
`pin_to_host_core`. `CoreBus` / `CoreAtomics` / `PerCoreSio` /
`SharedState` are unconditional (visible to `CortexM33`, which builds
on all targets).

## 1. `CoreBus` trait

```rust
pub trait CoreBus {
    fn read8(&mut self,  addr: u32, core: u8) -> u8;
    fn read16(&mut self, addr: u32, core: u8) -> u16;
    fn read32(&mut self, addr: u32, core: u8) -> u32;
    fn write8(&mut self,  addr: u32, val: u8,  core: u8);
    fn write16(&mut self, addr: u32, val: u16, core: u8);
    fn write32(&mut self, addr: u32, val: u32, core: u8);

    fn set_active_pc(&mut self, pc: u32, core: u8);

    fn bus_fault(&self) -> bool;
    fn bus_fault_addr(&self) -> u32;
    fn clear_bus_fault(&mut self);

```

10 methods. Everything else (IRQ pending, SEV, halted, WFE, RCP) is
on `CoreAtomics` (§2) and reached via `self.atomics` directly from
`CortexM33`.

`CortexM33::step<B: CoreBus>(&mut self, bus: &mut B)` and all helpers
become generic. Monomorphisation acknowledged in §13.

### `impl CoreBus for Bus`

Inherent-method delegates. `Bus::bus_fault` etc. route to the same
`CoreAtomics.bus_fault[self.core_id]` that the threaded path uses —
so single-threaded and threaded share one source of truth.

### Key methods

```rust
impl CoreAtomics {
    pub fn assert_irq(&self, core: usize, irq: u32);
    pub fn assert_irq_shared(&self, irq: u32);
    pub fn clear_irq(&self, core: usize, irq: u32);
    pub fn take_irq_pending(&self, core: usize) -> u64 {
        self.irq_pending[core].swap(0, AcqRel)
    }

    /// SEV writes both cores' event_flag. Stored-sticky until consumed.
    pub fn sev_both(&self);
    /// WFE consume: atomic swap to false; returns old value.
    pub fn event_flag_consume(&self, core: usize) -> bool;

    pub fn set_halted(&self, core: usize);
    pub fn clear_halted(&self, core: usize);
    pub fn is_halted(&self, core: usize) -> bool;
    /* same for wfe_waiting */

    /// `rcp_count_set X` — unconditional store.
    pub fn rcp_count_set(&self, value: u32);
    /// `rcp_count_check Y`: atomic compare-then-increment.
    /// Loop retries at most twice (only one peer can beat us before
    /// our stored value diverges from `expected`).
    pub fn rcp_count_check(&self, expected: u32) -> Result<(), u32> {
        loop {
            let cur = self.rcp_count.load(Acquire);
            if cur != expected { return Err(cur); }
            match self.rcp_count.compare_exchange(
                cur, cur.wrapping_add(1), AcqRel, Acquire)
            {
                Ok(_)  => return Ok(()),
                Err(_) => continue,
            }
        }
    }

    pub fn set_bus_fault(&self, core: usize, addr: u32);
    pub fn clear_bus_fault(&self, core: usize);
}
```

### Ownership invariant

`CortexM33::new(core_id: u8, atomics: Arc<CoreAtomics>) -> Self` —
atomics required at construction. No setter, no `Option`. `Bus::new()`
constructs a `CoreAtomics` once and hands the Arc to both cores plus
stores it on `Bus` (so inherent `Bus` methods can reach
`atomics.bus_fault[core]` etc.). `Emulator::new` orchestrates the
build; `from_emulator` (§8) extracts the Arc into `SharedState`.

## 4. `WorkerBus`

```rust
pub struct WorkerBus {
    core_id: u8,
    shared: SharedState,
    active_pc: u32,
    burst_mode: bool,
    extra_wait_states: u32,
    /// Addresses of executable-region writes queued by this step.
    /// Drained by the worker loop after each `core.step`.
    pending_cache_invalidations: Vec<u32>,
}
```

### Address-class routing

| Region (`addr >> 28`) | Target |
|---|---|
| `0x0` ROM / `0x1` XIP | `shared.memory.read*` |
| `0x2` SRAM | `shared.memory.read/write*`; writes record `self.pending_cache_invalidations.push(addr)` |
| `0x4` APB | sub-decode by offset → `peripherals.clocks / qmi / resets / apb / timers / dma` |
| `0x5` AHB | `peripherals.dma` |
| `0xD` SIO | `shared.sio.*` / `shared.gpio.*` / `shared.atomics.*` (DIV/INTERP intercepted on `CortexM33` — §6) |
| `0xE` PPB | unreachable (intercepted on `CortexM33`) |

Exact offsets match the `bus/mod.rs` decode match arms — `WorkerBus`
mirrors them. Maintaining a hand-written address table in this LLD
proved error-prone across V1–V3; the implementer cross-references
the existing `Bus` dispatch directly.

APB offsets routed to mutex components by their peripheral family
per §7.

### Peer-monitor snoop on every write

```rust
impl CoreBus for WorkerBus {
    fn write32(&mut self, addr: u32, val: u32, core: u8) {
        // ...region dispatch, including shared.memory.write32 for SRAM...
        if matches!(addr >> 28, 0x0 | 0x1 | 0x2) {
            self.pending_cache_invalidations.push(addr);
        }
        self.shared.monitors.snoop(addr);
    }
    // write16/write8 mirror: region dispatch, push invalidation for exec,
    // snoop peer monitor.
}
```

ARMv8-M §A3.4: any store to a word for which the peer holds an
exclusive monitor invalidates that monitor. Snooping every write —
not just STREX — matches the architecture. STREX separately clears
its own monitor at the CortexM33 execute site (existing Phase 0b.2
path; unchanged).

### Decode-cache invalidation (per-core, self-only)

After each `core.step`, the worker drains
`bus.pending_cache_invalidations` and calls
`core.invalidate_decode_cache_entries(&addrs)`. Vec capacity
pre-allocated to 16 (covers ARM STM up to 13 regs + some spare). The
Vec is `clear()`-ed each step; allocations amortise.

Cross-core SMC is NOT automatically handled — matches ARM spec
requirement that firmware issue `DSB; ISB; IC IVAU` cross-core.

### MMIO reads with side effects

Same list as V3 §4 — routed through the same components, so the same
atomicity story applies (SIO FIFO: SPSC pop; spinlock: atomic
fetch_or; PIO RXF: SPSC pop; ROSC RANDOM / TIMER TIMELR:
mutex-serialised).

## 5. `PioBus`

```rust
pub struct PioBus {
    shared: SharedState,
    blocks: [PioBlock; 3],
}
```

Per-quantum PIO-thread loop (unchanged from V2/V3):

1. `shared.pio.drain_commands()` → apply each command to local
   `PioBlock`s.
2. For each active SM (per `shared.pio.read_sm_enabled`), step one
   PIO cycle × `step_quantum` times.
3. Update `shared.pio.irq_flags` / `dreq`.

One-quantum delay on CPU→PIO writes (§5 V3). Firmware must issue DMB
between INSTR_MEM writes and SM_ENABLE if sub-quantum ordering
matters (same as real hardware).

FIFO join deferred to Phase 5.

## 6. SIO ownership split

### `ThreadedSio` (already in Phase 2)

Covers: FIFOs, spinlocks, doorbells, MTIME, MTIMECMP. Plus
`AtomicGpio` for GPIO_IN/OUT/OE.

### `PerCoreSio` (per-core, on `CortexM33`)

```rust
pub struct PerCoreSio {
    pub divider: Divider,
    pub interp:  [Interp; 2],
}
```

Defined in `crates/mdrp2350/src/core/mod.rs` (NOT a new file). The
existing `Divider` + `Interp` bodies in `mdpicoem-common` are
unchanged — only the storage location moves.

### SIO MMIO dispatch

`WorkerBus::read32/write32` at `0xD000_...`:

| Category | Route |
|---|---|
| GPIO in/out/oe, CPUID, MTIME/MTIMECMP | `shared.gpio` / `shared.sio.mtime*` / constant CPUID |
| FIFO_ST / FIFO_WR / FIFO_RD | `shared.sio.fifo_*` |
| SPINLOCK<0..31> | `shared.sio.spinlocks` |
| DIV_* / INTERP*_* | **intercepted on `CortexM33`** — routes to `self.sio_local.*` before reaching the bus |

The DIV/INTERP intercept is a one-line branch in
`CortexM33::bus_read32/write32` wrappers (mirrors the existing PPB
intercept for `0xE...`). No `CoreBus` trait surface needed —
DIV/INTERP are strictly per-core, so the intercept captures them
before cross-thread routing.

### CP0 coprocessor path

`coprocessor.rs` currently routes CP0 MMIO via
`bus.sio.cp0_read/write(reg, cpuid)`. With the split:
- GPIO / FIFO / spinlock CP0 regs → `shared` (via CoreBus or direct
  atomics access from CortexM33).
- DIV / INTERP CP0 regs → `self.sio_local`.

Mechanical rewrite: ~30 call sites in `coprocessor.rs` split by
register number. No new abstractions.

## 7. `Peripherals`

```rust
pub struct Peripherals {
    pub clocks: Mutex<ClocksState>,   // CLOCKS + PLL_SYS + PLL_USB + XOSC + ROSC
    pub qmi:    Mutex<QmiState>,
    pub resets: Mutex<ResetsState>,
    pub apb:    Mutex<ApbState>,      // UART/SPI/I2C/ADC/PWM/IO_BANK0/PADS_BANK0
    pub timers: Mutex<TimersState>,   // TICKS/TIMER0/1/WATCHDOG
    pub dma:    Mutex<DmaState>,
}
```

Lock order (documented in module rustdoc):
`clocks < qmi < resets < apb < timers < dma`.

Phase 3 codebase has zero nested-lock sites — the coordinator
takes locks sequentially, CPU workers take at most one per MMIO.
If a nested site appears later, add `debug_assert!` locally.

### Poisoning

`.lock().unwrap()` — panic on poison. `into_inner()` silently
proceeds on corrupted state; failing loud is safer. Phase 4 revisits
when real `ExitReason::Panic` lands.

### Construction at `from_emulator`

Built via struct literal inline in `from_emulator` — no 20-arg
`from_bus_components`. Each `Mutex<*State>::new(State { ... })`
wraps the destructured Bus fields.

### Coordinator snapshot pattern

`tick_peripherals` takes `clocks + resets` briefly, clones
`ClockTree` + `resets_state` into coordinator locals, drops both.
Narrows lock windows. (Comment in the coordinator body; no
dedicated LLD section.)

### `from_emulator`

```rust
pub fn from_emulator(emu: Emulator) -> Self {
    let n = std::thread::available_parallelism()
        .map(|n| n.get()).unwrap_or(1);
    assert!(n >= 4,
        "ThreadedEmulator requires >= 4 host cores (found {})", n);
    if n == 4 {
        tracing::warn!("exactly 4 host cores — workers will contend \
                        with OS/other processes; >= 5 recommended");
    }

    let Emulator { cores, bus, clock, step_quantum } = emu;
    let [core0, core1] = cores;

    // Exhaustive destructure — new Bus fields force a compile error.
    let Bus {
        memory, boot_ram, xip_sram,
        sio, pio,
        atomics,                  // Arc<CoreAtomics> — carry through
        event_flag: _,            // already inside atomics (Bus::new wires them)
        irq_pending: _,           // already inside atomics
        irq_pending_dirty: _,     // dropped: swap(0) protocol makes dirty-flag redundant
        bus_fault: _,             // already inside atomics
        bus_fault_addr: _,        // already inside atomics
        rcp_salt: _,              // already inside atomics
        rcp_salt_valid: _,        // already inside atomics
        rcp_count: _,             // already inside atomics
        decode_cache: _,          // per-core now; cores carry their own
        resets_state, ticks, timer0, timer1,
        uart0, spi0, i2c0, adc, pwm, io_bank0, pads_bank0,
        dma,
        clk_ref_ctrl, clk_sys_ctrl, clk_sys_div, clock_tree,
        pll_sys_regs, pll_usb_regs,
        pll_sys_lock_at_cycle, pll_usb_lock_at_cycle,
        rosc_regs, xosc_regs, gpio_hi_noise_state,
        qmi_regs, xip_cache_offset,
        gpio_in, gpio_external_in, gpio_external_mask,
        flash_loaded,
        peripheral_regs: _,       // legacy HashMap — Phase 2 typed-reg migration replaced it
        last_access_cycles: _,    // debug scalar; regenerated
        extra_wait_states: _,     // per-instruction scratch; lives on WorkerBus
        burst_mode: _,            // per-instruction scratch; lives on WorkerBus
        active_pc: _,             // per-instruction scratch; lives on WorkerBus
        trace_enabled: _,         // threaded tracing deferred to Phase 5
        trace_sink: _,            // threaded tracing deferred to Phase 5
        master_cycle: _,          // kept on ThreadedEmulator directly
    } = bus;

    let shared_mem = Arc::new(
        SharedMemory::from_memory(memory, boot_ram, xip_sram, flash_loaded));
    let shared_gpio = Arc::new(AtomicGpio::seed(
        sio.gpio_out, sio.gpio_oe, gpio_in,
        gpio_external_in, gpio_external_mask));
    let shared_sio = Arc::new(ThreadedSio::seed(&sio));
    // DIV + INTERP move onto the cores
    let [mut core0, mut core1] = [core0, core1];
    core0.sio_local = PerCoreSio::from_sio(&sio, 0);
    core1.sio_local = PerCoreSio::from_sio(&sio, 1);

    let peripherals = Arc::new(Peripherals {
        clocks: Mutex::new(ClocksState {
            clk_ref_ctrl, clk_sys_ctrl, clk_sys_div,
            tree: clock_tree,
            pll_sys: pll_sys_regs, pll_usb: pll_usb_regs,
            pll_sys_lock_at_cycle, pll_usb_lock_at_cycle,
            rosc: rosc_regs, xosc: xosc_regs,
            gpio_hi_noise_state,
        }),
        qmi:    Mutex::new(QmiState { regs: qmi_regs, xip_cache_offset }),
        resets: Mutex::new(ResetsState { state: resets_state }),
        apb:    Mutex::new(ApbState {
            uart0, spi0, i2c0, adc, pwm, io_bank0, pads_bank0,
        }),
        timers: Mutex::new(TimersState { ticks, timer0, timer1 }),
        dma:    Mutex::new(DmaState { dma }),
    });

    let shared = SharedState {
        memory: shared_mem,
        gpio: shared_gpio,
        sio: shared_sio,
        pio: Arc::new(ThreadedPio::new()),
        monitors: Arc::new(ExclusiveMonitors::new()),
        peripherals,
        atomics,   // shared with cores; Bus::new already built it
    };

    Self {
        shared,
        core0: Some(core0),
        core1: Some(core1),
        pio_blocks: Some(pio),
        step_quantum,
        master_cycle: clock.cycles,
        poisoned: false,
    }
}
```

### `run_quanta(n)`

```rust
pub fn run_quanta(&mut self, n: u64) {
    assert!(!self.poisoned,
        "ThreadedEmulator poisoned by prior worker panic; drop and rebuild");

    let core0 = self.core0.take().expect("run_quanta reentry");
    let core1 = self.core1.take().expect("run_quanta reentry");
    let blocks = self.pio_blocks.take().expect("run_quanta reentry");

    let barrier = Arc::new(SpinBarrier::new(4));
    let shared = self.shared.clone();
    let step_q = self.step_quantum;

    let h0 = spawn_worker(0, barrier.clone(), move |b| {
        core_worker_body(0, core0, shared.clone(), b, n, step_q)
    });
    // ... spawn_worker(1, ...) for core1
    // ... spawn_worker(2, ...) for pio
    // ... spawn_worker(3, ...) for coordinator
    let (r0, r1, rp, rc) = (h0.join(), h1.join(), hp.join(), hc.join());

    // Restore state from successfully-joined workers
    if let Ok(c) = r0 { self.core0 = Some(c); }
    if let Ok(c) = r1 { self.core1 = Some(c); }
    if let Ok(b) = rp { self.pio_blocks = Some(b); }
    if let Ok(m) = rc { self.master_cycle = m; }

    // Identify and report panicked worker(s)
    let panicked: Vec<&str> = [("core0", r0.is_err()),
                               ("core1", r1.is_err()),
                               ("pio",   rp.is_err()),
                               ("coordinator", rc.is_err())]
        .into_iter()
        .filter_map(|(name, err)| err.then_some(name))
        .collect();
    if !panicked.is_empty() {
        self.poisoned = true;
        panic!("worker thread(s) panicked: {}", panicked.join(", "));
    }
}
```

### `spawn_worker` generic helper

```rust
fn spawn_worker<F, R>(logical_core: usize,
                     barrier: Arc<SpinBarrier>,
                     body: F) -> JoinHandle<R>
where
    F: FnOnce(Arc<SpinBarrier>) -> R + Send + 'static,
    R: Send + 'static,
{
    thread::spawn(move || {
        pin_to_host_core(logical_core);
        let b2 = barrier.clone();
        match std::panic::catch_unwind(AssertUnwindSafe(move || body(b2))) {
            Ok(r) => r,
            Err(payload) => {
                barrier.poison();
                std::panic::resume_unwind(payload);
            }
        }
    })
}
```

One helper replaces V3's four `spawn_core_worker / spawn_pio_worker /
spawn_coordinator_worker / ...`. ~25 LOC total for panic recovery.

## 9. Worker bodies

### Core worker

```rust
fn core_worker_body(core_id: u8, mut core: CortexM33, shared: SharedState,
                    barrier: Arc<SpinBarrier>, n: u64, step_q: u32)
    -> CortexM33
{
    let mut bus = WorkerBus::new(core_id, shared.clone());
    let mut target: u64 = 0;
    let idx = core_id as usize;

    for _ in 0..n {
        target = target.wrapping_add(step_q as u64);

        let pending = shared.atomics.take_irq_pending(idx);
        if pending != 0 { core.ppb.merge_irq_pending(pending); }

        while !shared.atomics.is_halted(idx)
           && !shared.atomics.is_wfe_waiting(idx)
           && core.cycles < target
        {
            core.ppb.update_latest_cycles(core.cycles);
            core.step(&mut bus);
            if !bus.pending_cache_invalidations.is_empty() {
                core.invalidate_decode_cache_entries(
                    &bus.pending_cache_invalidations);
                bus.pending_cache_invalidations.clear();
            }
        }
        core.ppb.update_latest_cycles(core.cycles);

        if barrier.wait() == BarrierResult::Poisoned { return core; }
        if barrier.wait() == BarrierResult::Poisoned { return core; }
    }
    core
}
```

### PIO and Coordinator workers

Unchanged from V2 §8 (reproduced inline in the implementation for
clarity — not repeated here). Both wait at barrier 1 to start
coordinator phase, then barrier 2 to release all four for the next
quantum.

## 10. Memory barriers

`DMB`/`DSB` → `std::sync::atomic::fence(Ordering::SeqCst)` — orders
this core's stores vs its subsequent loads as seen by a peer-core
DMB. On x86 TSO this emits `mfence`.

`ISB` → `fence(SeqCst)` + `core.invalidate_decode_cache_all()`.
Flushes the executing core's decode cache entirely so any prior
write to executable memory (including cross-core writes that the
firmware explicitly ordered with `DSB` before `ISB`) is re-fetched.

Cross-core visibility: a DMB on one core does not force its stores
into the peer's observation window. Firmware must issue matching
DMBs on both sides (same as real hardware).

## 13. Risks

1. **Generic monomorphisation.** `CortexM33::step<B: CoreBus>` doubles
   code size for `core/execute*.rs` (~10 KLOC). Expect +~300 KB
   release `.exe`, +~1.2 MB debug, +~4 s `cargo build`. Acceptable.
2. **Bus destructure goes stale.** Exhaustive pattern makes additions
   a compile error — forced handling.
3. **Decode cache cross-core staleness.** Firmware-level DSB+ISB+IC
   IVAU required for cross-core SMC (matches ARM spec). Documented.
4. **Thread pinning.** < 4 cores = panic; exactly 4 cores = warn;
   SMT siblings not detected (pinning to logical 0–3 may straddle).
   Revisit in Phase 5 if benchmarks show contention.
5. **APB mutex contention.** Per-MMIO lock on tight loops. Phase 5
   measures; if real, split apb per-peripheral.
6. **`catch_unwind` covers panics, not deadlocks.** Worker infinite
   loops still hang. No watchdog in Phase 3.
7. **`pending_cache_invalidations` Vec allocation.** Preallocated
   capacity 16 covers STM (up to 13 regs) + some spare. Overflow
   heap-allocates once per step then stays grown. Negligible.
8. **Poisoned `ThreadedEmulator` requires rebuild.** After a worker
   panic, caller must drop and reconstruct via `from_emulator`. No
   in-place recovery.

## 14. Non-goals (deferred)

**Phase 4:**
- `ThreadedEmulator::run(pacer, duration, stop)` with Pacer.
- `ExitReason` enum + structured panic propagation (replaces poisoned
  flag).
- `reset()` that rebuilds workers.
- Threaded tracing (`Arc<Mutex<dyn Write>>`).
- Long-running worker model.

**Phase 5:**
- WFI wake check in coordinator + `ExitReason::BothWfi`.
- `set_quantum` runtime reconfig.
- `paced_bench --threaded --dual-core` + quantum sweep.
- PIO FIFO join reconfiguration.
- Threaded mode in `mdrp2350-app`.
- Real-firmware differential test.
- TSan Linux shim for primitives.

**Out of scope:**
- Hybrid per-core threaded/single mode.
- `ThreadedEmulator → Emulator` reverse conversion.
- Pipelined coordinator.
- Non-Windows, non-x86_64, < 4 host cores.
