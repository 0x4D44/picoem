# Phase 3: Interrupts, Faults, and Boot — Low-Level Design

Version: 0.2.0
Date: 2026-04-13
Parent: HLD Section 15, Phase 3

## 1. Purpose

Add exception handling (faults, SCB registers), coprocessor stubs, and
peripheral stubs — the minimum set required for the real RP2350 bootrom to
execute from reset and reach the "no flash detected" error path.

### Milestone

Load the real RP2350 bootrom (32 kB). Execute from reset. Bootrom initializes
clocks, probes for flash via BusFault, detects no flash. Integration test
verifies the PC lands in the expected fallback path.

### What the bootrom needs (and nothing more)

| Step | Bootrom action | Requires |
|------|---------------|----------|
| 1 | CPU reset: SP from ROM[0], PC from ROM[1] | Reset sequence |
| 2 | RCP instructions: stack canary salt write | CP7 stub |
| 3 | SYSINFO read: chip ID / platform | Peripheral stub |
| 4 | RESETS: bring peripherals out of reset | Peripheral stub |
| 5 | XOSC enable, PLL configure, clock switch | Peripheral stubs |
| 6 | Enable BusFault in SHCSR, install handler | SCB + exception entry |
| 7 | Attempt XIP read at 0x10000000 | BusFault delivery |
| 8 | BusFault handler runs, sets "no flash" flag | Exception return |
| 9 | Returns to thread code, sees flag, enters USB boot | — |

### What is deferred (not needed for milestone)

| Feature | Why not now | When |
|---------|------------|------|
| SysTick | Bootrom doesn't use SysTick during early boot | Phase 5 |
| NVIC external interrupt delivery | Bootrom only needs synchronous BusFault, not IRQs | Phase 5 |
| BASEPRI priority evaluation | Bootrom uses CPSID/CPSIE (PRIMASK) only | Phase 5 |
| WFI/WFE stall | Core 0 bootrom doesn't WFI; Core 1 permanently stalled | Phase 5 |
| Tail-chaining | Optimization, not functional requirement | Phase 8 |
| Lazy FP context save | No FP exceptions in boot path | Phase 7 |
| MPU enforcement | Bootrom doesn't configure MPU during early boot | Phase 5+ |

## 2. Key Design Decisions

### 2.1. PPB state lives on Bus

PPB (0xE0000000-0xE00FFFFF) is per-core but we place the state on Bus to
avoid modifying any load/store instruction handler. Bus dispatches PPB accesses
to the active core's PPB instance.

The active core is derived from the existing contention tracking state —
`contention_check_active == false` means core 0, `true` means core 1. No new
`active_core` field needed.

```rust
impl Bus {
    fn active_core(&self) -> usize {
        if self.contention_check_active { 1 } else { 0 }
    }
}
```

### 2.2. XIP without flash must trigger BusFault

**Critical discovery during review:** The bus currently returns 0 for XIP reads
when no flash is loaded. This means the bootrom would read zeros from XIP and
never take a BusFault — the entire "no flash" detection path is broken.

Solution: add a `flash_loaded: bool` flag to Bus (set by `load_flash()`). When
`flash_loaded == false` and region is 0x1 (XIP), set `bus_fault`.

**Open question:** Does the real bootrom detect flash absence via XIP BusFault,
or via QMI/QSPI status registers? Investigation needed: disassemble the first
50 instructions after the clock setup to confirm the detection mechanism. If
it's a QMI register check, we need a different stub. Design the bus_fault
mechanism either way — it's needed for general correctness.

### 2.3. BusFault signaling via latch

Add a sticky fault flag to Bus (same pattern as `extra_wait_states`):

```rust
bus_fault: bool,
bus_fault_addr: u32,
```

Set on: unmapped region access (0x3, 0x6-0xC, 0xF), and XIP access when no
flash is loaded. The core checks `bus.bus_fault()` after `decode_execute()`.

For multi-access instructions (LDM), the fault latches on first bad access.
Remaining accesses may partially complete — architecturally correct (M33 bus
faults can be imprecise).

### 2.4. EXC_RETURN detection — all PC-loading paths

EXC_RETURN must be checked in every instruction that loads PC from a data
value (not computed branches, which produce addresses, not magic values):

| Instruction | File:line | Needs check |
|-------------|-----------|-------------|
| BX Rm | execute.rs:384 | Yes |
| BLX Rm | execute.rs:402 | Yes (edge case but ARM mandates it) |
| MOV PC, Rm | execute.rs:362 | Yes |
| POP {PC} (Thumb-16) | execute.rs:678 | Yes |
| LDM {PC} (Thumb-32) | execute_thumb32.rs:627 | Yes |

Computed branches (B, BL, CBZ/CBNZ, TBB/TBH) cannot produce EXC_RETURN values
and do not need checks.

Detection: `val & 0xFF00_0000 == 0xFF00_0000` (all top 8 bits set). This is
the architecturally correct Armv8-M check — tighter than the 4-bit check in V1.

### 2.5. File organization

New files to keep Bus manageable:

| File | Contents |
|------|----------|
| `bus/ppb.rs` | Ppb struct, register read/write dispatch |
| `bus/peripherals.rs` | Peripheral stub methods (SYSINFO, RESETS, CLOCKS, XOSC, PLL) |
| `core/exceptions.rs` | Exception entry/return, fault delivery, priority evaluation |
| `core/coprocessor.rs` | CP0, CP4/5, CP7 stubs |

### 3.2. PPB dispatch

`Ppb::read32(offset)` matches on `offset & 0xFFFF`:

| Offset | Register | Read behavior |
|--------|----------|--------------|
| 0xE010-0xE01C | SysTick | Return 0 (stub) |
| 0xE100-0xE4FF | NVIC | Return 0 (stub) |
| 0xED00 | CPUID | 0x411F_D210 (Cortex-M33 r1p0, read-only) |
| 0xED04 | ICSR | Return icsr field |
| 0xED08 | VTOR | Return vtor |
| 0xED0C | AIRCR | Return aircr |
| 0xED10 | SCR | Return scr |
| 0xED14 | CCR | Return ccr |
| 0xED18-0xED20 | SHPR1-3 | Packed byte read from shpr[] |
| 0xED24 | SHCSR | Return shcsr |
| 0xED28 | CFSR | Return cfsr |
| 0xED2C | HFSR | Return hfsr |
| 0xED34 | MMFAR | Return mmfar |
| 0xED38 | BFAR | Return bfar |
| 0xED88 | CPACR | Return cpacr |
| _ | Unknown | Return 0 (silent, no fault) |

Write semantics: CFSR/HFSR are write-1-to-clear. NVIC/SysTick writes are
accepted but ignored. CPUID is read-only. Unknown offsets silently ignored.

### 3.3. Ppb defaults

Reset: VTOR=0, CCR=0x00000200 (STKALIGN=1), CPACR=0 (all CPs disabled).
All other fields zero.

**CPACR and CP7:** The RP2350 bootrom must write CPACR to enable CP7 before
its first RCP instruction. Investigation required: check if CPACR reset value
on RP2350 has CP7 pre-enabled, or if the bootrom writes CPACR first. If the
bootrom writes CPACR first, our default-to-0 is correct. If not, we may need
an RP2350-specific CPACR reset value. **Action: disassemble bootrom entry to
confirm, before Stage A implementation.**

## 4. Exception Entry and Return

New file: `crates/mdrp2354/src/core/exceptions.rs`

### 4.1. Exception entry

```rust
impl CortexM33 {
    /// Push exception frame, fetch vector, enter handler mode.
    /// Returns cycle cost (~12).
    pub fn enter_exception(&mut self, exc_num: u16, bus: &mut Bus) -> u32 {
        let use_psp = !self.regs.in_handler_mode()
                      && self.regs.active_sp_is_psp();
        let original_sp = if use_psp { self.regs.psp } else { self.regs.msp };

        // 8-byte align, with padding tracking (CCR.STKALIGN is RAO on M33)
        let aligned_sp = original_sp & !0x7;
        let frame_sp = aligned_sp - 32;
        let was_padded = aligned_sp != original_sp;

        // Encode IT state and alignment padding into stacked xPSR
        let mut stacked_xpsr = self.regs.xpsr | self.encode_it_to_xpsr();
        if was_padded {
            stacked_xpsr |= 1 << 9;  // Bit 9: frame was padded
        }

        // Push: R0, R1, R2, R3, R12, LR, ReturnAddress, xPSR
        bus.write32(frame_sp + 0,  self.regs.r[0]);
        bus.write32(frame_sp + 4,  self.regs.r[1]);
        bus.write32(frame_sp + 8,  self.regs.r[2]);
        bus.write32(frame_sp + 12, self.regs.r[3]);
        bus.write32(frame_sp + 16, self.regs.r[12]);
        bus.write32(frame_sp + 20, self.regs.lr());
        bus.write32(frame_sp + 24, self.return_address(exc_num));
        bus.write32(frame_sp + 28, stacked_xpsr);

        // Update SP
        if use_psp { self.regs.psp = frame_sp; }
        else { self.regs.msp = frame_sp; }

        // Set LR to EXC_RETURN (Armv8-M non-secure, no FP frame)
        // Bits: [31:24]=0xFF, [6]=S=1(secure), [5]=DCRS=1, [4]=FType=1(no FP),
        //       [3]=Mode(1=thread,0=handler), [2]=SPSEL(1=PSP,0=MSP)
        self.regs.r[14] = if self.regs.in_handler_mode() {
            0xFFFF_FFF1  // return to Handler, MSP
        } else if use_psp {
            0xFFFF_FFFD  // return to Thread, PSP
        } else {
            0xFFFF_FFF9  // return to Thread, MSP
        };

        // Fetch vector from table
        let vtor = bus.ppb[bus.active_core()].vtor;
        let vector = bus.read32(vtor.wrapping_add((exc_num as u32) * 4));
        self.regs.set_pc(vector & !1);

        // Enter handler mode: set IPSR, force MSP, clear IT state
        self.regs.xpsr = (self.regs.xpsr & !0x1FF) | (exc_num as u32);
        self.regs.control &= !2;  // handler mode always uses MSP
        self.regs.sync_sp_from_banked();
        self.it_state = 0;

        12  // exception entry cycles
    }
}
```

**Return address:** Synchronous faults (BusFault, UsageFault) return to the
faulting instruction (allowing retry). Synchronous calls (SVCall) and async
exceptions return to the next instruction. The `return_address(exc_num)` method
selects based on type: faults use `current_instr_addr`, calls use current PC.

### 4.2. Exception return

Triggered when any PC-loading instruction writes an EXC_RETURN magic value.

```rust
fn is_exc_return(val: u32) -> bool {
    val & 0xFF00_0000 == 0xFF00_0000
}

/// Pop exception frame, restore mode. Returns cycle cost (~12).
pub fn exit_exception(&mut self, exc_return: u32, bus: &mut Bus) -> u32 {
    // Capture the ACTIVE exception number BEFORE popping the frame
    let active_exc = self.regs.ipsr();

    let return_to_psp = exc_return & 0x4 != 0;
    let sp = if return_to_psp { self.regs.psp } else { self.regs.msp };

    // Pop frame
    self.regs.r[0]  = bus.read32(sp + 0);
    self.regs.r[1]  = bus.read32(sp + 4);
    self.regs.r[2]  = bus.read32(sp + 8);
    self.regs.r[3]  = bus.read32(sp + 12);
    self.regs.r[12] = bus.read32(sp + 16);
    self.regs.r[14] = bus.read32(sp + 20);
    let return_pc   = bus.read32(sp + 24);
    let return_xpsr = bus.read32(sp + 28);

    self.regs.set_pc(return_pc & !1);

    // Check alignment padding (bit 9 of stacked xPSR)
    let frame_size = if return_xpsr & (1 << 9) != 0 { 36 } else { 32 };

    // Restore xPSR (clear bit 9 — it's frame metadata, not real state)
    self.regs.xpsr = return_xpsr & !(1 << 9);
    self.it_state = Self::decode_it_from_xpsr(return_xpsr);

    // Deallocate frame (including padding word if present)
    if return_to_psp { self.regs.psp = sp + frame_size; }
    else { self.regs.msp = sp + frame_size; }

    // Restore SPSEL from EXC_RETURN
    self.regs.control = (self.regs.control & !2)
        | if return_to_psp { 2 } else { 0 };
    self.regs.sync_sp_from_banked();

    // Clear active exception (use captured active_exc, not stacked IPSR)
    bus.ppb[bus.active_core()].clear_active(active_exc as u16);

    12
}
```

### 4.3. IT state encoding

EPSR encodes IT in bits [26:25] (upper 2) and [15:10] (lower 6):

```rust
fn encode_it_to_xpsr(&self) -> u32 {
    let it = self.it_state as u32;
    ((it & 0xC0) << 19) | ((it & 0x3F) << 10)
}

fn decode_it_from_xpsr(xpsr: u32) -> u8 {
    (((xpsr >> 19) & 0xC0) | ((xpsr >> 10) & 0x3F)) as u8
}
```

## 5. Fault Delivery

### 5.1. Modified step()

```rust
pub fn step(&mut self, bus: &mut Bus) {
    if self.stall_cycles > 0 {
        self.stall_cycles -= 1;
        return;
    }

    let mut cycles = self.decode_execute(bus);

    // Synchronous bus fault from data access
    if bus.bus_fault() {
        // Read PPB values into locals to avoid borrow conflict
        let core = bus.active_core();
        let busfault_ena = bus.ppb[core].shcsr & (1 << 17) != 0;
        // Set CFSR: BFSR.PRECISERR (bit 9) + BFSR.BFARVALID (bit 15)
        bus.ppb[core].cfsr |= (1 << 9) | (1 << 15);
        bus.ppb[core].bfar = bus.bus_fault_addr();
        bus.clear_bus_fault();

        if busfault_ena {
            cycles = self.enter_exception(5, bus);  // BusFault
        } else {
            // Escalate to HardFault
            bus.ppb[bus.active_core()].hfsr |= 1 << 30;  // FORCED
            cycles = self.enter_exception(3, bus);
        }
    }

    // Synchronous fault from instruction (e.g. UsageFault on UDF)
    if let Some(fault) = self.pending_fault.take() {
        cycles = self.deliver_fault(fault, bus);
    }

    self.stall_cycles = cycles.saturating_sub(1);
}
```

Note: no SysTick tick, no NVIC interrupt scan, no WFI check. These are all
deferred to Phase 5. The step() additions for Phase 3 are minimal — just
bus fault check and pending fault delivery.

### 5.2. Priority evaluation (minimal for Phase 3)

```rust
/// Current execution priority. Only PRIMASK and active exception consulted.
/// BASEPRI and FAULTMASK deferred to Phase 5.
fn execution_priority(&self, bus: &Bus) -> i16 {
    let mut prio: i16 = 256;  // lowest (any exception can preempt)

    if self.regs.primask & 1 != 0 { prio = 0; }

    // Active exception raises effective priority
    // (min of mask priority and active exception priority)
    let ipsr = self.regs.ipsr();
    if ipsr > 0 {
        let exc_prio = bus.ppb[bus.active_core()].exception_priority(ipsr as u16);
        if exc_prio < prio { prio = exc_prio; }
    }

    prio
}

fn can_preempt(&self, exc_num: u16, bus: &Bus) -> bool {
    let exc_prio = bus.ppb[bus.active_core()].exception_priority(exc_num);
    exc_prio < self.execution_priority(bus)
}
```

Exception priority: HardFault = -1 (fixed). Exceptions 4-15 use
`shpr[(exc-4)]`, only bits [7:5] (8 priority levels). For Phase 3, external
IRQ priority lookup returns 0 (highest configurable) since NVIC arrays
aren't populated.

### 5.3. Fault types and delivery

```rust
pub(crate) enum Fault {
    UsageFault,   // undefined instruction, NOCP, div-by-zero (if CCR.DIV_0_TRP)
    BusFault,     // unmapped memory access (delivered via bus_fault flag, not here)
}
```

`deliver_fault()` checks if the corresponding handler is enabled in SHCSR,
sets CFSR bits, and calls `enter_exception` with the right vector. If disabled,
escalates to HardFault.

| Source | Fault | CFSR bits set |
|--------|-------|--------------|
| Undefined instruction | UsageFault | UFSR.UNDEFINSTR (bit 16) |
| Disabled coprocessor (CPACR) | UsageFault | UFSR.NOCP (bit 19) |
| Unmapped bus access | BusFault | BFSR.PRECISERR (bit 9) + BFARVALID (bit 15) |
| XIP access, no flash | BusFault | BFSR.PRECISERR (bit 9) + BFARVALID (bit 15) |

## 6. Coprocessor Stubs

New file: `crates/mdrp2354/src/core/coprocessor.rs`

```rust
pub(crate) fn thumb32_coprocessor(&mut self, hw0: u16, hw1: u16, bus: &mut Bus) -> u32 {
    let coproc = ((hw1 >> 8) & 0xF) as u8;

    // Check CPACR access permission (2 bits per CP)
    let cpacr = bus.ppb[bus.active_core()].cpacr;
    let access = (cpacr >> (coproc as u32 * 2)) & 0x3;
    if access == 0 {
        self.pending_fault = Some(Fault::UsageFault);  // NOCP
        return 0;
    }

    match coproc {
        0 => self.cp0_gpioc(hw0, hw1, bus),
        4 | 5 => 1,  // DCP: accept as NOP (see note below)
        7 => self.cp7_rcp(hw0, hw1),
        10 | 11 => self.fpu_execute(hw0, hw1, bus),
        _ => {
            self.pending_fault = Some(Fault::UsageFault);
            0
        }
    }
}
```

### 6.1. RCP (CP7) — Redundancy Coprocessor

State: `rcp_salt: u32` field on CortexM33.

- **MCR p7**: Store value as salt. Accept all encodings.
- **MRC p7**: Return `salt ^ 0xDEAD_BEEF` (deterministic dummy canary).
- **CDP p7**: Assertion check. Accept silently (never trigger NMI).

1 cycle per operation.

### 6.2. DCP (CP4/5) — Accept as NOP

The DCP uses RP2350-proprietary encodings for integer CRC/SHA operations, not
standard ARM floating-point. With no flash loaded, the bootrom likely never
reaches the DCP CRC code path. All CDP/MCR/MRC to CP4/5 are accepted as
1-cycle NOPs. If the integration test reveals DCP operations are actually
needed, we add state at that point.

### 6.3. GPIOC (CP0)

- **MRC p0**: Read GPIO pin state from SIO. Returns 0 (no external pins).
- **MCR p0**: Write GPIO output to SIO. Forward to `sio.gpio_out`.
- **MCRR/MRRC**: 64-bit GPIO access. Same behavior.

1 cycle per operation.

## 7. Peripheral Stubs for Boot

New file: `crates/mdrp2354/src/bus/peripherals.rs`

Dedicated match arms in the bus's 0x4 region handler, delegating to methods
in `peripherals.rs`. The existing `peripheral_regs` HashMap remains as
fallback for unclaimed APB addresses.

**Address decoding:** Use the existing pattern from bus/mod.rs — `addr & !0x3000`
strips atomic alias bits, then match on the canonical address. Peripheral base
is identified by bits [27:12] of the canonical address.

```rust
// In bus read32, region 0x4:
let canonical = addr & !0x3000;
let base = canonical & 0x0FFF_F000;  // peripheral base
let offset = canonical & 0x0000_0FFF; // register offset
match base {
    0x4000_0000 => self.sysinfo_read(offset),
    0x4002_0000 => self.resets_read(offset),
    0x4001_0000 => self.clocks_read(offset),
    0x4004_8000 => self.xosc_read(offset),
    0x4005_0000 => self.pll_sys_read(offset),
    _ => *self.peripheral_regs.get(&canonical).unwrap_or(&0),
}
```

For writes, same pattern: strip aliases first, then match base, then apply
XOR/SET/CLR logic for atomic alias writes.

### 7.1. SYSINFO (0x40000000) — read-only

| Offset | Name | Value |
|--------|------|-------|
| 0x000 | CHIP_ID | 0x0000_0002 (RP2350) |
| 0x004 | PACKAGE_SEL | 0x0000_0000 (RP2350A, QFN60) |
| 0x008 | PLATFORM | 0x0000_0001 (ASIC) |

### 7.2. RESETS (0x40020000)

State: `resets_state: u32` on Bus (default: 0x1FFF_FFFF, all in reset).

| Offset | Name | Behavior |
|--------|------|----------|
| 0x000 | RESET | Read/write. Bit=1 means in-reset |
| 0x004 | WDSEL | Ignored |
| 0x008 | RESET_DONE | Returns `~resets_state` (instant completion) |

Atomic-set/clear aliases work naturally: writing 0x40022008 (SET alias of
RESET_DONE) is handled by the existing alias logic in the bus write path.

| Offset | Name | Behavior |
|--------|------|----------|
| 0x030 | CLK_REF_CTRL | Accept writes |
| 0x038 | CLK_REF_SELECTED | Always 0x1 |
| 0x060 | CLK_SYS_CTRL | Accept writes |
| 0x068 | CLK_SYS_SELECTED | Always 0x1 |
| other | * | Accept writes, return 0 |

| Offset | Name | Behavior |
|--------|------|----------|

## 8. Reset Sequence

```rust
pub fn reset(&mut self) {
    let initial_sp = self.bus.memory.rom_read32(0);
    let reset_vector = self.bus.memory.rom_read32(4);

    // Core 0: execute from reset vector
    self.cores[0] = CortexM33::with_id(0);
    self.cores[0].regs.msp = initial_sp;
    self.cores[0].regs.r[13] = initial_sp;
    self.cores[0].regs.set_pc(reset_vector & !1);
    self.cores[0].regs.xpsr = XPSR_T;  // Thumb mode

    // Core 1: held (Phase 5)
    self.cores[1] = CortexM33::with_id(1);
    self.cores[1].halt();

    // Clear bus/PPB state
    self.bus.clear_bus_fault();
    self.bus.ppb = [Ppb::default(), Ppb::default()];
    self.bus.resets_state = 0x1FFF_FFFF;

    self.clock = Clock::new(self.clock.sys_clk_hz);
}
```

## 9. Instruction Handler Changes

### 9.1. SVC (execute.rs)

SVC is synchronous — enters exception immediately:

```rust
0xF => {
    // SVC #imm8 — synchronous, enters SVCall (exception 11) immediately
    self.enter_exception(11, bus)
}
```

Returns the cycle cost of exception entry (~12).

### 9.2. CPS (execute.rs)

```rust
0b0110 => {
    // CPS: bit 4 = im (0=IE, 1=ID), bit 1 = F, bit 0 = I
    let im = ((opcode >> 4) & 1) as u32;
    let affect_i = opcode & (1 << 0) != 0;  // bit 0 = I (PRIMASK)
    let affect_f = opcode & (1 << 1) != 0;  // bit 1 = F (FAULTMASK)
    if affect_i { self.regs.primask = im; }
    if affect_f { self.regs.faultmask = im; }
    1
}
```

Note: bit 0 = I (PRIMASK), bit 1 = F (FAULTMASK). V1 had these swapped.

### 9.3. EXC_RETURN in PC-loading instructions

All five PC-loading paths get the same guard:

```rust
// Pattern — applied in BX Rm, BLX Rm, MOV PC Rm, POP {PC}, LDM {PC}:
if Self::is_exc_return(val) {
    return self.exit_exception(val, bus);
}
self.regs.set_pc(val & !1);
```

### 9.4. Undefined instruction handlers

pub(crate) fn thumb32_undefined(&mut self, _hw0: u16, _hw1: u16) -> u32 {

## 10. Staging

Three stages, each independently testable.

### Stage A: PPB + Exceptions + Faults

Everything needed for the exception round-trip:

- New `bus/ppb.rs`: Ppb struct, read32/write32 dispatch
- Wire 0xE region in bus to `ppb[active_core()]`
- New `core/exceptions.rs`: enter_exception, exit_exception, IT encode/decode

**Tests:**

### Stage B: Coprocessors + Peripheral Stubs

Make the bus not crash on bootrom accesses:

- New `core/coprocessor.rs`: CP0, CP4/5, CP7
- New `bus/peripherals.rs`: SYSINFO, RESETS, CLOCKS, XOSC, PLL_SYS stubs
- CPACR enforcement in coprocessor dispatch
- `resets_state: u32` on Bus

**Tests:**
- MCR/MRC to CP7 executes (when CPACR allows)
- CP7 with CPACR=0 → UsageFault (NOCP)
- MRC from CP0 returns 0 (no GPIO)
- CDP/MCR/MRC to CP4/5 → NOP (no fault)
- SYSINFO.CHIP_ID = 0x00000002
- RESETS: deassert → RESET_DONE confirms
- XOSC.STATUS has STABLE bit, PLL_SYS.CS has LOCK bit
- CLK_SYS_SELECTED = 1

### Stage C: Reset + Bootrom Integration

- `Emulator::reset()` method
- Load real RP2350 bootrom binary
- Integration test

**Integration test strategy:**
1. Load bootrom binary (from SDK release)
2. Call `emu.reset()`
3. Run up to 10M cycles (safety limit)
4. If PC enters a tight loop or WFI, detect and stop
5. Check PC is in expected "no flash" fallback range

**Prerequisite:** Disassemble the RP2350 bootrom before implementation begins
to confirm: (a) the flash detection mechanism (XIP BusFault vs QMI register),
(b) the CPACR initialization sequence, (c) the "no flash" target PC address.
Without this, we're designing blind.

## 12. Known Limitations (acceptable for Phase 3)

- **No SysTick.** Deferred to Phase 5. PPB reads return 0.
- **No NVIC external interrupts.** Deferred to Phase 5. NVIC registers stub.
- **No BASEPRI evaluation.** Only PRIMASK checked. Phase 5.
- **No WFI/WFE.** Treated as NOP. Phase 5.
- **No tail-chaining.** Full pop+push on every exception transition. Phase 8.
- **No lazy FP context save.** Phase 7.
- **No MPU enforcement.** Phase 5+.
- **DCP is NOP.** If bootrom reaches DCP during no-flash path, integration test catches it.
- **Peripheral stubs return instant ready.** No PLL lock delay, no XOSC stabilization time.
- **Core 1 permanently stalled.** Phase 5.

## 13. Open Investigation Items

These must be resolved before implementation begins:

1. **Bootrom flash detection mechanism.** Disassemble bootrom to confirm it
   uses XIP read + BusFault (not QMI status register check).
2. **CPACR reset value / CP7 exemption.** Check if bootrom writes CPACR before
   first RCP instruction, or if RP2350 resets with CP7 enabled.
3. **"No flash" target address.** Identify the specific PC address/range for
   the integration test pass/fail check.
4. **DCP instruction encoding.** If needed: find RP2350 DCP documentation
   (SDK headers, datasheet appendix) for the proprietary encoding format.
