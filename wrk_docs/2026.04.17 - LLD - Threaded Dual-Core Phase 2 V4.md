# Threaded Dual-Core Phase 2 — Low-Level Design

Version: 4.0.0
Date: 2026-04-17
Parent HLD: 2026.04.16 - HLD - Threaded Dual-Core Emulation V5.md
Changes from V3: Add missing MMIO accessors that Phase 3 will need —
spinlock_bits, mtime_write, mtime_ctrl_read/write, mtimecmp_read/write.
Matches Phase 1 precedent (AtomicGpio exposes complete read/write API,
not "Phase 3 will add as needed").

## Scope

Four types that Phase 3 will compose into the 4-thread topology:

1. **SpscQueue** — lock-free SPSC ring buffer for u32 payloads
2. **SpinBarrier** — 4-way flat barrier
3. **ThreadedSio** — inter-core FIFOs, spinlocks, doorbells, MTIME
4. **ThreadedPio** — per-SM TX/RX FIFOs, atomic control, command queue

All in `crates/mdrp2350/src/threaded/`. No integration into Bus or
Emulator. No external dependencies. Concurrent tests via std::thread;
formal verification (TSan) deferred to Phase 3.

### Platform assumption

x86-64 TSO (same as Phase 1). Relaxed atomics compile to plain `mov`;
`compare_exchange` compiles to `lock cmpxchg`. No `cfg` gates on
these primitive types — the gate goes on `ThreadedEmulator` in Phase 3.

### Known Phase 2 limitation: panic deadlock

If a worker thread panics or takes a conditional early-exit before
reaching a SpinBarrier, the other threads spin forever. Phase 4 adds
`catch_unwind` + `barrier.poison()` to resolve the panic case. Phase 2
discipline:
- Tests must not panic in worker threads.
- Every code path in a worker must reach both barrier crossings
  (no `return`/`break` before the barrier).

## 1. SpscQueue

Lock-free single-producer single-consumer ring buffer for u32
payloads. Non-blocking try_push/try_pop (no spinning on full/empty).
Used by ThreadedSio (capacity 8) and ThreadedPio (capacity 4).

No external dependency. ~60 lines.

### Why not rtrb

A hand-rolled queue avoids an external dep and matches our exact
needs. Non-blocking semantics mean the Phase 0c capacity-8 slowdown
(tight spin loops) doesn't apply — try_push/try_pop fail immediately.

### Struct

```rust
pub struct SpscQueue {
    buffer: Box<[AtomicU32]>,
    head: AtomicU32,           // next write position (producer owns)
    tail: AtomicU32,           // next read position (consumer owns)
    capacity: u32,             // power of 2
    mask: u32,                 // capacity - 1
}
```

### Constructor

```rust
impl SpscQueue {
    pub fn new(capacity: u32) -> Self {
        assert!(capacity.is_power_of_two() && capacity >= 2);
        let mut buf = Vec::with_capacity(capacity as usize);
        for _ in 0..capacity { buf.push(AtomicU32::new(0)); }
        Self {
            buffer: buf.into_boxed_slice(),
            head: AtomicU32::new(0),
            tail: AtomicU32::new(0),
            capacity,
            mask: capacity - 1,
        }
    }
}
```

### Operations

```rust
pub fn try_push(&self, val: u32) -> bool {
    let head = self.head.load(Relaxed);
    let tail = self.tail.load(Acquire);
    if head.wrapping_sub(tail) >= self.capacity {
        return false;
    }
    self.buffer[(head & self.mask) as usize].store(val, Relaxed);
    self.head.store(head.wrapping_add(1), Release);
    true
}

pub fn try_pop(&self) -> Option<u32> {
    let tail = self.tail.load(Relaxed);
    let head = self.head.load(Acquire);
    if tail == head {
        return None;
    }
    let val = self.buffer[(tail & self.mask) as usize].load(Relaxed);
    self.tail.store(tail.wrapping_add(1), Release);
    Some(val)
}

pub fn len(&self) -> u32 {
    let head = self.head.load(Relaxed);
    let tail = self.tail.load(Relaxed);
    head.wrapping_sub(tail)
}

pub fn is_empty(&self) -> bool { self.len() == 0 }
pub fn is_full(&self) -> bool { self.len() >= self.capacity }

/// Reset to empty. Only safe when no concurrent push/pop.
pub fn clear(&self) {
    self.head.store(0, Relaxed);
    self.tail.store(0, Relaxed);
}
```

**Ordering:**
- Producer loads own head (Relaxed), peer's tail (Acquire); writes
  buffer (Relaxed), Release-stores head.
- Consumer: mirror with tail/head swapped.
- `len()`: Relaxed both — approximate count for status register.
- `clear()`: Relaxed — only called during coordinator phase or reset
  (no concurrent access).

**Fullness check:** `head.wrapping_sub(tail) >= capacity` uses unsigned
wrap-around arithmetic. Correct for all u32 values because capacity
is a power of 2 in [2, 2^31].

## 2. SpinBarrier

4-way flat barrier. Promoted from Phase 0c prototype
(`threading_micro.rs`). Identical to HLD §SpinBarrier spec.

### Struct

```rust
pub struct SpinBarrier {
    generation: AtomicU32,
    count: AtomicU32,
    parties: u32,
    poisoned: AtomicBool,
}

pub enum BarrierResult { Released, Poisoned }
```

### Implementation

```rust
impl SpinBarrier {
    pub fn new(parties: u32) -> Self {
        assert!(parties >= 2);
        Self {
            generation: AtomicU32::new(0),
            count: AtomicU32::new(0),
            parties,
            poisoned: AtomicBool::new(false),
        }
    }

    pub fn wait(&self) -> BarrierResult {
        if self.poisoned.load(Acquire) { return Poisoned; }
        let gen = self.generation.load(Acquire);
        let n = self.count.fetch_add(1, AcqRel) + 1;
        if n == self.parties {
            self.count.store(0, Relaxed);
            self.generation.store(gen.wrapping_add(1), Release);
        } else {
            loop {
                if self.poisoned.load(Acquire) { return Poisoned; }
                if self.generation.load(Acquire) != gen { break; }
                std::hint::spin_loop();
            }
        }
        Released
    }

    pub fn poison(&self) { self.poisoned.store(true, Release); }
}
```

Phase 0c measured ~425 ns mean round-trip (4-way), within the
<500 ns threshold.

## 3. ThreadedSio

Shared SIO state for threaded execution. Per-core state (divider,
interpolator) stays on the per-core bus view (Phase 3's WorkerBus).

### Struct

```rust
pub struct ThreadedSio {
    // Inter-core FIFOs (capacity 8, matching hardware)
    fifo_0to1: SpscQueue,       // core 0 produces, core 1 consumes
    fifo_1to0: SpscQueue,       // core 1 produces, core 0 consumes

    // Sticky FIFO error flags per core
    fifo_roe: [AtomicBool; 2],  // read-overflow-error (pop empty)
    fifo_wof: [AtomicBool; 2],  // write-overflow-fifo (push full)

    // Spinlocks: single 32-bit bitmask (one bit per lock)
    spinlocks: AtomicU32,

    // Doorbells: 4-bit pending field per core
    doorbells: [AtomicU32; 2],

    // Machine timer (coordinator advances, cores read)
    mtime: AtomicU64,
    mtime_ctrl: AtomicU32,      // bit 0 = enable
    mtimecmp: [AtomicU64; 2],   // per-core compare
}
```

**Spinlocks:** Single `AtomicU32` bitmask matching the current SIO's
`spinlock_bits: u32`. Each bit represents one of 32 hardware locks.
Claim via atomic `fetch_or` (test-and-set); release via
`fetch_and(!mask)`. Cache-friendly — all 32 locks in one word.

### Methods

```rust
impl ThreadedSio {
    pub fn new() -> Self { /* all zero-initialized */ }

    // --- FIFO ---

    /// Push to peer's RX FIFO. Sets WOF on failure.
    pub fn fifo_push(&self, writing_core: usize, val: u32) -> bool {
        debug_assert!(writing_core < 2);
        let q = match writing_core {
            0 => &self.fifo_0to1,
            _ => &self.fifo_1to0,
        };
        if q.try_push(val) {
            // NOTE: event_flag signaling for WFE wakeup is Phase 3's
            // responsibility — the caller (WorkerBus) sets it.
            true
        } else {
            self.fifo_wof[writing_core].store(true, Relaxed);
            false
        }
    }

    /// Pop from own RX FIFO. Sets ROE on failure.
    pub fn fifo_pop(&self, reading_core: usize) -> Option<u32> {
        debug_assert!(reading_core < 2);
        let q = match reading_core {
            0 => &self.fifo_1to0,
            _ => &self.fifo_0to1,
        };
        match q.try_pop() {
            Some(val) => Some(val),
            None => {
                self.fifo_roe[reading_core].store(true, Relaxed);
                None
            }
        }
    }

    /// Build FIFO_ST register value for the given core.
    /// Bit 0: VLD, Bit 1: RDY, Bit 2: WOF, Bit 3: ROE.
    pub fn fifo_st(&self, core: usize) -> u32 {
        debug_assert!(core < 2);
        let read_q = match core { 0 => &self.fifo_1to0, _ => &self.fifo_0to1 };
        let write_q = match core { 0 => &self.fifo_0to1, _ => &self.fifo_1to0 };
        let vld = if !read_q.is_empty() { 1 } else { 0 };
        let rdy = if !write_q.is_full()  { 2 } else { 0 };
        let wof = if self.fifo_wof[core].load(Relaxed) { 4 } else { 0 };
        let roe = if self.fifo_roe[core].load(Relaxed) { 8 } else { 0 };
        vld | rdy | wof | roe
    }

    /// Clear sticky bits (write-1-to-clear). Bits 0/1 (VLD/RDY) are
    /// read-only and silently ignored, matching hardware.
    pub fn fifo_st_clear(&self, core: usize, mask: u32) {
        debug_assert!(core < 2);
        if mask & 4 != 0 { self.fifo_wof[core].store(false, Relaxed); }
        if mask & 8 != 0 { self.fifo_roe[core].store(false, Relaxed); }
    }

    // --- Spinlocks ---

    /// Claim via atomic test-and-set (hardware READ semantics).
    /// Returns bitmask on success, 0 if already held.
    pub fn spinlock_claim(&self, id: usize) -> u32 {
        debug_assert!(id < 32);
        let mask = 1u32 << id;
        let prev = self.spinlocks.fetch_or(mask, Acquire);
        if prev & mask == 0 { mask } else { 0 }
    }

    /// Release a spinlock. Hardware semantics: writing ANY value to
    /// the SPINLOCK<N> register clears bit N (the written value is
    /// ignored). Our API omits the value since it's unused.
    pub fn spinlock_release(&self, id: usize) {
        debug_assert!(id < 32);
        self.spinlocks.fetch_and(!(1u32 << id), Release);
    }

    /// Read raw 32-lock bitmask (serves SPINLOCK_ST MMIO reads).
    pub fn spinlock_bits(&self) -> u32 {
        self.spinlocks.load(Relaxed)
    }

    // --- Doorbells ---

    pub fn doorbell_set(&self, core: usize, bits: u32) {
        debug_assert!(core < 2);
        self.doorbells[core].fetch_or(bits & 0xF, Relaxed);
    }
    pub fn doorbell_clear(&self, core: usize, bits: u32) {
        debug_assert!(core < 2);
        self.doorbells[core].fetch_and(!(bits & 0xF), Relaxed);
    }
    pub fn doorbell_read(&self, core: usize) -> u32 {
        debug_assert!(core < 2);
        self.doorbells[core].load(Relaxed) & 0xF
    }

    // --- MTIME (coordinator-only advance; all other ops are MMIO) ---

    pub fn mtime_read(&self) -> u64 {
        self.mtime.load(Relaxed)
    }

    /// Write MTIME directly (firmware init via MMIO).
    pub fn mtime_write(&self, val: u64) {
        self.mtime.store(val, Relaxed);
    }

    /// Advance MTIME by cycles. MUST be called only by the coordinator
    /// thread. No-op when mtime_ctrl bit 0 is clear.
    pub fn mtime_advance(&self, cycles: u64) {
        if self.mtime_ctrl.load(Relaxed) & 1 != 0 {
            self.mtime.fetch_add(cycles, Relaxed);
        }
    }

    pub fn mtime_ctrl_read(&self) -> u32 {
        self.mtime_ctrl.load(Relaxed)
    }

    pub fn mtime_ctrl_write(&self, val: u32) {
        self.mtime_ctrl.store(val, Relaxed);
    }

    pub fn mtimecmp_read(&self, core: usize) -> u64 {
        debug_assert!(core < 2);
        self.mtimecmp[core].load(Relaxed)
    }

    pub fn mtimecmp_write(&self, core: usize, val: u64) {
        debug_assert!(core < 2);
        self.mtimecmp[core].store(val, Relaxed);
    }

    pub fn mtime_check_match(&self, core: usize) -> bool {
        debug_assert!(core < 2);
        self.mtime.load(Relaxed) >= self.mtimecmp[core].load(Relaxed)
    }

    // --- Reset ---

    /// Reset all shared SIO state. Called during emulator reset
    /// (coordinator phase, no concurrent access).
    pub fn reset(&self) {
        self.fifo_0to1.clear();
        self.fifo_1to0.clear();
        for i in 0..2 {
            self.fifo_roe[i].store(false, Relaxed);
            self.fifo_wof[i].store(false, Relaxed);
            self.doorbells[i].store(0, Relaxed);
            self.mtimecmp[i].store(0, Relaxed);
        }
        self.spinlocks.store(0, Relaxed);
        self.mtime.store(0, Relaxed);
        self.mtime_ctrl.store(0, Relaxed);
    }
}
```

### What stays per-core (NOT in ThreadedSio)

- `divider: Divider` — only owning core accesses, no atomics needed
- `interp: [u32; 32]` — only owning core accesses

### Phase 3 responsibilities (NOT implemented here)

- **event_flag signaling** after FIFO push (WFE wakeup)
- **MTIME match → IRQ assertion** into NVIC
- **Doorbell → NVIC** propagation at quantum boundary

## 4. ThreadedPio

Shared PIO state. The PioBlock execution engine (SM stepping) stays
on the PIO worker thread — only communication interfaces are shared.

### Constants

```rust
const PIO_BLOCKS: usize = 3;
const SMS_PER_BLOCK: usize = 4;
const PIO_FIFO_DEPTH: u32 = 4;
```

### Struct

```rust
pub struct ThreadedPio {
    // TX FIFOs: CPU pushes, PIO thread pops
    tx: [[SpscQueue; SMS_PER_BLOCK]; PIO_BLOCKS],

    // RX FIFOs: PIO thread pushes, CPU pops
    rx: [[SpscQueue; SMS_PER_BLOCK]; PIO_BLOCKS],

    // Atomic control
    sm_enabled: [AtomicU8; PIO_BLOCKS],
    irq_flags: [AtomicU8; PIO_BLOCKS],
    dreq: [AtomicU8; PIO_BLOCKS],

    // Cold-path command queue (CPU → PIO thread)
    commands: std::sync::Mutex<Vec<PioCommand>>,
}
```

All SpscQueues initialized at capacity 4. **FIFO join (depth 8) is
deferred to Phase 3** — join is a setup-time operation and the Phase 3
coordinator can construct new queues during a barrier-protected pause.

**Construction:** SpscQueue has a `Box`, so it's neither Copy nor
Default-constructible via array literal. The constructor uses
`std::array::from_fn`:

```rust
impl ThreadedPio {
    pub fn new() -> Self {
        Self {
            tx: std::array::from_fn(|_|
                std::array::from_fn(|_| SpscQueue::new(PIO_FIFO_DEPTH))
            ),
            rx: std::array::from_fn(|_|
                std::array::from_fn(|_| SpscQueue::new(PIO_FIFO_DEPTH))
            ),
            sm_enabled: std::array::from_fn(|_| AtomicU8::new(0)),
            irq_flags: std::array::from_fn(|_| AtomicU8::new(0)),
            dreq: std::array::from_fn(|_| AtomicU8::new(0)),
            commands: std::sync::Mutex::new(Vec::new()),
        }
    }
}
```

### PioCommand

```rust
pub enum PioCommand {
    WriteInstrMem { block: u8, addr: u8, value: u16 },
    SetClkDiv { block: u8, sm: u8, int_div: u16, frac_div: u8 },
}
```

Two variants for Phase 2. Phase 3 will add remaining variants
(SetExecCtrl, SetShiftCtrl, SetPinCtrl, ForceExec, SmRestart,
ClkdivRestart) as MMIO dispatch demands them.

**Mutex is fine** because commands are infrequent (firmware setup
only). CPU workers send during execution phase; PIO worker drains
during coordinator phase (when no other thread is active). No
contention by design.

**Ordering:** Single-core MMIO ordering is preserved (each CPU thread
calls `send_command` sequentially). Cross-core ordering is NOT
guaranteed — if core 0 and core 1 both write to the same PIO register,
the Mutex serializes them arbitrarily. Firmware that depends on
precise cross-core PIO MMIO ordering will need external coordination
(which matches real hardware: concurrent writes to the same register
from two cores have arbitrary order).

### Methods

```rust
impl ThreadedPio {
    pub fn new() -> Self { /* all queues capacity 4, atomics zero */ }

    // --- CPU-side FIFO ---
    pub fn tx_push(&self, block: usize, sm: usize, val: u32) -> bool;
    pub fn rx_pop(&self, block: usize, sm: usize) -> Option<u32>;
    pub fn tx_level(&self, block: usize, sm: usize) -> u32;
    pub fn rx_level(&self, block: usize, sm: usize) -> u32;

    // --- PIO-thread-side FIFO ---
    pub fn tx_pop(&self, block: usize, sm: usize) -> Option<u32>;
    pub fn rx_push(&self, block: usize, sm: usize, val: u32) -> bool;

    // --- Atomic control ---
    pub fn read_sm_enabled(&self, block: usize) -> u8;
    pub fn write_sm_enabled(&self, block: usize, mask: u8);
    pub fn read_irq_flags(&self, block: usize) -> u8;
    pub fn write_irq_flags(&self, block: usize, flags: u8);
    pub fn clear_irq_flags(&self, block: usize, mask: u8);
    pub fn read_dreq(&self, block: usize) -> u8;
    pub fn write_dreq(&self, block: usize, val: u8);

    // --- Command queue ---
    pub fn send_command(&self, cmd: PioCommand);
    pub fn drain_commands(&self) -> Vec<PioCommand>;

    // --- Reset ---
    pub fn reset(&self);
}
```

### Phase 3 responsibilities (NOT implemented here)

- FIFO join/unjoin (reconfigure depth 4↔8)
- PioCommand dispatch into PioBlock state
- DREQ → DMA channel triggering
- IRQ flags → NVIC routing
