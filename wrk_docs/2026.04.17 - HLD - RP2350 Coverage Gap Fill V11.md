## §3 Per-item design

### §3.1 SYSINFO — fill read-only fields

**Current** (`bus/peripherals.rs:48`): `sysinfo_read` returns
`CHIP_ID = 0x0000_0002`, `PACKAGE_SEL = 0`, `PLATFORM = 1`.

**Target**: add the remaining read-only fields (`GITREF_RP2350`,
`CHIP_ID` revision field, additional PLATFORM bits) to match real
RP2354 silicon.

**Silicon scenario** (`silicon_periph_diff_rp2350`): one read at
reset, diff each u32.

**Unit test**: `sysinfo_reads_hardcoded_readonly_fields`.

### §3.2 POWMAN COUNT + MATCH

**Current** (`peripherals/powman.rs`): 64-bit COUNT/MATCH as
`AON_COUNT_LO/HI` (0x08 / 0x0C), `AON_MATCH_LO/HI` (0x10 / 0x14).
Storage-only. Warn-once on first write to COUNT/MATCH
(`peripherals/powman.rs:150, 168`).

**Implementation subtasks** beyond module work:
- Add `pub const RESET_POWMAN: u8 = 17;` to `bus/mod.rs` alongside
  the existing `RESET_*` constants (RP2350 datasheet §2.14.3
  RESETS_RESET table; bit 17 is the vacant slot between
  RESET_PWM = 16 and RESET_SPI0 = 18). Does not exist in tree
  today.
- Wire `POWMAN_BASE => Some(RESET_POWMAN)` into
  `reset_bit_for_base` at `bus/mod.rs:213` so the existing RESETS
  guard gates POWMAN MMIO correctly.
- POWMAN stays held-at-reset at bootrom exit (do not add to
  `RESETS_POST_BOOTROM`); firmware releases explicitly. This
  matches silicon.

**Target**:
- COUNT advances at 1 tick per POWMAN clock (XOSC / 4 assumed;
  pre-flight measures).
- MATCH fires `POWMAN_IRQ_TIMER` (NVIC line 45) when COUNT ==
  MATCH and MATCH_EN is set. One-shot.
- `POWMAN_IRQ_POW` (line 44) stays unwired.
- ARCHSEL warn-once on non-Arm write preserved (§10).

**Silicon scenario — MATCH fires IRQ line 45** (via
`silicon_isr_diff_rp2350`, same shape as `isr_ext_irq_timer0_cold`
in `isr_scenarios.rs`):

- **RESETS setup**: write
  `RESETS_RESET + ALIAS_CLR = (1 << RESET_POWMAN)` before POWMAN
  MMIO. `ALIAS_CLR = 0x3000` per `silicon_scenarios.rs:26`.
- **Vector table**: slot `16 + 45 = 61` → handler stub that
  writes `0xCAFE_BABE` to a memory marker and `bkpt #0`. Marker
  pre-seeded to `0xDEAD_BEEF` by setup to distinguish "handler
  ran" from "zeroed SRAM".
- **Main**: enable POWMAN; set `AON_MATCH_LO = 100`,
  `MATCH_EN = 1`; set NVIC ISER1 bit 13 (IRQ 45 is bank 1;
  ISER1 at `0xE000_E104`, **not** ISER0).
- **Observable**: memory marker == `0xCAFE_BABE`; CYCCNT delta
  within a pre-flight-measured window.
- **`max_sysclks`**: `K * sys_per_tick + margin`; numeric value
  filled in at implementation time from pre-flight (§8).
  Budgeted ~6000 under the XOSC/4 assumption.

**Unit tests**:
- `powman_count_advances_at_expected_rate` — tick N sys_clks,
  assert `count == N / sys_per_tick`.
- `powman_match_pends_nvic_line_45` — drive via the emulator's
  own bus with PRIMASK=1 (blocks dispatch via `can_preempt` in
  `exceptions.rs`; doesn't block ISPR latching); read ISPR1 bit
  13. Validates NVIC bank math without silicon.
- `powman_match_enters_emulator_handler` — PRIMASK=0, a 16-slot
  vector table in SRAM. **Test must write VTOR to point at the
  SRAM table** (both S_VTOR at `0xE000_ED08` and NS_VTOR at
  `0xE002_ED08`, matching `isr_scenarios.rs:1511-1534`) —
  otherwise IRQ 45 fetches slot 61 from address 0 (ROM) and the
  test silently passes for the wrong reason. Assert the emulator
  takes the exception and PC lands at the SRAM handler.
- `powman_archsel_non_arm_write_warns_once` — regression
  tripwire for the RISC-V track (§10).

**Implementation**: add `aon_count: u64`, `aon_match: u64`,
`match_en: bool` to `PowmanRegs`. Drive from `tick_peripherals`.
Drop the warn-once on COUNT/MATCH writes. IRQ via
`raise_irqs_u64(1u64 << 45)` — `raise_irqs_u64` in `bus/mod.rs`
takes a u64 bitmask.

### §3.3 GLITCH_DETECTOR — ARM readback

**Current** (`peripherals/inert.rs:128, 139`): HashMap storage;
`STATUS.ARM` forced 0 on read; `TRIG_STATUS` W1C.

**Target**: `STATUS.ARM` reads back the value written to
`CTRL.ARM`. `TRIG_STATUS` stays at 0. No IRQ.

**Silicon scenario** (`silicon_periph_diff_rp2350`): setup writes
`CTRL.ARM = 1`; observe `STATUS.ARM = 1`, `TRIG_STATUS = 0`.

**Unit test**: `glitch_detector_arm_readback_tracks_ctrl`.

### §3.4 TBMAN — PLATFORM selector

**Current** (`peripherals/inert.rs:45`): HashMap storage only.

**Target**: PLATFORM field reads the silicon-observed value
(assumption `0b01`; pre-flight confirms).

**Silicon scenario** (`silicon_periph_diff_rp2350`): one-shot
read of `TBMAN_BASE + 0x00` at reset.

**Unit test**: `tbman_platform_reads_silicon_value`.
