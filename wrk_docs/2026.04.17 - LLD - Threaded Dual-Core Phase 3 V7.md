## Changes from V6

Review round 6 found 5 real gaps + 3 nits. All addressed.

**Real gaps:**

- **`master_cycle` is visible to CPU workers.** `bus/peripherals.rs`
  at `:273`, `:283`, `:294`, `:305` all feed `self.master_cycle` into
  the PLL CS read path (LOCK bit derived from `master_cycle >=
  pll_*_lock_at_cycle`). V6 kept `master_cycle` only on
  `ThreadedEmulator`, so CPU workers had no route to it — PLL-waiting
  firmware would hang forever. V7: `master_cycle: Arc<AtomicU64>`
  lives on `SharedState`; coordinator advances it each quantum with
  `fetch_add(step_q, Release)`; CPU workers read with
  `load(Acquire)` (lock-free). See §3 and §9.

- **§6 SIO wake hooks scoped to parity with current single-threaded
  behavior.** V6 wired FIFO-push→`IRQ_SIO_IRQ_FIFO`,
  doorbell-set→`IRQ_SIO_IRQ_BELL`, MTIME-match→`IRQ_SIO_IRQ_MTIMECMP`.
  Spot-check of `sio/mod.rs` + `bus/mod.rs:2184-2186` shows the
  baseline does **none** of these — FIFO push sets `event_flag[peer]`
  only (no IRQ); doorbell and MTIME just mutate bits. Phase 2 V4's
  "Phase 3 responsibilities" list was aspirational. V6's additions
  only handled the rising edge — level-triggered SIO_IRQ_FIFO would
  get stuck asserted because no code de-asserted on FIFO pop. V7
  drops all three IRQ hooks; keeps the `event_flag[peer]` signal
  on FIFO push (WFE wake, which is parity). Hardware-accurate SIO
  IRQ wiring is a separate future HLD with both rising + falling
  edges.

- **STREX write-success path clarified in §4.** V6 claimed STREX's
  success path "also goes through `write32`". Wrong — Phase 1 V3 §3
  STREX protocol uses `shared_memory.cas32` directly, bypassing
  `WorkerBus::write32` and therefore `pending_cache_invalidations`.
  V7 spec: "STREX on success calls `shared_memory.cas32` +
  `monitors.snoop(addr)` directly. It does NOT queue a decode-cache
  invalidation — STREX into exec memory is unsupported in Phase 3;
  firmware must issue ISB manually."

- **WFE instruction-level migration spelled out.** `core/mod.rs:301`
  (`wfe`) currently reads `bus.event_flag[core]` and writes
  `self.wfe_waiting`. V6 added the worker-loop wake check but never
  said the instruction body also changes. V7 §12 "Files changed"
  explicitly names: WFE body changes from `bus.event_flag[core]`
  load/store to `self.atomics.event_flag_consume(self.core_id)` +
  `self.atomics.set_wfe_waiting(self.core_id)`; `wfe_waiting` field
  on `CortexM33` deleted (now lives in `CoreAtomics`).

- **Atomic orderings pinned in §2.** `event_flag_consume` uses
  `swap(false, AcqRel)` — so any store the SEV-caller made before
  `sev_both` is visible after the consume returns true. `sev_both`
  uses `store(true, Release)` on both event_flags. Benign on x86
  TSO, correct on weaker models if ever ported.

**Nits:**

- Stale `IRQ_SIO_IRQ_FIFO_PROC{peer}` notation goes away with the
  scope reduction above.
- §13 gains a note that Phase 1 V3's "snoop/set monitor race" is
  resolved by the barrier protocol (LDREX runs in execution phase;
  coordinator-side DMA snoop runs in coordinator phase; barrier 1
  orders them).
- §13 gains a note that PLL LOCK transitions are observed at
  quantum boundaries (up to `step_q` cycles of jitter). Firmware
  busy-polling for lock will see quantised transitions.

## Scope

Compose Phase 1/2 primitives into a 4-thread runtime:

1. `CoreBus` trait — MMIO surface `CortexM33` uses on the bus.
2. `CoreAtomics` — `Arc`'d cross-core per-core state.
3. `SharedState` — `Arc` bundle (includes shared `master_cycle`).
4. `WorkerBus` — CPU-thread view (impls `CoreBus`).
5. `PioBus` — PIO thread's view, owns `PioBlock`s.
6. `PerCoreSio` — divider + interpolator on each `CortexM33`.
7. `Peripherals` — mutex-protected coordinator-owned state.
8. `ThreadedEmulator::from_emulator` + `run_quanta(n)`.
9. Windows thread pinning (cores 0/1/2/3 default, mask-overridable).

Deferred to Phases 4/5: see §14.

### Platform gate

`#[cfg(all(target_arch = "x86_64", target_os = "windows"))]` on
`ThreadedEmulator`, `WorkerBus`, `PioBus`, `worker::*`,
`pin_to_host_core`. `CoreBus` / `CoreAtomics` / `PerCoreSio` /
`SharedState` are unconditional (visible to `CortexM33`, which builds
on all targets).

## 1. `CoreBus` trait

```rust
pub trait CoreBus {
    fn read8(&mut self,  addr: u32, core: u8) -> u8;
    fn read16(&mut self, addr: u32, core: u8) -> u16;
    fn read32(&mut self, addr: u32, core: u8) -> u32;
    fn write8(&mut self,  addr: u32, val: u8,  core: u8);
    fn write16(&mut self, addr: u32, val: u16, core: u8);
    fn write32(&mut self, addr: u32, val: u32, core: u8);

    fn set_active_pc(&mut self, pc: u32, core: u8);

    // Per-core bus fault observation.
    fn bus_fault(&self, core: u8) -> bool;
    fn bus_fault_addr(&self, core: u8) -> u32;
    fn clear_bus_fault(&mut self, core: u8);

    // Wait-state accounting (no core arg — one instruction in flight
    // per bus instance at a time).

    fn add_extra_wait_states(&mut self, n: u32);
    fn take_extra_wait_states(&mut self) -> u32;
```

(§2) and reached via `self.atomics` directly from `CortexM33`.

`CortexM33::step<B: CoreBus>(&mut self, bus: &mut B)` and all helpers
become generic. Monomorphisation acknowledged in §13.

### Key methods (orderings explicit)

```rust
impl CoreAtomics {
    pub fn assert_irq(&self, core: usize, irq: u32);
    pub fn assert_irq_shared(&self, irq: u32);
    pub fn clear_irq(&self, core: usize, irq: u32);

    /// Non-zero return replaces the old `irq_pending_dirty` flag.
    pub fn take_irq_pending(&self, core: usize) -> u64 {
        self.irq_pending[core].swap(0, AcqRel)
    }

    /// SEV writes both cores' event_flag with Release ordering so
    /// pre-SEV stores on the caller side are visible after a peer's
    /// `event_flag_consume` returns true.
    pub fn sev_both(&self) {
        self.event_flag[0].store(true, Release);
        self.event_flag[1].store(true, Release);
    }

    /// WFE consume: AcqRel swap-to-false — pairs with `sev_both`'s
    /// Release to publish the SEV-caller's memory effects.
    pub fn event_flag_consume(&self, core: usize) -> bool {
        self.event_flag[core].swap(false, AcqRel)
    }

    pub fn set_halted(&self, core: usize);
    pub fn clear_halted(&self, core: usize);
    pub fn is_halted(&self, core: usize) -> bool;
    pub fn set_wfe_waiting(&self, core: usize);
    pub fn clear_wfe_waiting(&self, core: usize);
    pub fn is_wfe_waiting(&self, core: usize) -> bool;

    pub fn rcp_count_set(&self, value: u32);
    pub fn rcp_count_check(&self, expected: u32) -> Result<(), u32> {
        loop {
            let cur = self.rcp_count.load(Acquire);
            if cur != expected { return Err(cur); }
            match self.rcp_count.compare_exchange(
                cur, cur.wrapping_add(1), AcqRel, Acquire)
            {
                Ok(_)  => return Ok(()),
                Err(_) => continue,
            }
        }
    }

    pub fn set_bus_fault(&self, core: usize, addr: u32);
    pub fn clear_bus_fault(&self, core: usize);
}
```

### Address-class routing

| Region (`addr >> 28`) | Target |
|---|---|
| `0x0` ROM / `0x1` XIP | `shared.memory.read*` |
| `0x2` SRAM | `shared.memory.read/write*`; writes record `self.pending_cache_invalidations.push(addr)` |
| `0x4` APB | sub-decode by offset → `peripherals.clocks / qmi / resets / apb / timers / dma / legacy` |
| `0x5` AHB | `peripherals.dma` |
| `0xD` SIO | `shared.sio.*` / `shared.gpio.*` / `shared.atomics.*` (DIV/INTERP intercepted on `CortexM33` — §6) |
| `0xE` PPB | unreachable (intercepted on `CortexM33`) |

Unresolved APB addresses fall through to `peripherals.legacy`
(the HashMap of untyped peripheral registers; 9-11 live call sites
in `bus/mod.rs`). Phase 5 migrates the remaining sites and deletes
the field.

PLL CS read-path specifics: `ClocksState` exposes a helper that
takes `&self, current_master_cycle: u64` and returns the PLL CS
value (LOCK bit derived from `current_master_cycle >=
pll_*_lock_at_cycle`). WorkerBus's APB dispatch does
`shared.master_cycle.load(Acquire)` then takes the clocks lock
and calls the helper — the master-cycle read is outside the lock
so a concurrent coordinator update doesn't serialize with the CPU.

### Peer-monitor snoop on every write

```rust
impl CoreBus for WorkerBus {
    fn write32(&mut self, addr: u32, val: u32, core: u8) {
        // ...region dispatch, including shared.memory.write32 for SRAM...
        if matches!(addr >> 28, 0x0 | 0x1 | 0x2) {
            self.pending_cache_invalidations.push(addr);
        }
        self.shared.monitors.snoop(addr);
    }
    // write16/write8 mirror: region dispatch, push invalidation for exec,
    // snoop peer monitor.
}
```

ARMv8-M §A3.4: any store to a word for which the peer holds an
exclusive monitor invalidates that monitor.

### STREX success path

STREX is NOT routed through `WorkerBus::write32`. The execute-site
calls `shared.memory.cas32(addr, expected, new_val)` directly on
success, then `shared.monitors.snoop(addr)` to invalidate the
peer's reservation, then `shared.monitors.clear(self.core_id)`
+ clears the local `exclusive_address`. Because STREX bypasses
WorkerBus, its success write does NOT push to
`pending_cache_invalidations`. **STREX into exec memory is
unsupported in Phase 3** — firmware must issue ISB manually after
any STREX to a range it intends to execute. This matches ARM's
architectural position (STREX to exec memory is atypical and
deadlock-prone).

### Decode-cache invalidation (per-core, self-only)

After each `core.step`, the worker drains
`bus.pending_cache_invalidations` and calls
`core.invalidate_decode_cache_entries(&addrs)`. Vec capacity
pre-allocated to 16.

Cross-core SMC is NOT automatically handled — matches ARM spec
requirement that firmware issue `DSB; ISB; IC IVAU` cross-core.

### MMIO reads with side effects

Same list as V3 §4 — routed through the same components, so the same
atomicity story applies.

## 5. `PioBus`

```rust
pub struct PioBus {
    shared: SharedState,
    blocks: [PioBlock; 3],
}
```

Per-quantum PIO-thread loop:

1. `shared.pio.drain_commands()` → apply each command to local
   `PioBlock`s.
2. For each active SM, step one PIO cycle × `step_quantum` times.
3. Update `shared.pio.irq_flags` / `dreq`. PIO IRQ flags raised
   this quantum are mirrored into core NVICs via
   `shared.atomics.assert_irq_shared(PIO_IRQ_*)` at PIO worker
   barrier exit — implementer mirrors the existing Bus → NVIC
   path from single-threaded dispatch. If the single-threaded
   path doesn't route PIO IRQs (verify during impl), this hook
   is omitted.

One-quantum delay on CPU→PIO writes. FIFO join deferred to Phase 5.

## 6. SIO ownership split + WFE wake hook

### `ThreadedSio` (Phase 2)

Covers: FIFOs, spinlocks, doorbells, MTIME, MTIMECMP. Plus
`AtomicGpio` for GPIO_IN/OUT/OE.

### `PerCoreSio` (per-core, on `CortexM33`)

```rust
pub struct PerCoreSio {
    pub divider: Divider,
    pub interp:  [Interp; 2],
}
```

Defined in `crates/mdrp2350/src/core/mod.rs`. Only the storage
location moves; existing `Divider` + `Interp` bodies unchanged.

### SIO MMIO dispatch

`WorkerBus::read32/write32` at `0xD000_...`:

| Category | Route | Phase 3 hook |
|---|---|---|
| GPIO in/out/oe, CPUID, MTIME/MTIMECMP | `shared.gpio` / `shared.sio.mtime*` / constant CPUID | none |
| FIFO_ST / FIFO_WR / FIFO_RD | `shared.sio.fifo_*` | **On successful `fifo_push(writer, val)`: `atomics.event_flag[peer].store(true, Release)`.** Matches `bus/mod.rs:2184-2186` single-threaded path — sets the WFE wake signal, nothing else. |
| SPINLOCK<0..31> | `shared.sio.spinlocks` | none |
| DOORBELL_OUT_* / DOORBELL_IN_* | `shared.sio.doorbell_*` | none (parity — current `sio/mod.rs:152-154` just mutates bits) |
| DIV_* / INTERP*_* | **intercepted on `CortexM33`** — routes to `self.sio_local.*` | none |

**Scope note**: SIO_IRQ_FIFO / SIO_IRQ_BELL / SIO_IRQ_MTIMECMP
assertions are NOT wired in Phase 3, because the current
single-threaded baseline does not wire them either (verified against
`sio/mod.rs`, `bus/mod.rs:2184-2186`, and a grep of production
`assert_irq_core` sites — only tests). Adding these would require
both rising-edge and falling-edge handling (level-triggered on
VLD/BELL_IN/MTIME>=MTIMECMP) and is a separate future HLD, not
Phase 3 scope.

The DIV/INTERP intercept is a one-line branch in
`CortexM33::bus_read32/write32` wrappers.

### CP0 coprocessor path

`coprocessor.rs` today takes `&mut self: CortexM33, &mut Bus`. Under
V7 the bus arg becomes `&mut B: CoreBus`. Additionally:

- ~30 dispatch arms split by route.
- ~5 function signatures change (`cp0_read/write`, `cp0_mcr/mrc`,
  dispatch hub) — `&mut Bus` → `&mut B: CoreBus`.
- DIV / INTERP CP0 regs route to `&mut self.sio_local` — requires a
  local-first match-then-fall-through split (~20 LOC).

### `from_emulator`

```rust
pub fn from_emulator(emu: Emulator) -> Self {
    let n = std::thread::available_parallelism()
        .map(|n| n.get()).unwrap_or(1);
    assert!(n >= 4,
        "ThreadedEmulator requires >= 4 host cores (found {})", n);
    if n == 4 {
        tracing::warn!("exactly 4 host cores — workers will contend \
                        with OS/other processes; >= 5 recommended");
    }

    let Emulator { cores, bus, clock, step_quantum } = emu;
    let [core0, core1] = cores;

    // Exhaustive destructure — new Bus fields force a compile error.
    // Dropped fields: event_flag, irq_pending, irq_pending_dirty,
    // bus_fault*, rcp_*, decode_cache (per-core on CortexM33 now).
    let Bus {
        memory, boot_ram, xip_sram,
        sio, pio,
        atomics,
        resets_state, ticks, timer0, timer1,
        uart0, spi0, i2c0, adc, pwm, io_bank0, pads_bank0,
        dma,
        clk_ref_ctrl, clk_sys_ctrl, clk_sys_div, clock_tree,
        pll_sys_regs, pll_usb_regs,
        pll_sys_lock_at_cycle, pll_usb_lock_at_cycle,
        rosc_regs, xosc_regs, gpio_hi_noise_state,
        qmi_regs, xip_cache_offset,
        gpio_in, gpio_external_in, gpio_external_mask,
        flash_loaded,
        peripheral_regs,          // LIVE HashMap — routed to Peripherals.legacy
        last_access_cycles: _,
        extra_wait_states: _,
        burst_mode: _,
        active_pc: _,
        trace_enabled: _,
        trace_sink: _,
        master_cycle,             // seed the shared AtomicU64 with this
    } = bus;

    let shared_mem = Arc::new(
        SharedMemory::from_memory(memory, boot_ram, xip_sram, flash_loaded));
    let shared_gpio = Arc::new(AtomicGpio::seed(
        sio.gpio_out, sio.gpio_oe, gpio_in,
        gpio_external_in, gpio_external_mask));
    let shared_sio = Arc::new(ThreadedSio::seed(&sio));
    let [mut core0, mut core1] = [core0, core1];
    core0.sio_local = PerCoreSio::from_sio(&sio, 0);
    core1.sio_local = PerCoreSio::from_sio(&sio, 1);

    let peripherals = Arc::new(Peripherals {
        clocks: Mutex::new(ClocksState {
            clk_ref_ctrl, clk_sys_ctrl, clk_sys_div,
            tree: clock_tree,
            pll_sys: pll_sys_regs, pll_usb: pll_usb_regs,
            pll_sys_lock_at_cycle, pll_usb_lock_at_cycle,
            rosc: rosc_regs, xosc: xosc_regs,
            gpio_hi_noise_state,
        }),
        qmi:    Mutex::new(QmiState { regs: qmi_regs, xip_cache_offset }),
        resets: Mutex::new(ResetsState { state: resets_state }),
        apb:    Mutex::new(ApbState {
            uart0, spi0, i2c0, adc, pwm, io_bank0, pads_bank0,
        }),
        timers: Mutex::new(TimersState { ticks, timer0, timer1 }),
        dma:    Mutex::new(DmaState { dma }),
        legacy: Mutex::new(peripheral_regs),
    });

    let shared = SharedState {
        memory: shared_mem,
        gpio: shared_gpio,
        sio: shared_sio,
        pio: Arc::new(ThreadedPio::new()),
        monitors: Arc::new(ExclusiveMonitors::new()),
        peripherals,
        atomics,
        // Seed shared master_cycle from the single-threaded Bus state,
        // so PLL lock deadlines carried across the conversion remain
        // on the same timeline.
        master_cycle: Arc::new(AtomicU64::new(master_cycle.max(clock.cycles))),
    };

    Self {
        shared,
        core0: Some(core0),
        core1: Some(core1),
        pio_blocks: Some(pio),
        step_quantum,
        thread_mask: [0, 1, 2, 3],
        poisoned: false,
    }
}

pub fn with_thread_mask(mut self, mask: [usize; 4]) -> Self {
    self.thread_mask = mask;
    self
}

pub fn master_cycle(&self) -> u64 {
    self.shared.master_cycle.load(Ordering::Acquire)
}
```

### `run_quanta(n)`

```rust
pub fn run_quanta(&mut self, n: u64) {
    assert!(!self.poisoned,
        "ThreadedEmulator poisoned by prior worker panic; drop and rebuild");

    let core0 = self.core0.take().expect("run_quanta reentry");
    let core1 = self.core1.take().expect("run_quanta reentry");
    let blocks = self.pio_blocks.take().expect("run_quanta reentry");

    let barrier = Arc::new(SpinBarrier::new(4));
    let shared = self.shared.clone();
    let step_q = self.step_quantum;
    let mask = self.thread_mask;

    let h0 = spawn_worker(mask[0], barrier.clone(), {
        let s = shared.clone();
        move |b| core_worker_body(0, core0, s, b, n, step_q)
    });
    let h1 = spawn_worker(mask[1], barrier.clone(), {
        let s = shared.clone();
        move |b| core_worker_body(1, core1, s, b, n, step_q)
    });
    let hp = spawn_worker(mask[2], barrier.clone(), {
        let s = shared.clone();
        move |b| pio_worker_body(blocks, s, b, n, step_q)
    });
    let hc = spawn_worker(mask[3], barrier.clone(), {
        let s = shared.clone();
        move |b| coordinator_worker_body(s, b, n, step_q)
    });
    let (r0, r1, rp, rc) = (h0.join(), h1.join(), hp.join(), hc.join());

    if let Ok(c) = r0 { self.core0 = Some(c); }
    if let Ok(c) = r1 { self.core1 = Some(c); }
    if let Ok(b) = rp { self.pio_blocks = Some(b); }
    // Coordinator worker returns (); master_cycle lives in shared.

    let panicked: Vec<&str> = [("core0", r0.is_err()),
                               ("core1", r1.is_err()),
                               ("pio",   rp.is_err()),
                               ("coordinator", rc.is_err())]
        .into_iter()
        .filter_map(|(name, err)| err.then_some(name))
        .collect();
    if !panicked.is_empty() {
        self.poisoned = true;
        panic!("worker thread(s) panicked: {}", panicked.join(", "));
    }
}
```

## 9. Worker bodies

### Core worker (with WFE wake)

```rust
fn core_worker_body(core_id: u8, mut core: CortexM33, shared: SharedState,
                    barrier: Arc<SpinBarrier>, n: u64, step_q: u32)
    -> CortexM33
{
    let mut bus = WorkerBus::new(core_id, shared.clone());
    let mut target: u64 = 0;
    let idx = core_id as usize;

    for _ in 0..n {
        target = target.wrapping_add(step_q as u64);

        // WFE wake: if a peer fired SEV while we were parked, consume
        // the event and clear wfe_waiting. WFI wake remains Phase 5.
        if shared.atomics.is_wfe_waiting(idx)
           && shared.atomics.event_flag_consume(idx)
        {
            shared.atomics.clear_wfe_waiting(idx);
        }

        let pending = shared.atomics.take_irq_pending(idx);
        if pending != 0 { core.ppb.merge_irq_pending(pending); }

        while !shared.atomics.is_halted(idx)
           && !shared.atomics.is_wfe_waiting(idx)
           && core.cycles < target
        {
            core.ppb.update_latest_cycles(core.cycles);
            core.step(&mut bus);
            if !bus.pending_cache_invalidations.is_empty() {
                core.invalidate_decode_cache_entries(
                    &bus.pending_cache_invalidations);
                bus.pending_cache_invalidations.clear();
            }
        }
        core.ppb.update_latest_cycles(core.cycles);

        if barrier.wait() == BarrierResult::Poisoned { return core; }
        if barrier.wait() == BarrierResult::Poisoned { return core; }
    }
    core
}
```

### PIO worker

```rust
fn pio_worker_body(mut blocks: [PioBlock; 3], shared: SharedState,
                   barrier: Arc<SpinBarrier>, n: u64, step_q: u32)
    -> [PioBlock; 3]
{
    for _ in 0..n {
        for cmd in shared.pio.drain_commands() {
            apply_pio_command(&mut blocks, cmd);
        }
        for block_idx in 0..3 {
            let enabled = shared.pio.read_sm_enabled(block_idx);
            for _ in 0..step_q {
                for sm in 0..4 {
                    if enabled & (1 << sm) != 0 {
                        blocks[block_idx].step_sm(sm, &shared);
                    }
                }
            }
        }
        // PIO IRQ routing mirrors whatever the single-threaded Bus PIO
        // → NVIC path does today. Implementer verifies during impl;
        // if absent, this hook is dropped.

        if barrier.wait() == BarrierResult::Poisoned { return blocks; }
        if barrier.wait() == BarrierResult::Poisoned { return blocks; }
    }
    blocks
}
```

### Coordinator worker

```rust
fn coordinator_worker_body(shared: SharedState, barrier: Arc<SpinBarrier>,
                           n: u64, step_q: u32)
{
    for _ in 0..n {
        if barrier.wait() == BarrierResult::Poisoned { return; }

        // Publish master_cycle BEFORE ticking peripherals so CPU
        // workers' next-quantum PLL reads (post-barrier-2) observe
        // the fresh timeline. fetch_add is Release-ordered so the
        // CPU workers' Acquire-load pairs correctly.
        shared.master_cycle.fetch_add(step_q as u64, Release);
        shared.sio.mtime_advance(step_q as u64);

        // Coordinator-owned peripheral ticks: DMA, TIMER0/1, UART
        // FIFOs, ADC FIFO, PWM wrap. Lock order enforced
        // (clocks < qmi < resets < apb < timers < dma).
        tick_peripherals(&shared, step_q as u64);

        if barrier.wait() == BarrierResult::Poisoned { return; }
    }
}
```

No SIO_IRQ_MTIMECMP assertion (scope — §6 note). If Phase 4 or later
wants hardware-accurate MTIMECMP IRQ, that's a separate change with
both assert and de-assert handling.

### Thread pinning

```rust
fn pin_to_host_core(host_core: usize) {
    use winapi::um::processthreadsapi::{GetCurrentThread, SetThreadAffinityMask};
    let h = unsafe { GetCurrentThread() };
    let mask = 1usize << host_core;
    let prev = unsafe { SetThreadAffinityMask(h, mask) };
    assert!(prev != 0, "SetThreadAffinityMask failed for host core {}", host_core);
}
```

Default mapping is `[0, 1, 2, 3]` (dense). `.with_thread_mask(...)`
for hyperthreaded-host spread.

## 13. Risks

1. **Generic monomorphisation.** `CortexM33::step<B: CoreBus>`
   doubles code size for `core/execute*.rs` (~10 KLOC). Expect
   +~300 KB release `.exe`, +~1.2 MB debug, +~4 s `cargo build`.
   Acceptable.
2. **Bus destructure goes stale.** Exhaustive pattern makes additions
   a compile error.
3. **Decode cache cross-core staleness.** Firmware-level
   DSB+ISB+IC IVAU required for cross-core SMC (matches ARM spec).
   Covered by test #19.
4. **Thread pinning.** `.with_thread_mask(...)` lets caller force
   physical-core spread on SMT hosts.
5. **APB mutex contention.** Phase 5 measures; split per-peripheral
   if needed.
6. **`catch_unwind` covers panics, not deadlocks.**
7. **`pending_cache_invalidations` Vec allocation.** Preallocated 16.
8. **Poisoned `ThreadedEmulator` requires rebuild.**
9. **Decode cache per-core doubles footprint.** 192 KB × 2 = 384 KB.
   Phase 0c benchmarks re-validated with doubled footprint before
   claiming same throughput ceiling.
10. **Legacy HashMap Mutex bottleneck.** Acceptable placeholder;
    Phase 5 deletes.
11. **Monitor snoop/set race (Phase 1 V3 §3).** Resolved by the
    barrier protocol: LDREX's `monitors.set` runs in the execution
    phase; coordinator-originated DMA writes snoop in the
    coordinator phase; barrier 1 orders them. No additional
    synchronisation needed in Phase 3.
12. **PLL LOCK quantum-boundary granularity.** `master_cycle`
    advances once per quantum (in the coordinator phase). PLL LOCK
    transitions are observed at quantum boundaries, so firmware
    that busy-polls PLL_CS sees quantised lock transitions —
    up to `step_q` cycles of jitter. Acceptable for typical
    boot-time PLL configuration (firmware waits well past lock);
    revisit if a real workload needs sub-quantum LOCK fidelity.
13. **STREX into exec memory unsupported.** STREX bypasses
    `WorkerBus::write32`, so no auto decode-cache invalidation on
    the success path. Firmware must issue ISB manually. Matches
    ARM's position on STREX to exec memory.

## 14. Non-goals (deferred)

**Phase 4:**
- `ThreadedEmulator::run(pacer, duration, stop)` with Pacer.
- `ExitReason` enum + structured panic propagation.
- `reset()` that rebuilds workers.
- Threaded tracing (`Arc<Mutex<dyn Write>>`).
- Long-running worker model.

**Phase 5:**
- WFI wake check in coordinator + `ExitReason::BothWfi`.
- `set_quantum` runtime reconfig.
- `paced_bench --threaded --dual-core` + quantum sweep.
- PIO FIFO join reconfiguration.
- Threaded mode in `mdrp2350-app`.
- Real-firmware differential test.
- TSan Linux shim for primitives.
- Migrate remaining `legacy` HashMap users; delete the field.
- Phase 0c decode-cache benchmark re-validation at doubled footprint.
- Hardware-accurate SIO IRQ wiring (SIO_IRQ_FIFO / SIO_IRQ_BELL /
  SIO_IRQ_MTIMECMP) with both rising and falling edges —
  intentionally outside Phase 3 scope.

**Out of scope:**
- Hybrid per-core threaded/single mode.
- `ThreadedEmulator → Emulator` reverse conversion.
- Pipelined coordinator.
- Non-Windows, non-x86_64, < 4 host cores.
