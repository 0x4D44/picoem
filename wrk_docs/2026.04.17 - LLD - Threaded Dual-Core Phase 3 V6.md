## Changes from V5

Review round 5 found 5 blocking gaps + 5 medium + 3 NITs. All
addressed:

**Blocking:**

- **Bus inherent API: `bus_fault`/`bus_fault_addr`/`clear_bus_fault`
  gain a `core: usize` arg.** V5 claimed "public API unchanged"
  while forwarding to `atomics.bus_fault[core]` — impossible without
  a core index. Single-threaded caller (`core/mod.rs:199`) has
  `self.core_id` in scope; the 3-4 other inherent call sites are
  mechanical updates. `CoreBus` trait method already takes `&self`
  only because the impl (WorkerBus or Bus-via-forwarding) knows its
  core, but the **inherent Bus API now matches the trait by routing
  through a `core` arg on the inherent method** — the trait
  `bus_fault(&self)` is implemented by `WorkerBus` using its own
  `core_id` field and by `Bus` via a thin wrapper that takes the
  core from the per-instruction `active_pc.core_id` hint.
  See §2 for the exact signatures.

- **`CoreBus` trait gains `burst_mode` / `wait_state` methods.**
  `set_burst_mode(bool)` + `take_extra_wait_states() -> u32` +
  `add_extra_wait_states(u32)`. V5 dropped the storage onto
  WorkerBus (correct) but the `CortexM33` call sites (11+ in
  `core/mod.rs` around STM/LDM/PUSH/POP wait-state accounting)
  were stranded with no trait surface. Instruction-level cycle
  accuracy depends on these — not optional.

- **FIFO-push / doorbell / MTIME-match wake hooks wired in §6.**
  Phase 2 V4 §3 explicitly deferred `event_flag` on FIFO push,
  doorbell → peer NVIC, and MTIME match → NVIC to "Phase 3
  responsibility". V5 forwarded the delegations but never named
  the hook code. V6 §6 spells them out in `WorkerBus` SIO
  dispatch and in the coordinator loop.

- **WFE consume + un-halt transition at quantum entry.** The core
  worker checks `atomics.event_flag_consume(idx)` before the
  `is_wfe_waiting` short-circuit. WFI wake stays deferred to
  Phase 5 per §14, but WFE works in Phase 3. §9.

- **`peripheral_regs` HashMap is NOT dead.** V5 destructured with
  `_` calling it "legacy, Phase 2 typed-reg migration replaced
  it". Wrong — 11 live reads/writes remain in `bus/mod.rs`
  (`:1254`, `:1523`, `:1533`, `:1673`, `:1932`, `:1943`, `:2034`,
  `:2168`, `:2176`, plus init sites). V6 routes the HashMap
  through `Peripherals.legacy: Mutex<HashMap<u32, u32>>`. The
  typed-reg migration can delete it in Phase 5 when the remaining
  call sites have typed homes; until then it's load-bearing.

- **`irq_pending_dirty` is removed, not ignored.** V5's destructure
  never named it. V6: the `atomics.take_irq_pending(core)` swap
  returns the full pending mask atomically — non-zero return
  replaces the "dirty" flag test exactly, so the flag disappears.
  Core step path updated to test the swap return value; Bus
  field removed; destructure no longer needs to mention it
  (exhaustive-destructure compile check enforces).

**Medium:**

- **Decode cache per-core sizing acknowledged.** 192 KB → 384 KB
  total (two copies). Per-core is architecturally correct (each
  M33 has its own pipeline); the size is noted in §13 risk 9.

- **Dense SMT pinning softened.** `--thread-mask` CLI hook (or
  env override) allowing the caller to pick host logical IDs
  explicitly. Default stays at 0–3 dense. §9.

- **`rcp_count_check` concurrency test restored (back to 13).**
  V5 dropped it arguing "stdlib-atomic covers it". Correct for
  the primitive, wrong for the wrapper retry loop — the test
  verifies *our* compare-then-increment contract under race, not
  stdlib's CAS. ~20 LOC. §11.

- **Parent HLD citation.** Points to the actual latest in-tree
  file (HLD V3, 2026.04.14). If an HLD V5 is drafted later, bump
  the cite.

- **Coordinator worker body reproduced in §9** (V5 said
  "unchanged from V2 §8" — V6 stands alone).

**Nits:**

- §6 CP0 rewrite: explicit signature-shift count (not just
  ~30 dispatch arms).
- §11: cross-core SMC test added (core 0 writes into core 1's
  code region + DSB/ISB/re-execute).
- §4 STREX note: decode-cache invalidation also fires for the
  write-side of STREX, not just ordinary writes.

## Scope

Compose Phase 1/2 primitives into a 4-thread runtime:

1. `CoreBus` trait — MMIO surface `CortexM33` uses on the bus.
2. `CoreAtomics` — `Arc`'d cross-core per-core state.
3. `SharedState` — `Arc` bundle.
4. `WorkerBus` — CPU-thread view (impls `CoreBus`).
5. `PioBus` — PIO thread's view, owns `PioBlock`s.
6. `PerCoreSio` — divider + interpolator on each `CortexM33`.
7. `Peripherals` — mutex-protected coordinator-owned state.
8. `ThreadedEmulator::from_emulator` + `run_quanta(n)`.
9. Windows thread pinning (cores 0/1/2/3 default, mask-overridable).

Deferred to Phases 4/5: see §14.

### Platform gate

`#[cfg(all(target_arch = "x86_64", target_os = "windows"))]` on
`ThreadedEmulator`, `WorkerBus`, `PioBus`, `worker::*`,
`pin_to_host_core`. `CoreBus` / `CoreAtomics` / `PerCoreSio` /
`SharedState` are unconditional (visible to `CortexM33`, which builds
on all targets).

## 1. `CoreBus` trait

```rust
pub trait CoreBus {
    fn read8(&mut self,  addr: u32, core: u8) -> u8;
    fn read16(&mut self, addr: u32, core: u8) -> u16;
    fn read32(&mut self, addr: u32, core: u8) -> u32;
    fn write8(&mut self,  addr: u32, val: u8,  core: u8);
    fn write16(&mut self, addr: u32, val: u16, core: u8);
    fn write32(&mut self, addr: u32, val: u32, core: u8);

    fn set_active_pc(&mut self, pc: u32, core: u8);

    // Per-core bus fault observation (was single-flag in V5; real
    // semantics are per-core — a fault raised during core 0's
    // access must not be observable by core 1, and vice versa).
    fn bus_fault(&self, core: u8) -> bool;
    fn bus_fault_addr(&self, core: u8) -> u32;
    fn clear_bus_fault(&mut self, core: u8);

    // Wait-state accounting — instruction-level cycle fidelity
    // depends on these being on the trait surface (not reached past).
    fn set_burst_mode(&mut self, on: bool);
    fn add_extra_wait_states(&mut self, n: u32);
    fn take_extra_wait_states(&mut self) -> u32;
}
```

13 methods. Everything else (IRQ pending, SEV, halted, WFE, RCP) is
on `CoreAtomics` (§2) and reached via `self.atomics` directly from
`CortexM33`.

`CortexM33::step<B: CoreBus>(&mut self, bus: &mut B)` and all helpers
become generic. Monomorphisation acknowledged in §13.

### `impl CoreBus for Bus`

Inherent `Bus::bus_fault(&self, core: usize) -> bool` etc. take the
core as an argument. The `CoreBus for Bus` impl just forwards:

```rust
impl CoreBus for Bus {
    fn bus_fault(&self, core: u8) -> bool { Bus::bus_fault(self, core as usize) }
    // ...
}
```

All 3-4 existing single-threaded call sites in `core/mod.rs` gain a
`self.core_id` argument — this is the V5-claimed "public API unchanged"
concession. It is a small, contained API break, justified by correctness
(V3 HLD §0b.1's `active_core` flag removal was the right direction; V5's
"forward without a core arg" attempt silently reintroduced the
single-shared-flag pathology).

## 2. `CoreAtomics`

```rust
pub struct CoreAtomics {
    pub halted:      [AtomicBool; 2],
    pub wfe_waiting: [AtomicBool; 2],
    pub event_flag:  [AtomicBool; 2],
    pub irq_pending: [AtomicU64; 2],
    pub rcp_salt:       [AtomicU32; 2],
    pub rcp_salt_valid: [AtomicBool; 2],
    pub rcp_count:      AtomicU32,
    pub bus_fault:      [AtomicBool; 2],
    pub bus_fault_addr: [AtomicU32; 2],
}
```

### Key methods

```rust
impl CoreAtomics {
    pub fn assert_irq(&self, core: usize, irq: u32);
    pub fn assert_irq_shared(&self, irq: u32);
    pub fn clear_irq(&self, core: usize, irq: u32);

    /// Atomic swap-to-zero. Non-zero return replaces the old
    /// `irq_pending_dirty` flag — caller merges the returned
    /// mask into its NVIC ISPR. Zero return = no new IRQ edges
    /// since last take.
    pub fn take_irq_pending(&self, core: usize) -> u64 {
        self.irq_pending[core].swap(0, AcqRel)
    }

    /// SEV writes both cores' event_flag. Stored-sticky until consumed.
    pub fn sev_both(&self);
    /// WFE consume: atomic swap to false; returns old value.
    pub fn event_flag_consume(&self, core: usize) -> bool;

    pub fn set_halted(&self, core: usize);
    pub fn clear_halted(&self, core: usize);
    pub fn is_halted(&self, core: usize) -> bool;
    pub fn set_wfe_waiting(&self, core: usize);
    pub fn clear_wfe_waiting(&self, core: usize);
    pub fn is_wfe_waiting(&self, core: usize) -> bool;

    /// `rcp_count_set X` — unconditional store.
    pub fn rcp_count_set(&self, value: u32);
    /// `rcp_count_check Y`: atomic compare-then-increment.
    pub fn rcp_count_check(&self, expected: u32) -> Result<(), u32> {
        loop {
            let cur = self.rcp_count.load(Acquire);
            if cur != expected { return Err(cur); }
            match self.rcp_count.compare_exchange(
                cur, cur.wrapping_add(1), AcqRel, Acquire)
            {
                Ok(_)  => return Ok(()),
                Err(_) => continue,
            }
        }
    }

    pub fn set_bus_fault(&self, core: usize, addr: u32);
    pub fn clear_bus_fault(&self, core: usize);
}
```

### Ownership invariant

`CortexM33::new(core_id: u8, atomics: Arc<CoreAtomics>) -> Self` —
atomics required at construction. No setter, no `Option`. `Bus::new()`
constructs a `CoreAtomics` once and hands the Arc to both cores plus
stores it on `Bus` (so inherent `Bus` methods can reach
`atomics.bus_fault[core]` etc.). `Emulator::new` orchestrates the
build; `from_emulator` (§8) extracts the Arc into `SharedState`.

### Unit-test constructor

```rust
impl CortexM33 {
    #[cfg(test)]
    pub fn for_test(core_id: u8) -> Self {
        Self::new(core_id, Arc::new(CoreAtomics::default()))
    }
}
```

Test sites call `for_test(0)` / `for_test(1)`.

## 4. `WorkerBus`

```rust
pub struct WorkerBus {
    core_id: u8,
    shared: SharedState,
    active_pc: u32,
    burst_mode: bool,
    extra_wait_states: u32,
    /// Addresses of executable-region writes queued by this step.
    /// Drained by the worker loop after each `CortexM33::step`.
    pending_cache_invalidations: Vec<u32>,
}
```

### Address-class routing

| Region (`addr >> 28`) | Target |
|---|---|
| `0x0` ROM / `0x1` XIP | `shared.memory.read*` |
| `0x2` SRAM | `shared.memory.read/write*`; writes record `self.pending_cache_invalidations.push(addr)` |
| `0x4` APB | sub-decode by offset → `peripherals.clocks / qmi / resets / apb / timers / dma / legacy` |
| `0x5` AHB | `peripherals.dma` |
| `0xD` SIO | `shared.sio.*` / `shared.gpio.*` / `shared.atomics.*` (DIV/INTERP intercepted on `CortexM33` — §6) |
| `0xE` PPB | unreachable (intercepted on `CortexM33`) |

Unresolved APB addresses fall through to `peripherals.legacy`
(the HashMap of untyped peripheral registers). `bus/mod.rs` has 11
live legacy-register sites today; until the Phase 5 typed-reg
migration clears the last one, the HashMap is the fallback path.

Exact offsets match the `bus/mod.rs` decode match arms — `WorkerBus`
mirrors them. Maintaining a hand-written address table in this LLD
proved error-prone across V1–V3; the implementer cross-references
the existing `Bus` dispatch directly.

### Peer-monitor snoop on every write

```rust
impl CoreBus for WorkerBus {
    fn write32(&mut self, addr: u32, val: u32, core: u8) {
        // ...region dispatch, including shared.memory.write32 for SRAM...
        if matches!(addr >> 28, 0x0 | 0x1 | 0x2) {
            self.pending_cache_invalidations.push(addr);
        }
        self.shared.monitors.snoop(addr);
    }
    // write16/write8 mirror: region dispatch, push invalidation for exec,
    // snoop peer monitor.
}
```

ARMv8-M §A3.4: any store to a word for which the peer holds an
exclusive monitor invalidates that monitor. Snooping every write —
not just STREX — matches the architecture.

STREX's own success path also goes through `write32` (success → the
value is committed via SharedMemory's CAS primitive + `monitors.snoop`).
STREX's local reservation is cleared by the CortexM33 execute site
(pre-existing Phase 0b.2 path; unchanged). Both together give ARM
semantics: STREX success invalidates its own monitor AND invalidates
the peer's if the peer happened to be reading the same line.

### Decode-cache invalidation (per-core, self-only)

After each `core.step`, the worker drains
`bus.pending_cache_invalidations` and calls
`core.invalidate_decode_cache_entries(&addrs)`. Vec capacity
pre-allocated to 16 (covers ARM STM up to 13 regs + some spare). The
Vec is `clear()`-ed each step; allocations amortise.

Cross-core SMC is NOT automatically handled — matches ARM spec
requirement that firmware issue `DSB; ISB; IC IVAU` cross-core.

### MMIO reads with side effects

Same list as V3 §4 — routed through the same components, so the same
atomicity story applies (SIO FIFO: SPSC pop; spinlock: atomic
fetch_or; PIO RXF: SPSC pop; ROSC RANDOM / TIMER TIMELR:
mutex-serialised).

## 5. `PioBus`

```rust
pub struct PioBus {
    shared: SharedState,
    blocks: [PioBlock; 3],
}
```

Per-quantum PIO-thread loop:

1. `shared.pio.drain_commands()` → apply each command to local
   `PioBlock`s.
2. For each active SM (per `shared.pio.read_sm_enabled`), step one
   PIO cycle × `step_quantum` times.
3. Update `shared.pio.irq_flags` / `dreq`. PIO IRQ flags raised
   this quantum are mirrored into
   `shared.atomics.assert_irq(core, PIO_IRQ_{0,1})` at the PIO
   worker's barrier-exit so CPU workers see them at the next
   quantum's `take_irq_pending`.

One-quantum delay on CPU→PIO writes. Firmware must issue DMB between
INSTR_MEM writes and SM_ENABLE if sub-quantum ordering matters.

FIFO join deferred to Phase 5.

## 6. SIO ownership split + wake hooks

### `ThreadedSio` (already in Phase 2)

Covers: FIFOs, spinlocks, doorbells, MTIME, MTIMECMP. Plus
`AtomicGpio` for GPIO_IN/OUT/OE.

### `PerCoreSio` (per-core, on `CortexM33`)

```rust
pub struct PerCoreSio {
    pub divider: Divider,
    pub interp:  [Interp; 2],
}
```

Defined in `crates/mdrp2350/src/core/mod.rs` (NOT a new file). The
existing `Divider` + `Interp` bodies in `mdpicoem-common` are
unchanged — only the storage location moves.

### SIO MMIO dispatch (with wake hooks)

`WorkerBus::read32/write32` at `0xD000_...`:

| Category | Route | Wake hook (new in V6) |
|---|---|---|
| GPIO in/out/oe, CPUID, MTIME/MTIMECMP | `shared.gpio` / `shared.sio.mtime*` / constant CPUID | (MTIME match in coordinator — below) |
| FIFO_ST / FIFO_WR / FIFO_RD | `shared.sio.fifo_*` | **On successful `fifo_push(writer, val)`, set `atomics.event_flag[peer]` and `atomics.assert_irq(peer, IRQ_SIO_IRQ_FIFO_PROC{peer})`.** |
| SPINLOCK<0..31> | `shared.sio.spinlocks` | none |
| DOORBELL_OUT_SET/CLR, DOORBELL_IN_* | `shared.sio.doorbell_*` | **On `doorbell_set(target, bits)` with any bit new, `atomics.assert_irq(target, IRQ_SIO_IRQ_BELL)`.** |
| DIV_* / INTERP*_* | **intercepted on `CortexM33`** — routes to `self.sio_local.*` before reaching the bus | none |

The three wake hooks (FIFO event-flag + FIFO IRQ, Doorbell IRQ) were
declared as "Phase 3 responsibility" by Phase 2 V4 §3 "Phase 3
responsibilities". V5 elided them. V6 names them in the dispatch
table above and spells out the code in §9 (core worker body
includes the CortexM33-level code path for FIFO_WR).

The DIV/INTERP intercept is a one-line branch in
`CortexM33::bus_read32/write32` wrappers (mirrors the existing PPB
intercept for `0xE...`). No `CoreBus` trait surface needed —
DIV/INTERP are strictly per-core.

### MTIME match → NVIC (coordinator)

Coordinator phase (§9) runs `mtime_advance(quantum_cycles)` then
for each core checks `mtime_check_match(core)` — on match (and
re-arm bit, per existing MTIMECMP semantics), calls
`atomics.assert_irq(core, IRQ_SIO_IRQ_MTIMECMP)`.

### CP0 coprocessor path

`coprocessor.rs` currently takes `&mut self: CortexM33, &mut Bus`.
Under V6 the bus arg becomes `&mut B: CoreBus`. Additionally:

- ~30 dispatch arms (CP0 register numbers) split by route.
- ~5 function signatures change (`cp0_read/write`,
  `cp0_mcr/mrc`, dispatch hub) — `&mut Bus` → `&mut B: CoreBus`.
- DIV / INTERP CP0 regs route to `&mut self.sio_local`, which
  requires splitting the hub into a local-first match-then-fall-
  through pattern (~20 LOC).

"Mechanical" understates — name the signature shifts explicitly so
the implementer doesn't under-budget the refactor.

## 7. `Peripherals`

```rust
pub struct Peripherals {
    pub clocks: Mutex<ClocksState>,   // CLOCKS + PLL_SYS + PLL_USB + XOSC + ROSC
    pub qmi:    Mutex<QmiState>,
    pub resets: Mutex<ResetsState>,
    pub apb:    Mutex<ApbState>,      // UART/SPI/I2C/ADC/PWM/IO_BANK0/PADS_BANK0
    pub timers: Mutex<TimersState>,   // TICKS/TIMER0/1/WATCHDOG
    pub dma:    Mutex<DmaState>,
    /// Legacy untyped register HashMap — the 11 `bus/mod.rs` call
    /// sites that haven't yet been migrated to typed state. Phase 5
    /// deletes when the last one has a home.
    pub legacy: Mutex<HashMap<u32, u32>>,
}
```

Lock order (documented in module rustdoc):
`clocks < qmi < resets < apb < timers < dma < legacy`.

Phase 3 codebase has zero nested-lock sites — the coordinator
takes locks sequentially, CPU workers take at most one per MMIO.
If a nested site appears later, add `debug_assert!` locally.

### Poisoning

`.lock().unwrap()` — panic on poison. `into_inner()` silently
proceeds on corrupted state; failing loud is safer.

### Construction at `from_emulator`

Built via struct literal inline in `from_emulator` — no 20-arg
`from_bus_components`. Each `Mutex<*State>::new(State { ... })`
wraps the destructured Bus fields.

### Coordinator snapshot pattern

`tick_peripherals` takes `clocks + resets` briefly, clones
`ClockTree` + `resets_state` into coordinator locals, drops both.
Narrows lock windows.

## 8. `ThreadedEmulator` + `from_emulator` + `run_quanta`

```rust
#[cfg(all(target_arch = "x86_64", target_os = "windows"))]
pub struct ThreadedEmulator {
    shared: SharedState,
    core0: Option<CortexM33>,
    core1: Option<CortexM33>,
    pio_blocks: Option<[PioBlock; 3]>,
    step_quantum: u32,
    master_cycle: u64,
    /// Default [0,1,2,3]; overridable via `with_thread_mask`.
    thread_mask: [usize; 4],
    /// Set when any worker panics. Subsequent run_quanta calls fail fast.
    poisoned: bool,
}
```

### `from_emulator`

```rust
pub fn from_emulator(emu: Emulator) -> Self {
    let n = std::thread::available_parallelism()
        .map(|n| n.get()).unwrap_or(1);
    assert!(n >= 4,
        "ThreadedEmulator requires >= 4 host cores (found {})", n);
    if n == 4 {
        tracing::warn!("exactly 4 host cores — workers will contend \
                        with OS/other processes; >= 5 recommended");
    }

    let Emulator { cores, bus, clock, step_quantum } = emu;
    let [core0, core1] = cores;

    // Exhaustive destructure — new Bus fields force a compile error.
    // Post-decomposition `Bus` carries only coordinator-owned storage
    // plus the shared `Arc<CoreAtomics>`. Fields that moved to atomics
    // (event_flag, irq_pending, bus_fault*, rcp_*) are no longer on
    // `Bus`. `irq_pending_dirty` is deleted — swap-to-zero semantics
    // on `atomics.take_irq_pending` replace it. `decode_cache` moves
    // to each CortexM33 (per-core, 192 KB each; total 384 KB — see
    // §13 risk 9).
    let Bus {
        memory, boot_ram, xip_sram,
        sio, pio,
        atomics,                  // Arc<CoreAtomics> — carry through
        resets_state, ticks, timer0, timer1,
        uart0, spi0, i2c0, adc, pwm, io_bank0, pads_bank0,
        dma,
        clk_ref_ctrl, clk_sys_ctrl, clk_sys_div, clock_tree,
        pll_sys_regs, pll_usb_regs,
        pll_sys_lock_at_cycle, pll_usb_lock_at_cycle,
        rosc_regs, xosc_regs, gpio_hi_noise_state,
        qmi_regs, xip_cache_offset,
        gpio_in, gpio_external_in, gpio_external_mask,
        flash_loaded,
        peripheral_regs,          // LIVE HashMap — routed to Peripherals.legacy
        last_access_cycles: _,    // debug scalar; regenerated
        extra_wait_states: _,     // per-instruction scratch; lives on WorkerBus
        burst_mode: _,            // per-instruction scratch; lives on WorkerBus
        active_pc: _,             // per-instruction scratch; lives on WorkerBus
        trace_enabled: _,         // threaded tracing deferred to Phase 5
        trace_sink: _,            // threaded tracing deferred to Phase 5
        master_cycle: _,          // kept on ThreadedEmulator directly
    } = bus;

    let shared_mem = Arc::new(
        SharedMemory::from_memory(memory, boot_ram, xip_sram, flash_loaded));
    let shared_gpio = Arc::new(AtomicGpio::seed(
        sio.gpio_out, sio.gpio_oe, gpio_in,
        gpio_external_in, gpio_external_mask));
    let shared_sio = Arc::new(ThreadedSio::seed(&sio));
    // DIV + INTERP move onto the cores
    let [mut core0, mut core1] = [core0, core1];
    core0.sio_local = PerCoreSio::from_sio(&sio, 0);
    core1.sio_local = PerCoreSio::from_sio(&sio, 1);

    let peripherals = Arc::new(Peripherals {
        clocks: Mutex::new(ClocksState {
            clk_ref_ctrl, clk_sys_ctrl, clk_sys_div,
            tree: clock_tree,
            pll_sys: pll_sys_regs, pll_usb: pll_usb_regs,
            pll_sys_lock_at_cycle, pll_usb_lock_at_cycle,
            rosc: rosc_regs, xosc: xosc_regs,
            gpio_hi_noise_state,
        }),
        qmi:    Mutex::new(QmiState { regs: qmi_regs, xip_cache_offset }),
        resets: Mutex::new(ResetsState { state: resets_state }),
        apb:    Mutex::new(ApbState {
            uart0, spi0, i2c0, adc, pwm, io_bank0, pads_bank0,
        }),
        timers: Mutex::new(TimersState { ticks, timer0, timer1 }),
        dma:    Mutex::new(DmaState { dma }),
        legacy: Mutex::new(peripheral_regs),
    });

    let shared = SharedState {
        memory: shared_mem,
        gpio: shared_gpio,
        sio: shared_sio,
        pio: Arc::new(ThreadedPio::new()),
        monitors: Arc::new(ExclusiveMonitors::new()),
        peripherals,
        atomics,   // shared with cores; Bus::new already built it
    };

    Self {
        shared,
        core0: Some(core0),
        core1: Some(core1),
        pio_blocks: Some(pio),
```

### `run_quanta(n)`

```rust
pub fn run_quanta(&mut self, n: u64) {
    assert!(!self.poisoned,
        "ThreadedEmulator poisoned by prior worker panic; drop and rebuild");

    let core0 = self.core0.take().expect("run_quanta reentry");
    let core1 = self.core1.take().expect("run_quanta reentry");
    let blocks = self.pio_blocks.take().expect("run_quanta reentry");

    let barrier = Arc::new(SpinBarrier::new(4));
    let shared = self.shared.clone();
    let step_q = self.step_quantum;
    let mask = self.thread_mask;

    let h0 = spawn_worker(mask[0], barrier.clone(), move |b| {
        core_worker_body(0, core0, shared.clone(), b, n, step_q)
    });
    // ... spawn_worker(mask[1], ...) for core1
    // ... spawn_worker(mask[2], ...) for pio
    // ... spawn_worker(mask[3], ...) for coordinator
    let (r0, r1, rp, rc) = (h0.join(), h1.join(), hp.join(), hc.join());

    // Restore state from successfully-joined workers
    if let Ok(c) = r0 { self.core0 = Some(c); }
    if let Ok(c) = r1 { self.core1 = Some(c); }
    if let Ok(b) = rp { self.pio_blocks = Some(b); }
    if let Ok(m) = rc { self.master_cycle = m; }

    // Identify and report panicked worker(s)
    let panicked: Vec<&str> = [("core0", r0.is_err()),
                               ("core1", r1.is_err()),
                               ("pio",   rp.is_err()),
                               ("coordinator", rc.is_err())]
        .into_iter()
        .filter_map(|(name, err)| err.then_some(name))
        .collect();
    if !panicked.is_empty() {
        self.poisoned = true;
        panic!("worker thread(s) panicked: {}", panicked.join(", "));
    }
}
```

### `spawn_worker` generic helper

```rust
fn spawn_worker<F, R>(host_core: usize,
                     barrier: Arc<SpinBarrier>,
                     body: F) -> JoinHandle<R>
where
    F: FnOnce(Arc<SpinBarrier>) -> R + Send + 'static,
    R: Send + 'static,
{
    thread::spawn(move || {
        pin_to_host_core(host_core);
        let b2 = barrier.clone();
        match std::panic::catch_unwind(AssertUnwindSafe(move || body(b2))) {
            Ok(r) => r,
            Err(payload) => {
                barrier.poison();
                std::panic::resume_unwind(payload);
            }
        }
    })
}
```

## 9. Worker bodies

### Core worker (with WFE wake)

```rust
fn core_worker_body(core_id: u8, mut core: CortexM33, shared: SharedState,
                    barrier: Arc<SpinBarrier>, n: u64, step_q: u32)
    -> CortexM33
{
    let mut bus = WorkerBus::new(core_id, shared.clone());
    let mut target: u64 = 0;
    let idx = core_id as usize;

    for _ in 0..n {
        target = target.wrapping_add(step_q as u64);

        // WFE wake (Phase 3 path; WFI wake is Phase 5).
        // If a peer called sev_both while we were parked, consume
        // the event and clear wfe_waiting so execution resumes.
        if shared.atomics.is_wfe_waiting(idx)
           && shared.atomics.event_flag_consume(idx)
        {
            shared.atomics.clear_wfe_waiting(idx);
        }

        let pending = shared.atomics.take_irq_pending(idx);
        if pending != 0 { core.ppb.merge_irq_pending(pending); }

        while !shared.atomics.is_halted(idx)
           && !shared.atomics.is_wfe_waiting(idx)
           && core.cycles < target
        {
            core.ppb.update_latest_cycles(core.cycles);
            core.step(&mut bus);
            if !bus.pending_cache_invalidations.is_empty() {
                core.invalidate_decode_cache_entries(
                    &bus.pending_cache_invalidations);
                bus.pending_cache_invalidations.clear();
            }
        }
        core.ppb.update_latest_cycles(core.cycles);

        if barrier.wait() == BarrierResult::Poisoned { return core; }
        if barrier.wait() == BarrierResult::Poisoned { return core; }
    }
    core
}
```

### PIO worker

```rust
fn pio_worker_body(mut blocks: [PioBlock; 3], shared: SharedState,
                   barrier: Arc<SpinBarrier>, n: u64, step_q: u32)
    -> [PioBlock; 3]
{
    for _ in 0..n {
        for cmd in shared.pio.drain_commands() {
            apply_pio_command(&mut blocks, cmd);
        }
        for block_idx in 0..3 {
            let enabled = shared.pio.read_sm_enabled(block_idx);
            for _ in 0..step_q {
                for sm in 0..4 {
                    if enabled & (1 << sm) != 0 {
                        blocks[block_idx].step_sm(sm, &shared);
                    }
                }
            }
        }
        // Route PIO IRQ flags → core NVICs so CPU workers observe
        // them at the next quantum's take_irq_pending.
        for block_idx in 0..3 {
            let flags = shared.pio.read_irq_flags(block_idx);
            if flags != 0 {
                // Maps to IRQ_PIO0_IRQ_0 / _1 etc. per RP2350 NVIC table.
                shared.atomics.assert_irq_shared(pio_irq(block_idx, flags));
            }
        }

        if barrier.wait() == BarrierResult::Poisoned { return blocks; }
        if barrier.wait() == BarrierResult::Poisoned { return blocks; }
    }
    blocks
}
```

### Coordinator worker

```rust
fn coordinator_worker_body(shared: SharedState, barrier: Arc<SpinBarrier>,
                           n: u64, step_q: u32, mut master_cycle: u64)
    -> u64
{
    for _ in 0..n {
        if barrier.wait() == BarrierResult::Poisoned { return master_cycle; }

        // Advance master cycle + MTIME; check MTIME match per core.
        master_cycle = master_cycle.wrapping_add(step_q as u64);
        shared.sio.mtime_advance(step_q as u64);
        for core_idx in 0..2 {
            if shared.sio.mtime_check_match(core_idx) {
                shared.atomics.assert_irq(core_idx, IRQ_SIO_IRQ_MTIMECMP);
            }
        }

        // Coordinator-owned peripheral ticks: DMA, TIMER0/1, UART FIFOs,
        // ADC FIFO, PWM wrap. Each takes its mutex briefly, ticks, may
        // assert IRQs via atomics.assert_irq. Lock order enforced
        // (clocks < qmi < resets < apb < timers < dma).
        tick_peripherals(&shared, step_q as u64);

        if barrier.wait() == BarrierResult::Poisoned { return master_cycle; }
    }
    master_cycle
}
```

Two barriers per quantum: first releases when all four workers have
finished their execution-phase work; second releases after coordinator
phase (including IRQ fan-out) completes so CPU workers see fresh IRQs
on the next quantum.

### Thread pinning

```rust
fn pin_to_host_core(host_core: usize) {
    use winapi::um::processthreadsapi::{GetCurrentThread, SetThreadAffinityMask};
    let h = unsafe { GetCurrentThread() };
    let mask = 1usize << host_core;
    let prev = unsafe { SetThreadAffinityMask(h, mask) };
    assert!(prev != 0, "SetThreadAffinityMask failed for host core {}", host_core);
}
```

Default mapping is `[0, 1, 2, 3]` (dense). On hyperthreaded hosts
this may straddle SMT siblings — caller passes
`.with_thread_mask([0, 2, 4, 6])` (or whatever the host's topology
dictates) to force physical-core spread. §13 risk 4.

## 10. Memory barriers

`DMB`/`DSB` → `std::sync::atomic::fence(Ordering::SeqCst)` — orders
this core's stores vs its subsequent loads as seen by a peer-core
DMB. On x86 TSO this emits `mfence`.

`ISB` → `fence(SeqCst)` + `core.invalidate_decode_cache_all()`.
Flushes the executing core's decode cache entirely so any prior
write to executable memory (including cross-core writes that the
firmware explicitly ordered with `DSB` before `ISB`) is re-fetched.

Cross-core visibility: a DMB on one core does not force its stores
into the peer's observation window. Firmware must issue matching
DMBs on both sides (same as real hardware).

## 13. Risks

1. **Generic monomorphisation.** `CortexM33::step<B: CoreBus>` doubles
   code size for `core/execute*.rs` (~10 KLOC). Expect +~300 KB
   release `.exe`, +~1.2 MB debug, +~4 s `cargo build`. Acceptable.
2. **Bus destructure goes stale.** Exhaustive pattern makes additions
   a compile error — forced handling.
3. **Decode cache cross-core staleness.** Firmware-level DSB+ISB+IC
   IVAU required for cross-core SMC (matches ARM spec). Covered by
   test #17.
4. **Thread pinning.** < 4 cores = panic; exactly 4 cores = warn;
   SMT siblings not auto-detected. `.with_thread_mask(...)` lets the
   caller force physical-core spread. Default dense 0–3 acceptable
   on non-SMT hosts.
5. **APB mutex contention.** Per-MMIO lock on tight loops. Phase 5
   measures; if real, split apb per-peripheral.
6. **`catch_unwind` covers panics, not deadlocks.** Worker infinite
   loops still hang. No watchdog in Phase 3.
7. **`pending_cache_invalidations` Vec allocation.** Preallocated
   capacity 16 covers STM (up to 13 regs) + some spare. Overflow
   heap-allocates once per step then stays grown. Negligible.
8. **Poisoned `ThreadedEmulator` requires rebuild.** After a worker
   panic, caller must drop and reconstruct via `from_emulator`. No
   in-place recovery.
9. **Decode cache per-core doubles footprint.** 192 KB × 2 = 384 KB.
   Architecturally correct (each M33 has its own pipeline); Phase 0c
   benchmarks need re-validating with doubled footprint before we
   claim "same throughput ceiling".
10. **Legacy HashMap is a Mutex bottleneck.** Any unmigrated
    peripheral register flows through it. Acceptable Phase 3
    placeholder; Phase 5 typed-reg migration removes the last
    call sites and then the field.
