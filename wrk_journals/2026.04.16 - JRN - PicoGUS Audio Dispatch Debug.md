### Investigation round 3
- **Agent a9aa9a881f09971d0** — selectively reverted each per-register alias path in a worktree. Only SHIFTCTRL toggles the frame count. But tracing shows the alias-forwarding code is **mathematically correct** — writes round-trip correctly. Reverting SHIFTCTRL "rescues" frames by corrupting the initial config (`0x80000000`, zeroing thresholds), which causes PIO1 SM0 (PSRAM SPI) to free-run, flailing its output pins.
- **The I2S capture module mistook pin flailing for LRCLK edges.** The "4,895 frames" at parent was a phantom. The "12,344 frames" in the earlier Phase E journal was almost certainly the same kind of phantom.
- **Conclusion:** there has never been a working audio path. `b239366` is a legitimate correct fix. The real outstanding bug: firmware never arms DMA to feed PIO1 SM3 (I2S) or PIO1 SM0 (PSRAM writes). Autopush=134,446 on PIO0 SM0 confirms firmware IS receiving ISA ingestion; it just doesn't complete the audio-out arming.
