## Goal

Close the five follow-ups documented in the prior campaign journal:

1. **Pre-existing `edge_cases_rv32a` unit-test failure** — atomic address `0x80000400` out of reservable window `0x20000000..0x20082000`.
2. **PMP fuzz class** — blocked on emulator `pmpcfg*`/`pmpaddr*` CSR model.
3. **Silicon-fuzz BLOCKER (scenario state-leakage)** — A.2.3 family; `pwm_wrap_irq`, `pio0_nop_loop`, `pio0_int_routing_split` fail because orchestrator resets DUT between iterations, not between scenarios.
4. **`uart0_rx_loopback` two-valued HW signature** — HW={0x5A, 0xAD} vs EMU=0x42 under soak-shuffle; possibly second state-leakage bug, possibly timing jitter.
5. **Fuzz-filter UX** — `--fuzz N --class X` generates N mixed then filters ≈5%; misleading to users.

## Process

1. **HLD phase (parallel)**: five `Plan` agents each produce an HLD. Path: `wrk_docs/2026.04.18 - HLD - <topic> V1.md`. Scale depth to scope — short fixes get short HLDs. No code yet.
2. **Team lead review**: I read each HLD, iterate with the agent via SendMessage until signed off. Any HLD I reject gets a new version (V2, V3…).
3. **Implementation phase**: once ALL HLDs signed off, launch implementation agents. Serialize pairs that touch the same files; parallelize the rest.
4. **Review + apply**: each implementation gets a code-reviewer pass, then apply-feedback pass, then commit.
5. **Final audit**: independent completeness check.
