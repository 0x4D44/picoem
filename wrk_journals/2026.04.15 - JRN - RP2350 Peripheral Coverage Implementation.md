## Orchestration model

- Supervisor (me): high-level guidance only. No direct coding/testing/debugging.
- Per phase:
  1. **Implementer** agent writes the code with TDD discipline (unit tests first, run `cargo test -p mdrp2350` + touched harness crates). Produces a summary of what landed.
  2. **code-reviewer** agent using the `code-reviewer` skill reviews the delta.
  3. **code-review-apply-feedback** agent using the `code-review-apply-feedback` skill acts on Required / Suggested items.
  4. **Devil's advocate** agent challenges remaining assumptions and surfaces missed edges.
  5. **Final**: commit the phase as an atomic commit, update this journal, move to the next phase.
- **Hardware-gated items** (probe-rs / real RP2354 silicon) cannot be run by agents. These are surfaced explicitly — Arthur runs them on the lab rig.

### 2026-04-15 — Phase 0a complete

**Implementer** landed: `irq.rs` (new, +264 — IRQ constants, CORE_LOCAL_IRQS); `bus/ppb.rs` (+488 — per-core NVIC banks ISER/ICER/ISPR/ICPR/IABR = 2 u32, IPR = 13 u32); `core/exceptions.rs` (+66 — BASEPRI fold, try_take_external_irq); `core/mod.rs` (+15 — third async block, short-circuit); `bus/mod.rs` (+46 — irq_pending: [u64;2], assert_irq_core); `tests.rs` (+248 — 13 new unit tests); `isr_scenarios.rs` (+998/-102 — mode-set + 3 external-IRQ scenarios). Bumped `mdrp2350 0.5.4 → 0.6.0`.

**Code reviewer (code-reviewer skill) + devil's advocate** found four blockers and three required tests:
- B1: MMIO writes to NVIC_ISPR/ICPR didn't mirror into `bus.irq_pending` — all three new scenarios pend via MMIO, so they'd fail on EMU.
- B2: Async-vs-external arbitration was split — ARMv8-M requires unified priority ordering. Unified into `try_take_any_pending_exception`.
- B3: `CORE_LOCAL_IRQS` defined but never consulted. Added `assert_irq_shared`, `clear_irq_core`, `clear_irq_shared`, `is_core_local_irq`.
- B4: Vector default-fill only went slot 16..=47 — extended to 64, image layout restructured (handler offsets 0x100/0x104/0x140/0x180).
- R1–R3: Missing tests for MMIO-ISPR-dispatch, BASEPRI-no-op, end-to-end preempt. Added.
- Four suggestions fixed (stale dead_code, impl merge, test rename, clippy).

**Apply-feedback agent** landed all fixes. Final state:
