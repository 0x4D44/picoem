## Open design questions

- **BADPASSWD bit layout.** Silicon-unconfirmed. Model bit 0 as sticky
  W1C latch. If future silicon runs show a different bit, fix in-stage
  (V12 Stage 1 precedent with CHIP_ID).
- **CTRL_OFFSET legacy.** Current model has a plain-storage `ctrl` field
  at 0x00. Silicon's offset 0x00 is BADPASSWD. Replacing the plain
  storage breaks the `ctrl_roundtrip` unit test — that's the correct
  direction (V11 guess being corrected), so rename the test.

### Stage 3 — smoke halt-read-resume — GREEN (pending silicon verify)

**Red/green nuance**: V13's red signal for this stage is the V12
journal-captured silicon fault (`An ARM specific error occurred` on
`read_word_32(DWT_CYCCNT)` after `core.run()`). Strict TDD isn't
achievable here without the probe — the reproducer *is* a silicon
observation. Stage 3 therefore lands as a targeted rewrite rather
than a classic unit-test red/green; correctness is validated at the
next silicon run.

**Rework**: rewrote `smoke_powman_pacing_rp2350.rs` to stay halted
throughout, leaning on the fact that POWMAN's COUNT advances from
XOSC/4 independent of core run state. Halted reads are safe under
probe-rs; the run-mode fault is avoided by not running the core.

Changes from the V11/V12 version:
- Removed the DWT CYCCNT enable + CYCCNT sampling. CYCCNT doesn't
  tick while halted, so it would be a poor reference. The smoke's
  actual question — "is POWMAN ticking at XOSC/4 = 3 MHz?" — is
  answerable from POWMAN COUNT alone plus the host `Instant` clock.
- Kept the existing `--probe` arg-parse, `DEFAULT_PROBE` hard-wired
  serial, POWMAN password handling, and register dump.
- New sampling loop: halted `read_word_32(POWMAN_READ_TIME_LOWER)` +
  host `Instant::now()`, pushed onto `Vec<(Instant, u32)>` on each
  distinct COUNT value. Derives rate from first-to-last span.
- Output format: `µs since first sample, COUNT` per pair + a derived
  tick rate line comparing vs the 3 MHz XOSC/4 expectation.

**Verify**:
- `cargo build -p mdpicoem-harness --bin smoke_powman_pacing_rp2350` →
  clean.
- `./target/debug/smoke_powman_pacing_rp2350 --help` → arg-parser
  reaches main, prints usage on unknown arg.
- Silicon verify: deferred to next probe session. Expected output:
  derived rate ≈ 3 MHz (potentially under-read due to SWD sampling
  cadence; the comment in the binary documents this).
