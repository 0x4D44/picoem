# JRN — Crate Rename for crates.io publication

**Date:** 2026-05-02
**Owner:** Arthur (decisions) / Claude (execution)
**Driver:** OSS-release HLD `wrk_docs/2026.04.26 - HLD - Open Source Release V1.md` §13 — discoverability rename agreed before publishing the four library crates to crates.io.

## Decisions taken (this session)

1. **Drop the `md` personal-namespace prefix** for the public OSS face. Discoverability on crates.io is dominated by token matches against the chip name (`rp2350`, `rp2040`) and the project umbrella (`pico`, `picoem`). The `md*` family naming (matches Arthur's other tools `mdkey`, `mddosem`, `mdtimeout`, etc.) loses to that on a public crates.io search.
2. **Adopt `rp{2350,2040}-emu` for the chip emulator libraries** and `picoem-{common,devices,debug,harness}` for the project umbrella crates. Aligns with `rp235x-hal` / `rp2040-hal` ecosystem; no name collisions confirmed by `cargo info` against the registry.
3. **Rename the apps too** (`mdrp2350app` → `rp2350-emu-tui`, `mdrp2040app` → `rp2040-emu-tui`). Apps stay unpublished for now (HLD §13.3 Tier 2 deferred), but consistency in the repo trumps the partial-rename smell.
4. **Rename the Tier 3 placeholder crates** (`mdpicoem-debug`, `mdpicoem-harness`) for the same consistency reason.
5. **Leave `epio-sys` alone** — `-sys` belongs to the upstream `piersfinlayson/epio` project; squatting it would be rude.
6. **Leave `third_party/probe-rs-0.31.0-mdrp-patched/` alone** — vendored fork, scheduled to retire when upstream `probe-rs/probe-rs#3872` lands, not worth a churn pass.
7. **Don't squat crates.io now.** Repo is private; names are confirmed-free; race window doesn't open until the public-repo flip. Squat in one batch right before public flip.

## Risks identified up front

- **Feature-forward syntax** — `mdpicoem-common/test-hooks` lives in 2 spots (`mdrp2350/Cargo.toml:44`, `mdrp2040/Cargo.toml:31`). Miss either and `cargo test --features test-hooks` silently breaks the harness. Verify with a smoke run.
- **Two ident forms per rename** — Rust uses underscore form (`mdpicoem_common`), Cargo uses hyphen form (`mdpicoem-common`). sed needs both passes per crate.
- **`RUST_LOG=mdrp2350::bus`** in CLAUDE.md — that's a Rust target path (underscore form), separate from `cargo run -p mdrp2350` (hyphen form). Easy to miss the distinction.
