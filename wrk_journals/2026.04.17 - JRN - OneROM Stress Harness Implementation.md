## Plan (stages)

1. **Stage 0 — pre-flight.** Probe the 1541 fixture: confirm `lift_shadow_from_flash`
   works, verify ROM set count, inspect pin invariant. If the CPU-mode sync
   PC range or the patcher offset don't transfer cleanly from `test-sdrr-0`
   to `1541`, surface that now before writing the binary.
2. **Stage 1 — library TDD.** `onerom_stress` module: sweep generator,
   histogram aggregator, report formatter. Three pure-function unit tests.
3. **Stage 2 — PIO stress binary.** Wire `run_case` loop. First full-sweep run
   on 1541 fixture. Inspect for latency sawtooth + first-failure triage.
4. **Stage 3 — CPU stress binary + 1541-cpu fixture.** Produce
   `onerom-fire-24-a-rp2350-1541-cpu.bin`. Verify CPU-mode sync PC range
   (risk 1). Wire the CPU `run_case` loop.
5. **Stage 4 — devil's-advocate review.** Independent agent reviews both
   binaries + library, challenging design and correctness. Gaps feed back
   into stage 2/3 as needed.
6. **Stage 5 — plan-vs-implementation confirmation.** Independent agent
   compares final state against the HLD, reports completeness.

Commit after each stage (not in bulk). Each stage has its own code-reviewer
pass + apply-feedback loop before commit.
