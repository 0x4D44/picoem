### 2026-04-16 — Phase 0c landed (f32ed2b)

Primitives micro-prototype benchmark binary (threading_micro.rs).
5 benchmarks measuring real threading primitive costs:

| Benchmark | Result |
|---|---|
| SpinBarrier (4-way, 1M rounds) | ~425 ns mean |
| AtomicU32 contended (10M ops) | ~78 Mops/s |
| AtomicU32 uncontended | ~350 Mops/s (4-5x ratio) |
| Masked CAS (4 threads) | ~35 ns, ~25% retry |
| Lock-free SPSC (cap=256) | ~45 Mops/s |
| sync_channel(8) baseline | ~10 Mops/s |
| Mutex contended (4 threads) | ~90 ns |

**Go/no-go thresholds both PASS:**
- SpinBarrier: ~425 ns < 500 ns threshold
- AtomicU32 contended: ~78 Mops/s > 50 Mops/s threshold

**Key finding:** SPSC queue at capacity 8 was pathologically slow
(couldn't complete 1M elements in 30s). Cross-core cache-line bouncing
dominates at small capacities. Minimum viable capacity is ~256. This
informs Phase 2 ThreadedSio/PIO queue sizing.

**Devil's advocate review:** 5/5 components pass — SpinBarrier
ordering correct, CAS retry accounting correct, SPSC queue orderings
sound for SPSC contract, measurement validity good (warmup done,
compiler-opt risk acceptable), Windows thread affinity correct.
