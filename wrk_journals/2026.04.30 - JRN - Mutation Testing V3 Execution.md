## Stage 1 — Stream A: classifier unit tests (complete)

Goal: convert the 79 mdrp2040 + 51 mdrp2350 classifier-cluster survivors from oracle-invisible to test-caught.

### Decision: inline `#[cfg(test)] mod classifier_tests` block

The classifier helpers (`classify_is_pure`, `classify_thumb16_pure`,
`classify_thumb16_misc_pure`, `classify_thumb32_pure`, plus mdrp2350's
`classify_thumb32_branch_misc_pure`, `classify_thumb32_misc_control_pure`,
and `is_thumb16_flag_only`) are private (`fn`, no `pub`) inside the
respective `decode.rs` files. To test them externally I'd need to bump
their visibility. Instead I added an inline `#[cfg(test)] mod
classifier_tests { use super::*; ... }` block at the bottom of each
`decode.rs` — same pattern used in `crates/mdrp2350/src/core/mod.rs:1147`.
Zero visibility surface change; tests live next to what they exercise.

### Test design

Two layers per classifier:

1. **Per-match-arm structural assertions** with named encodings. Catches
   match-arm-delete, boolean-flip, and constant-flip mutations with
   human-readable diagnostics. Documents intent.
2. **FNV-1a 64-bit fingerprint** over the relevant input space —
   exhaustive 16-bit for Thumb-16 classifiers, structured cross-product
   for Thumb-32. Catches any mutation that changes even a single
   input → output mapping. Single-line assert against a checked-in
   constant computed once and pasted in.

FNV-1a was chosen over `std::collections::hash_map::DefaultHasher`
because the std hasher is **not stable across Rust versions**. FNV-1a
(`offset_basis = 0xcbf29ce484222325`, `prime = 0x100000001b3`) is
canonical, ~5 lines inline, and survives toolchain changes.

### Cross-crate check on misc op[11:8] semantics

The two crates intentionally diverge on the misc-fallback arm:

| op[11:8]      | mdrp2040 | mdrp2350 | Reason |
|---            |---       |---       |---     |
| `0b1110` BKPT | impure   | pure     | M0+ classifies BKPT impure (sets `pending_fault`); M33 stubs it as NOP. |
| `0b1110` CBZ/CBNZ | n/a (no encoding) | pure | M33 supports CBZ/CBNZ; M0+ does not. |
| Unenumerated  | impure (`_ => false`) | pure (`_ => true`) | mdrp2350 trusts NOP-stub misc encodings; mdrp2040 conservative. |

Each crate's `misc_other_ops_*` test asserts the correct fallback. A
mutation flipping either crate's `_` arm is caught.
