### 2026-04-17 — Stage 2 complete

**Process:** implementer (with mandatory empirical QEMU checks) → code-reviewer + devil's-advocate combined lens → apply-feedback (agent crashed on infrastructure error partway through, but most work landed; supervisor applied final 3 nits directly).

**Empirical discoveries (locked into LLD §2):**
- HLD's speculated `-cpu rv32,a=true,m=true,c=true,zicsr=true,zifencei=true` syntax is **verified correct** on QEMU 10.2. Lowercase single-letter + lowercase `zicsr`/`zifencei`.
- **`-kernel` is rejected with `-machine none`** on QEMU 10.2 ("use the generic 'loader' device instead"). LLD swapped to `-device loader,file=<bin>,addr=0x20000000,cpu-num=0`. Deviation from core HLD V6 §6 P2.5 — tracked in `tech_debt.md` under "HLD/LLD alignment".
- **CSR-via-qXfer does NOT work** on QEMU 10.2 — advertised in target.xml but `qXfer:features:read:riscv-csr.xml` returns E00; flat-index register reads ≥0x42 return E14. The HLD's fallback "instruction-splice proxy" is not a fallback — it is the only working mechanism. LLD pins this.
- D-extension default (RV32D) pulls 64-bit FPRs into GDB register map. LLD adds `f=false,d=false` to CPU property line, killing the FPR block + aligning misa with Hazard3's `0x4080_1105`.

**Review findings addressed:**
- **Critical C1:** proxy self-mask leak extended beyond Zicsr class. LLD §4.1 adds pre-suite self-check reading each diff-set CSR via two instruction patterns (`csrrs rd, csr, x0` and `csrrw rd, csr, x0` with `rs1=x0`); abort if patterns disagree on either side.
- **Major M1-M6:** tech_debt entry for HLD deviation; alternatives-considered box rejecting `-machine virt`/`sifive_e`; WARL starter table with 5 known-divergence rows; `f=false,d=false` added; `riscv-decode` 0.2.3 crate as property-test reference encoder (zero hand-rolled); `-icount` removed from pinned (deferred until a cycle-diff dimension needs it).
- **Minor/Nit:** Zcmp weight halved (30 edge cases already sweep the quadrant bits); prerequisite table got the property-test gate row; §13 "Three edits" corrected.

**Deliverables:**
- `wrk_docs/2026.04.17 - LLD - QEMU Diff RISC-V V1.md` (340 LoC, 14 sections)
- `tech_debt.md` — new "HLD/LLD alignment" entry
