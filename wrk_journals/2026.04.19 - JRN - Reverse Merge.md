## Context

Earlier today we committed `05855bf` — the forward merge of `worktree-threading-phase0` into `main`, with the `threading` Cargo feature gated off by default. That got us to a compile-green, test-green state on main, but at the cost of *disabling* the threading Phase 0-4 work that we actually need for perf.

Arthur's framing: we 100% need threading to meet perf targets. The forward merge was a safety play; the architectural answer is the **reverse**. ## Approach: cherry-pick 126 commits, test between each

Discussed and rejected Path A (one giant reverse-merge commit with 33+ conflict resolutions in one session). Arthur's framing for why that's less safe: failure in one giant merge requires archaeology across all resolutions simultaneously, whereas per-commit cherry-picks localise failures to the specific commit. `cargo check` between each is cheap (~30s). Most commits will be no-ops; only the hot-zone ones need architectural judgment.

### Rules

1. **Base**: `27bbd90` (threading-phase0 tip — load-first fast-path fix, benchmarked).
2. **Branch**: `reverse-merge`, worktree at `.claude/worktrees/reverse-merge`.
3. **Order**: topological oldest-first (`git log --reverse 10362a5..ea9970f --no-merges`).
4. **Tool**: `git cherry-pick -x` (leave SHA breadcrumb in commit message).
5. **Conflict rule**: threading's architecture wins in `core/`, `bus/`, `sio/`, `dma.rs`, `threaded/`, `lib.rs`. Main's content wins elsewhere. If a specific main commit is genuinely incompatible with threading shape, skip it and port semantically — log reasoning here.
6. **Test cadence**:
   - After every cherry-pick: `cargo check --workspace --exclude epio-sys`.
   - After every hot-zone commit (33 identified): add `cargo test -p mdrp2350 --lib`.
   - At milestones (end of RISC-V P1-P4, end of coverage V11/V12, end of peripheral fidelity wave): full `cargo test --workspace --exclude epio-sys` + `cargo build --features mdrp2350/threading --exclude epio-sys`.
   - Final gate: QEMU M33 fuzz 100K + QEMU RISC-V fuzz 10K + full test suite both feature settings.
7. **Abort conditions**: if more than 5 consecutive commits need skip-and-port, stop and reassess — the approach may not fit.

### Post-verification

On green final gate: `git checkout main && git reset --hard reverse-merge`. Orphans `05855bf` (forward merge), `906a94b` (overnight fuzz artefacts), `6fc705f` (journal appendix). Will port the latter two's *content* onto the new tip before reset (fuzz run-scripts/deadline/log are already independent; journal appendix's narrative is preserved in this journal instead).
