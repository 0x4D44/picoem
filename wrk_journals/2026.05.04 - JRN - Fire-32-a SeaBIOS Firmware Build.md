## Pin map (for the harness widening follow-up)

`sdrr-info -d` reports the fire-32-a + 27C020 pin layout the firmware expects. This is fundamentally different from fire-24-a's `[7,6,5,4,3,2,1,0,10,11,14,15,12]` 13-pin address map.

```
Data:
  D0..D7 on GPIO 0..7

Address (19 lines, A0..A18):
  A0 =P0:34   A1 =P0:33   A2 =P0:32   A3 =P0:31   A4 =P0:30
  A5 =P0:29   A6 =P0:28   A7 =P0:27   A8 =P0:20   A9 =P0:19
  A10=P0:17   A11=P0:18   A12=P0:26   A13=P0:21   A14=P0:22
  A15=P0:25   A16=P0:16   A17=P0:23   A18=P0:24

Chip selects:
  CS1=P0:13   CS2=P0:16   CE =P0:15   OE =P0:14
  X1/2 jumper pull = P0:0  (note: collides with D0!)

Image select pins:
  SEL0=P0:38  SEL1=P0:39  SEL2=P0:36  SEL3=P0:37
  SWCLK=P0:36  SWDIO=P0:37 (SEL2/SEL3 alias SWD)

Control:
  VBUS=P0:46  Status LED=P0:45
```

Notes for the harness:
- A18 is wired even though 27C020 only needs A0..A17 — the 32-pin socket also accommodates 27C040 (512 KiB), so A18 is a dedicated address line on the chip. ROM-set size in metadata reports 524 288 bytes (= 27C040 capacity), even though only 256 KiB of the shadow has the SeaBIOS bytes; the rest is presumably mirrored or padded.
- CS2 (P0:16) aliases A16. So driving A16 high on the host bus also raises CS2. For 27C020 with `cs2 = "Active Low"` (per sdrr-info), the chip is selected when CS2 is low, which means the address-pin alias is benign (high A16 = chip deselected by CS2 = data pins tristated). The harness sweep over all 19-bit addresses needs to know this aliasing to interpret which patterns are servable.
- D0..D7 on GPIO 0..7 is a contiguous lane; reading the data byte from `gpio_in & 0xFF` is the natural lift.

## Reproduction recipe

```bash
# 1. Toolchain (one-time):
winget install Arm.ArmGnuToolchain    # 12.2 mpacbti-rel1
winget install GnuWin32.Make          # 3.81

# 2. Clone:
git clone --depth 1 https://github.com/piersfinlayson/one-rom.git \
   "/c/Users/$USER/AppData/Local/Temp/one-rom-work/one-rom"
cd "/c/Users/$USER/AppData/Local/Temp/one-rom-work/one-rom"

# 3. Pre-clone deps:
cd sdrr && git clone --depth 1 https://github.com/piersfinlayson/segger-rtt.git \
       && git clone --depth 1 https://github.com/piersfinlayson/apio.git
cd ..

# 4. Patch sdrr/link/common.ld /DISCARD/ block (GCC 12.2 quirk):
#    Add: *(.ARM.exidx*) *(.ARM.extab*) *(.eh_frame*) *(.eh_frame_hdr*)

# 5. Drop SeaBIOS where the JSON expects it:
cp /c/language/picoem/crates/picoem-harness/fixtures/sources/seabios-256k.bin images/

# 6. Author onerom-config/seabios-32-27c020.json:
#    {"$schema":"https://images.onerom.org/configs/schema.json","version":1,
#     "name":"seabios-32-27c020","description":"...",
#     "categories":["bios","x86","firmware"],
#     "rom_sets":[{"type":"single","roms":[
#        {"description":"SeaBIOS 256 KiB x86 BIOS",
#         "file":"images/seabios-256k.bin","type":"27C020"}]}]}

# 7. Build the Rust tools:
cd rust && cargo build --release -p sdrr-gen -p onerom-fw -p sdrr-info && cd ..

# 8. Generate empty firmware sources, build, splice metadata:
mkdir -p output_empty
./rust/target/release/sdrr-gen.exe --mcu rp2350 --hw fire-32-a --overwrite \
  --output-dir output_empty --status-led --swd --count-rom-access

cd sdrr
export PATH="/c/Program Files (x86)/Arm GNU Toolchain arm-none-eabi/12.2 mpacbti-rel1/bin:/c/Program Files (x86)/GnuWin32/bin:$PATH"
export GEN_OUTPUT_DIR=output_empty EXCLUDE_METADATA=1
export EXTRA_C_FLAGS="-fno-unwind-tables -fno-asynchronous-unwind-tables -fno-exceptions"
export VERSION_MAJOR=0 VERSION_MINOR=6 VERSION_PATCH=9 BUILD_NUMBER=1 GIT_COMMIT=local
export BIN_PREFIX=sdrr-rp2350-empty
make CC=arm-none-eabi-gcc OBJDUMP=arm-none-eabi-objdump OBJCOPY=arm-none-eabi-objcopy SIZE=arm-none-eabi-size
cd ..

mkdir -p builds-out
./rust/target/release/onerom-fw.exe --fw-image sdrr/build/sdrr-rp2350-empty.bin \
  --rom onerom-config/seabios-32-27c020.json \
  --out builds-out/onerom_fire-32-a_seabios-32-27c020.bin

# 9. Validate:
./rust/target/release/sdrr-info.exe info -d --strict builds-out/onerom_fire-32-a_seabios-32-27c020.bin

# 10. Install:
cp builds-out/onerom_fire-32-a_seabios-32-27c020.bin \
   /c/language/picoem/crates/picoem-harness/fixtures/onerom-fire-32-a-rp2350-seabios.bin
```
