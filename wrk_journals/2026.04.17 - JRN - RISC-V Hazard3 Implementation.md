## Operating model

I am the supervisor. I do not directly write code, run tests, or debug. I delegate to agents:

- **Implementer agents** (general-purpose) write the code per a focused brief.
- **Reviewer agents** (general-purpose, instructed to use the `code-reviewer` skill) critique.
- **Apply-feedback agents** (general-purpose, instructed to use the `code-review-apply-feedback` skill) act on the review.
- **Devil's advocate agent** (general-purpose) challenges, looks for hidden assumptions and gaps.

Per stage:
1. Implementer brief → spawn agent, await result
2. Build/test verification (via implementer agent or a dedicated verifier agent)
3. Code review pass
4. Apply-feedback pass if the review surfaces material issues
5. Devil's advocate sweep
6. Commit
7. Update this journal
