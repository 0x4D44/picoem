## Results

**CANNOT SUSTAIN REAL-TIME on this host (3 GHz).**

| Metric | Value |
|--------|-------|
| Target | 150 MHz |
| Achieved | ~100 MHz (67% of target) |
| Utilization | 100% (no headroom) |
| Behind count | 3.15M quanta in 5 seconds |
| Host TSC | 3071 MHz |
| Host cycles/emu cycle | ~30 (need ~20 for real-time) |

The HLD assumed a 5 GHz host (33 cycles/emu cycle budget). At 3 GHz we only
have ~20 cycles budget, and we're using ~30.

**Release profile already has:** opt-level=3, fat LTO, panic=abort,
codegen-units=1 for the emulator crate. PGO is not set up yet.

**Next steps for performance:**
- Profile the hot loop (flamegraph/perf) to find bottlenecks
- PGO (HLD mentions this)
- Investigate whether step() can be optimised (the dual-core step with
  halted core 1 still has overhead per cycle)
- Check if a coarser quantum reduces overhead
- On a 5 GHz host this would likely work (50 cycles budget)
