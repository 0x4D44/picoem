## What Was Built

### Address Map Decode
- Full RP2350 memory map routing (ROM 32KB, SRAM 520KB, XIP, APB, AHB, SIO, PPB)
- Inner range guards (ROM < 0x8000, SRAM < SRAM_SIZE)
- Unmapped regions return 0 (BusFault deferred to Phase 3)

### SRAM Banking
- Word-striped SRAM0-7: `bank = (offset >> 2) & 7` (64KB per bank)
- Non-striped SRAM8 (4KB at 0x20080000), SRAM9 (4KB at 0x20081000)
- `Memory::bank_for_address()` validates SRAM region, returns Option<u8>

### Bus Latency
- Per-region latency: SRAM/ROM/SIO/AHB/PPB = 1 cycle, APB = 3R/4W
- `extra_wait_states` accumulator: layered on top of execute return values
- Zero changes to execute.rs (~123KB) — accumulator added in decode.rs
- peek/poke bypass bus timing via Memory directly

### Bus Arbitration
- `downstream_port()`: 15 port IDs (ROM, XIP, SRAM banks 0-9, APB, AHB, unmapped)
- `arbitrate_pair()`: core 0 wins same-port conflicts
- SIO/PPB core-local — never contend
- Not yet wired into Emulator::step() (deferred to Phase 5, dual-core)

### Atomic Access Aliases
- XOR/SET/CLR via bits [13:12] in 16KB peripheral windows
- APB interposed atomics: +2 extra cycles (6 total)
- AHB native atomics: no extra cost
- HashMap stub backing store for peripheral registers
- SRAM aliases (0x21/22/23xxxxxx) deferred — different mechanism

## Known Issues / Phase 3 Prep

**Items identified by DA for Phase 3:**
1. PPB reads return 0 — NVIC/SCB/VTOR invisible (bootrom needs these)
2. No BusFault generation — bootrom probes flash via BusFault
3. Coprocessors (RCP/DCP/GPIOC) need stubs — bootrom uses within first 20 instructions
4. Peripheral registers are pure storage — no side effects (RESETS_DONE, CLOCKS)
5. SIO reads return 0 — CPUID not differentiated per core

**Design issue for Phase 5:**
- Dual-core `extra_wait_states` accumulator: core 0's bus accesses within a tick pollute core 1's accumulator because `reset_extra_wait_states()` is called inside `decode_execute()`, not between core steps. Fix: reset before each core's step in Emulator::step().
