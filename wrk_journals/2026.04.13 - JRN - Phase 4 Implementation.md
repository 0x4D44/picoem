## Full Boot Chain

```
Reset → SP from ROM[0], PC from ROM[1]
  → Secure init: CPACR, SAU (8 regions), MPU (16 regions)
  → SAU verification via TT instructions
  → Clock setup: XOSC, PLL SYS, PLL USB
  → RESETS: bring peripherals out of reset
  → QMI flash init
  → bxns lr → Non-Secure transition
  → NS nsboot: SG gateway calls back to Secure
  → Flash detection: GPIO_HI_IN QSPI noise sampling
  → Flash scan: read picobin IMAGE_DEF at 0x10000040 via XIP SRAM window
  → SHA-256 validation (software, in ROM)
  → Jump to application entry: 0x10000060
  → Blinky: configure GPIO 25 pad, IO bank, output enable, output
  → GPIO 25 HIGH ✓
```

## Key Discoveries

1. **SG (Secure Gateway) instruction was missing** — the nsboot code calls
   back into secure ROM via SG at 0x7E00+. Without SG, the instruction was
   decoded as LDRD, corrupting registers.

2. **Flash detection via QSPI pin noise** — bootrom samples SIO GPIO_HI_IN
   21 times, summing upper bits. Needed pseudo-random values simulating pin
   activity when flash is loaded.

3. **XIP SRAM is the flash read window** — bootrom reads flash through
   0x1C000000 (cache-as-SRAM), NOT directly from 0x10000000. XIP SRAM
   must serve flash data when flash_loaded is true.

4. **SIO uses RP2350 offsets (8-byte spacing)** — GPIO_OUT_SET is at 0x018
   (not RP2040's 0x014). LLD had wrong offsets; implementation is correct.
