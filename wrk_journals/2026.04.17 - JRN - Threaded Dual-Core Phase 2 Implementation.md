## Scope

Four standalone types in `crates/mdrp2350/src/threaded/`:
1. SpscQueue — lock-free SPSC ring buffer (u32)
2. SpinBarrier — 4-way flat barrier
3. ThreadedSio — inter-core FIFOs, spinlocks, doorbells, MTIME
4. ThreadedPio — TX/RX FIFOs, atomic control, command queue

## Implementation order

1. SpscQueue (foundational — used by SIO and PIO)
2. SpinBarrier (independent, small)
3. ThreadedSio (depends on SpscQueue)
4. ThreadedPio (depends on SpscQueue)
5. Module wiring + build verification
6. Code review + devil's advocate + apply feedback
7. Final LLD parity check

Agents 2, 3, 4 can run in parallel after SpscQueue lands since they
all depend only on SpscQueue.

## Protocol per stage

1. Implementation agent writes code + tests
2. Run `cargo build -p mdrp2350` + tests
3. Code-reviewer agent reviews diff
4. Devil's advocate reviews
5. Feedback-applier addresses reviews
6. Re-verify
7. Commit
8. Update journal
