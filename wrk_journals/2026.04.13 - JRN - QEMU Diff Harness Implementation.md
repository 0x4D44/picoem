## Live Testing Against QEMU

### QEMU Installation
- Installed QEMU 10.2.0 via winget (`SoftwareFreedomConservancy.QEMU`)
- Located at `C:\Program Files\qemu\qemu-system-arm.exe` (not on PATH)

### First Run: 295/382 passed
Three issues found and fixed:

1. **QEMU omits EPSR.T from xPSR reads.** Sanity check expected T bit but
   QEMU's M-profile GDB stub doesn't expose it. Fixed: R0 round-trip probe
   + plausibility check instead of T bit check.

2. **addr_regs registers compared as absolute values.** Base registers (R1,
   R3 etc.) are intentionally set to different absolute addresses per side.
   Fixed: skip addr_regs registers in comparison; use scratch base for SP
   delta when SP is in addr_regs.

3. **STM stores translated base address to memory.** STM R3!, {R0-R7} stores
   R3 which contains the scratch base (0x200 vs 0x20000200). Fixed: exclude
   base register from STM register list.
