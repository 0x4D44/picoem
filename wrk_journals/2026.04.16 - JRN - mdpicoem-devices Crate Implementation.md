### Stage 2 — Move PSRAM

**Status:** complete. Commit `e0051f3` (combined with Stage 1).

Moved `peripherals/psram.rs` → `mdpicoem-devices/src/psram.rs`.
Pin constants (PIN_MISO/CS/SCK/MOSI) became instance fields on
`Psram` (25+ sites updated). Added `Psram::picogus()` convenience
constructor and `pin_miso()` accessor.

`Bus::psram` changed from `Psram` to `Option<Psram>` (default None).
`update_gpio()` and `reset()` wrapped in `if let Some`.
`EmulatorBuilder` gained `.psram()` method.

`phase_is_idle()` promoted from `#[cfg(test)]` to unconditional pub
(cross-crate integration tests need it).

Bus integration tests (4) and PIO integration tests (2) stayed in
`mdrp2040/src/peripherals/psram.rs` as test-only modules, switched
to builder API with `.as_ref().unwrap()` for buffer access.

10 PSRAM unit tests + 6 integration tests: all green.

### Stage 3 — Move LCD

**Status:** complete. Commit `22d5c84` (combined with Stage 4).

Moved `mdrp2040app/src/devices/lcd.rs` → `mdpicoem-devices/src/lcd.rs`.
Moved `LcdState` (+ custom Default with space fill) from
`mdrp2040app/src/snapshot.rs` into `lcd.rs`.

Pin constants became constructor params:
`LcdDecoder::new(sclk_pin, data_pin, cs_pin)`.

App updated: `snapshot.rs` imports from `mdpicoem_devices`,
`sim.rs` uses `LcdDecoder::new(14, 15, 16)`.

11 LCD unit tests: all green.

### Stage 4 — Move I2S capture

`default_out_path()` and its test moved to
