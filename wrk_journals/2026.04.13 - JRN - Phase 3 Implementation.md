## Key Discoveries During Bootrom Iteration

1. **TT instruction is critical** — used immediately after SAU setup for verification
2. **Boot RAM at 0xEFFF_F000** — 4KB secure stack (initial SP = 0xF0000000)
3. **MPU registers must be writable** — bootrom configures and verifies 16 regions
4. **PLL USB needed in addition to PLL SYS** — nsboot path configures USB PLL
5. **QMI flash controller stub needed** — bootrom initializes flash via QMI before probing
6. **XIP SRAM at 0x1C000000** — 16KB cache-as-SRAM used for NS code staging
7. **NS banked registers** — bootrom writes MSPLIM_NS, PRIMASK_NS etc. during NS setup
8. **The "no flash" path is the nsboot path** — not a WFI loop at 0x3E6 as we assumed. The bootrom sets up NS USB boot code and transitions to it via `bxns lr`.

## Open Items (beyond Phase 3 scope)
