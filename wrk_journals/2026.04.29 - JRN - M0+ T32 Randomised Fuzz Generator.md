## Context

The V1 work-package (commits `e02b070`..`0d31d5a`) closed the QEMU oracle filter gap for the M0+ Thumb-32 subset, but the actual fuzz path stayed Thumb-16 only. Differential signal for `execute_wide.rs` came from 10 hand-curated cases — too thin for catching encoding-edge bugs (e.g. BL imm21 sign-extension off-by-one near ±2^20). This iteration adds a randomised generator that produces M0+-subset T32 cases the relaxed filter admits, so `--fuzz N` becomes a real differential against QEMU `cortex-m0`.

No formal HLD: the work is small (one function ~80 LOC, one call-site, ~6 unit tests) and design decisions are constrained. This journal entry is the contract.

## Design (greenlit)

**New function** `generate_fuzz_m0plus_t32(count, rng) -> Vec<TestCase>` in `crates/mdpicoem-harness/src/thumb32_gen.rs`. Round-robin/random pick among four shapes:

| Shape | Random parameters | Encoder |
|---|---|---|
| BL T1 | imm21 ∈ ±2^20 (full 21-bit signed range, valid encodings only) | `enc_t32_bl` |
| MSR T1 | Rn ∈ 0..=12, sysm ∈ {0, 8, 9, 16, 20} | `enc_t32_msr` |
| MRS T1 | Rd ∈ 0..=12, sysm ∈ {0, 8, 9, 16, 20} | `enc_t32_mrs` |
| Barriers | DSB / DMB / ISB, option ∈ 0..=15 | inline (hw0=0xF3BF, hw1=0x8F0X) |

**SYSm set** — {0 (APSR), 8 (MSP), 9 (PSP), 16 (PRIMASK), 20 (CONTROL)}. The filter admits a wider range but these are the SYSm fields M0+ firmware actually reaches. Closes the V1 §7 gap on MSR CONTROL + MSP/PSP coverage.

**Filter discipline.** Every generated `TestCase` must satisfy `is_m0plus_safe(&case)`. Asserted in unit tests. No wasted fuzz cycles.

**Integration.** Add the call to `generate_fuzz_classes` in `crates/mdpicoem-harness/src/lib.rs:~4970` alongside the existing `generate_fuzz_t32_alu` / `_t32_mem` / `_fpu` calls. Per-class N expansion: `--fuzz 10000` adds ~10k cases on top of the existing ~127k → ~137k. Acceptable.

## Out of scope

- Mask variation in MSR (`enc_t32_msr` mask=0b10 hardcode stays — separate item).
- Per-case `[T32 PASS]` print in `run_targeted` (separate item).
- Curated cases in `gen_t32_branch` / `gen_t32_misc_control` — untouched.
- M33 / mdrp2350 generators.

### Stage B — review (parallel agents `a15170c9` code-reviewer, `a86534518a7c59366` devils-advocate)

**Code-reviewer:** clean overall. No required changes. Suggestions: the BL 21-bit choice abandons the 22..24-bit XOR-boundary surface; barrier op narrowing below the filter needs an explanatory comment; tests duplicate the sysm admit literal instead of reusing `M0PLUS_SYSM_ADMIT`; one tautological assertion.

**Devils-advocate:** confirmed the bones are right but called the contract overstated. Six substantive concerns:
- **C3** — uniform random sampling at 21-bit hits exact boundary values ~2^-20 per draw; the journal's stated motivation ("BL imm21 sign-extension off-by-one near ±2^20") is structurally untargeted without curated boundary cases. **Blocker.**
- **C4** — encoder accepts 25-bit signed; 21-bit silently drops the s/I1/I2 XOR boundary surface near ±2^24.
- **C6** — MSR sysm=0 (APSR) cases use `MASK_NO_FLAGS`, masking out exactly the bits that APSR write changes. APSR-write differential is structurally blind. **Blocker.**
- **C1/C2** — "round-robin" is misnamed; implementation is block-sequential. `mixed_distribution` test is tautological as a result.
- **C5** — unit tests re-derive filter predicates inline; drift between them and `is_m0plus_safe` is undetected.
- **Wall-time scaling** — generator emits 4×count cases, so `--fuzz 100000` would mean ~2h11min vs the 30 min the journal promised.

Supervisor decision: take all six as Stage C. Code-reviewer nits also bundled.

### Stage D — validation (agent `a2028622`) — bugs found

Validation working as designed. Generator surfaces 2,277 real bugs in `crates/mdrp2040/src/core/execute_wide.rs` MSR/MRS sysm handling.

**Smoke (no `--fuzz`):** 392/392 passed. Curated path unbroken.

**`--fuzz 10000 --seed 1`:** 137,561 cases (V1: 127,513, +10,048 = matches contract). 135,284 passed, **2,277 FAILed**. Wall ~12 min. Failure surface is finite and bounded by `(Rn × sysm)` cardinality — bug count plateaus around case ~60k.
