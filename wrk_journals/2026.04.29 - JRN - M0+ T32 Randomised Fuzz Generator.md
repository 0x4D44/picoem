## Context

The V1 work-package (commits `e02b070`..`0d31d5a`) closed the QEMU oracle filter gap for the M0+ Thumb-32 subset, but the actual fuzz path stayed Thumb-16 only. Differential signal for `execute_wide.rs` came from 10 hand-curated cases — too thin for catching encoding-edge bugs (e.g. BL imm21 sign-extension off-by-one near ±2^20). This iteration adds a randomised generator that produces M0+-subset T32 cases the relaxed filter admits, so `--fuzz N` becomes a real differential against QEMU `cortex-m0`.

No formal HLD: the work is small (one function ~80 LOC, one call-site, ~6 unit tests) and design decisions are constrained. This journal entry is the contract.

## Design (greenlit)

**New function** `generate_fuzz_m0plus_t32(count, rng) -> Vec<TestCase>` in `crates/mdpicoem-harness/src/thumb32_gen.rs`. Round-robin/random pick among four shapes:

| Shape | Random parameters | Encoder |
|---|---|---|
| BL T1 | imm21 ∈ ±2^20 (full 21-bit signed range, valid encodings only) | `enc_t32_bl` |
| MSR T1 | Rn ∈ 0..=12, sysm ∈ {0, 8, 9, 16, 20} | `enc_t32_msr` |
| MRS T1 | Rd ∈ 0..=12, sysm ∈ {0, 8, 9, 16, 20} | `enc_t32_mrs` |
| Barriers | DSB / DMB / ISB, option ∈ 0..=15 | inline (hw0=0xF3BF, hw1=0x8F0X) |

**SYSm set** — {0 (APSR), 8 (MSP), 9 (PSP), 16 (PRIMASK), 20 (CONTROL)}. The filter admits a wider range but these are the SYSm fields M0+ firmware actually reaches. Closes the V1 §7 gap on MSR CONTROL + MSP/PSP coverage.

**Filter discipline.** Every generated `TestCase` must satisfy `is_m0plus_safe(&case)`. Asserted in unit tests. No wasted fuzz cycles.

**Integration.** Add the call to `generate_fuzz_classes` in `crates/mdpicoem-harness/src/lib.rs:~4970` alongside the existing `generate_fuzz_t32_alu` / `_t32_mem` / `_fpu` calls. Per-class N expansion: `--fuzz 10000` adds ~10k cases on top of the existing ~127k → ~137k. Acceptable.

## Out of scope

- Mask variation in MSR (`enc_t32_msr` mask=0b10 hardcode stays — separate item).
- Per-case `[T32 PASS]` print in `run_targeted` (separate item).
- Curated cases in `gen_t32_branch` / `gen_t32_misc_control` — untouched.
- M33 / mdrp2350 generators.
