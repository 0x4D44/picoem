# `cargo tree --duplicates` baseline

**Date:** 2026-04-26
**Context:** Tranche 1 / A6 of the Tech Debt Action Plan. Capture today's
duplicate-tree state so a future regression can be diffed against it.
**Command:** `cargo tree --duplicates` from the workspace root.

## Summary of duplicate roots

All duplicates trace back to two third-party DAGs we cannot move:

1. **probe-rs / espflash chain** — `probe-rs 0.31` (vendored at
   `third_party/probe-rs-0.31.0-mdrp-patched`) pulls `espflash 4.4.0`,
   which in turn pulls a different RustCrypto generation than our own
   direct `sha2` use in `mdrp2350`. This forks `digest`, `md-5`,
   `block-buffer`, `crypto-common`, and `object` into two coexisting
   versions.
2. **ratatui chain** — the TUI apps pull `ratatui 0.30.0` which uses
   `darling 0.23`, `hashbrown 0.16` / `0.17`, `unicode-width 0.2`,
   `strum 0.27`, etc. — versus the older generations bundled with the
   probe-rs / espflash deps.

## What this tells us

- **Nothing the workspace can fix without an upstream bump.** Every fork
  is between two third-party crates whose own dep graphs disagree. The
  only direct-pin we control (`windows-sys = "0.61"` in
  `mdpicoem-harness/Cargo.toml`) is already aligned with the probe-rs
  generation it shares ABI with.
- **The two `windows-sys` versions are both pulled by probe-rs** (0.52
  via `serialport 4.9.0`, 0.61.2 via `nusb`/`hidapi`/`async-io`/
  `ctrlc`). This is internal probe-rs dep skew, not a workspace bug.
- **No workspace crate ships with two copies of a crate it directly
  uses.** Confirmed by walking each line: every duplicate root has its
  branches anchored in different transitive crates.

## Watchdog

If a future `cargo tree --duplicates` introduces a *new* root not on the
table above — particularly anything that touches the workspace crates
directly (e.g., a second `tracing` or `serde` major version reaching a
chip crate) — investigate. A duplicate inside a third-party DAG is
acceptable; a duplicate that escapes into our own crates is not.

## Net action

None today. Baseline captured. Re-run on next major dep bump (probe-rs
≥ 0.32, ratatui ≥ 0.31) and diff.
