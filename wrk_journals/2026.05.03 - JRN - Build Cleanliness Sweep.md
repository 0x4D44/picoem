### `cargo clippy --release --all-targets -- -D warnings`

19 lints, all from clippy 1.95.0 (the system rustc upgraded recently —
toolchain is `rustc 1.95.0 (59807616e 2026-04-14)`). None of them
were defects, missing code, or bad-merge artefacts — all idiom
upgrades clippy 1.95 added on top of patterns that were idiomatic
under earlier toolchains:

**`rp2040-emu` (3 lints):**
- `peripherals/timer.rs` — `if self.pause { 1 } else { 0 }` →
  `u32::from(self.pause)`. Cleaner than clippy's collapsible_match
  suggestion (which would have lost the else branch by routing
  through the `_ => 0` catch-all).
- `peripherals/i2c.rs` — collapsed `if !is_enabled()` guards on
  IC_CON / IC_TAR writes into match-arm guards. Writes while enabled
  fall through to the `_ => {}` catch-all (semantics preserved).

**`rp2350-emu` (11 lints):**
- `peripherals/timer.rs` — same `u32::from(self.pause)` rewrite.
- `peripherals/i2c.rs` — same collapsible_match treatment.
- `core/coprocessor.rs` — collapsible_match on the CP0 HI-bank MRC
  write-zero, and the rcp_btrue / rcp_bfalse / rcp_iequal assert
  arms. Each "assertion holds" path falls through to the silent-NOP
  catch-all, identical to before.
- `core/execute_thumb32.rs` — BASEPRI_MAX guard collapsed; UDIV
  uses `a.checked_div(b).unwrap_or(0)`.
- `core_riscv/execute.rs` — `MulDivKind::Divu` via `checked_div`.
  (`Remu` was not flagged — its fallback is `a`, not a constant.
  Left alone.)
- `peripherals/powman.rs` — `sys_per_tick` rewritten via
  `checked_div().map().unwrap_or()` so tick_hz=0 returns 0 (the
  obvious `unwrap_or(0).max(1)` would have returned 1).

**`picoem-harness` (5 lints):**
- `build_seabios_fixture.rs` — moved `#[cfg(test)] mod sha256_tests`
  to the bottom of the file (`items_after_test_module`).
- `seabios_fixture_byte_correct.rs` — `SetTally` struct literal
  with `..Default::default()` (`field_reassign_with_default`);
  `.is_multiple_of(N)` on progress modulo (`manual_is_multiple_of`).
- `onerom_cpu_probe.rs` — `sort_by_key(|e| Reverse(e.1))`
  (`unnecessary_sort_by`).
- `picogus_diff_rp2040.rs` — decile bucket via
  `checked_div().map().unwrap_or(0)` (`manual_checked_ops`).
